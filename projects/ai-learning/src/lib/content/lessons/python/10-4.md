# 学生成绩管理系统

## 项目概述

综合运用类、字典、可变参数等知识，实现一个学生成绩管理系统。

## 功能需求

1. 添加学生（姓名 + 多门成绩）
2. 计算学生平均分
3. 显示所有学生信息
4. 查询指定学生
5. 班级统计分析

## 代码实现

```python
class StudentManager:
    """学生成绩管理器"""

    def __init__(self):
        self.students = {}  # 字典存储学生信息

    def add_student(self, name, *scores):
        """添加学生及成绩"""
        avg = sum(scores) / len(scores) if scores else 0
        self.students[name] = {
            "scores": list(scores),
            "average": avg,
        }
        print(f"✅ 已添加: {name}，平均分: {avg:.1f}")

    def get_student(self, name):
        """查询学生信息"""
        if name in self.students:
            return self.students[name]
        return None

    def show_all(self):
        """显示所有学生"""
        if not self.students:
            print("📭 暂无学生数据")
            return

        print("\n" + "=" * 40)
        print("📊 所有学生成绩")
        print("=" * 40)

        for name, data in self.students.items():
            scores_str = ", ".join(map(str, data["scores"]))
            print(f"  👤 {name}")
            print(f"     成绩: {scores_str}")
            print(f"     平均: {data['average']:.1f}")
            print()

    def class_average(self):
        """计算全班平均分"""
        if not self.students:
            return 0
        total = sum(d["average"] for d in self.students.values())
        return total / len(self.students)

    def top_student(self):
        """找出最高分学生"""
        if not self.students:
            return None
        return max(self.students.items(), key=lambda x: x[1]["average"])

# 使用示例
manager = StudentManager()
manager.add_student("小明", 85, 90, 78)
manager.add_student("小红", 92, 88, 95)
manager.add_student("小刚", 70, 65, 80)

manager.show_all()
print(f"全班平均分: {manager.class_average():.1f}")

top_name, top_data = manager.top_student()
print(f"最高分学生: {top_name} ({top_data['average']:.1f}分)")
```

## 关键知识点

- 类封装数据和行为
- `**scores` 可变参数接收多门成绩
- 字典存储学生信息
- `max()` + `key` 参数找出最高分
- 类的方法组织功能模块
