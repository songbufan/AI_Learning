# 简易计算器

## 项目概述

综合运用函数、异常处理等知识，实现一个命令行计算器。

## 功能需求

1. 支持 `+`、`-`、`*`、`/` 四种运算
2. 处理除零错误
3. 处理无效输入
4. 支持连续计算
5. 清晰的用户界面

## 代码实现

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        raise ZeroDivisionError("除数不能为零")
    return a / b

# 运算符映射
operations = {
    "+": add,
    "-": subtract,
    "*": multiply,
    "/": divide,
}

def calculator():
    """计算器主函数"""
    print("=" * 40)
    print("🧮 简易计算器")
    print("支持运算: + - * /")
    print("输入 'quit' 退出")
    print("=" * 40)

    while True:
        # 获取用户输入
        user_input = input("\n请输入表达式（如: 10 + 5）: ").strip()

        if user_input.lower() == "quit":
            print("再见！")
            break

        # 解析输入
        parts = user_input.split()
        if len(parts) != 3:
            print("⚠️ 格式错误！请使用: 数字 运算符 数字")
            continue

        num1_str, op, num2_str = parts

        # 类型转换
        try:
            num1 = float(num1_str)
            num2 = float(num2_str)
        except ValueError:
            print("⚠️ 请输入有效的数字！")
            continue

        # 执行运算
        if op not in operations:
            print(f"⚠️ 不支持的运算符: {op}")
            continue

        try:
            result = operations[op](num1, num2)
            print(f"结果: {num1} {op} {num2} = {result}")
        except ZeroDivisionError:
            print("⚠️ 错误：除数不能为零！")

# 启动计算器
calculator()
```

## 关键知识点

- 函数映射（字典映射运算符到函数）
- 异常处理（`try-except`）
- 字符串解析（`split()`）
- 循环 + 用户交互
