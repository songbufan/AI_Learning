# for 循环

## 什么是循环？

循环用于**重复执行**一段代码。当需要多次执行相同或类似的操作时，循环可以大大简化代码。

## for 循环基本语法

```python
for 变量 in 序列:
    # 每次循环执行的代码块
    代码块
```

## 遍历列表

```python
fruits = ["苹果", "香蕉", "橙子"]

for fruit in fruits:
    print(f"我喜欢吃 {fruit}")
```

输出：

```
我喜欢吃 苹果
我喜欢吃 香蕉
我喜欢吃 橙子
```

## 遍历字符串

字符串也可以被遍历，每次取出一个字符：

```python
for char in "Python":
    print(char)
```

输出：

```
P
y
t
h
o
n
```

## range() 函数

`range()` 生成一个数字序列，常用于控制循环次数：

```python
# range(n) - 生成 0 到 n-1
for i in range(5):
    print(i)
# 输出: 0 1 2 3 4
```

## 在编辑器中练习

```python

for fruit in fruits:

```

3. 遍历字符串 "Hello"，逐个打印每个字符

5. 打印九九乘法表的第一行（1×1=1）

## 知识点总结

- `for` 循环用于遍历任何序列（列表、元组、字符串等）
- 循环体内代码必须缩进
- `for` 循环会依次取出序列中的每个元素
- 循环结束后，变量保留最后一个值
- 配合 `range()` 可以控制循环次数
