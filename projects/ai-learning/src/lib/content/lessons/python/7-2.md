# finally 与 else

## try-except-else-finally 完整结构

```python
try:
    # 可能出错的代码
    result = risky_operation()
except SomeException:
    # 出错时执行
    handle_error()
else:
    # 没有异常时执行
    process_result(result)
finally:
    # 无论是否异常都执行
    cleanup()
```

## else 子句

`else` 在 `try` 块**没有发生任何异常**时执行：

```python
try:
    num = int(input("请输入数字: "))
    result = 100 / num
except (ValueError, ZeroDivisionError):
    print("输入无效！")
else:
    # 只有 try 成功时才执行
    print(f"计算成功: 100 / {num} = {result}")
```

## finally 子句

`finally` **无论是否发生异常都会执行**：

```python
f = None
try:
    f = open("data.txt", "r")
    content = f.read()
except FileNotFoundError:
    print("文件不存在")
finally:
    # 确保资源被释放
    if f:
        f.close()
    print("清理完成")
```

## 使用 with 替代 finally

对于文件等资源，推荐使用 `with` 语句（自动处理）：

```python
# 传统方式
f = None
try:
    f = open("file.txt", "r")
    content = f.read()
finally:
    if f:
        f.close()

# 推荐方式（with 自动处理）
with open("file.txt", "r") as f:
    content = f.read()
```

## finally 的典型应用

### 清理资源

```python
def divide(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        print("错误：除数不能为零")
        result = None
    finally:
        print("清理资源或记录日志...")
    return result

print(divide(10, 2))   # 5.0
print(divide(10, 0))   # None
```

### 确保代码执行

```python
def process():
    try:
        connect_db()
        do_something()
    except Exception as e:
        print(f"错误: {e}")
    finally:
        disconnect_db()  # 确保断开数据库连接
```

## 知识点总结

- `else`：try 无异常时执行
- `finally`：无论是否异常都执行
- `finally` 适合资源清理
- 执行顺序：`try` → 无异常 → `else` → `finally`
- 执行顺序：`try` → 有异常 → `except` → `finally`
- `with` 语句内部就是 `try-finally` 机制
- `finally` 中的 return 会覆盖 try/except 中的 return
