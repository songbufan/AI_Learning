# 继承

## 什么是继承？

继承允许一个类（子类）**获取另一个类（父类）的属性和方法**，实现代码复用。

## 基本语法

```python
# 父类（基类）
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "发出声音"

# 子类（派生类）
class Cat(Animal):  # Cat 继承 Animal
    def speak(self):
        return f"{self.name} 喵喵叫"

class Dog(Animal):  # Dog 继承 Animal
    def speak(self):
        return f"{self.name} 汪汪叫"
```

## 方法重写（Override）

子类可以重新定义父类的方法：

```python
class Animal:
    def speak(self):
        return "发出声音"

class Cat(Animal):
    def speak(self):  # 重写父类方法
        return "喵喵"

class Dog(Animal):
    def speak(self):  # 重写父类方法
        return "汪汪"
```

## super() 调用父类方法

在子类中调用父类的方法：

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Cat(Animal):
    def __init__(self, name, color):
        super().__init__(name)  # 调用父类的 __init__
        self.color = color

    def introduce(self):
        return f"我是{self.name}，颜色是{self.color}"
```

## 多层继承

```python
class Animal:
    pass

class Mammal(Animal):  # 继承 Animal
    pass

class Cat(Mammal):      # 继承 Mammal（间接继承 Animal）
    pass
```

## 在编辑器中练习

```python
# 类继承

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "发出声音"

class Cat(Animal):  # Cat 继承 Animal
    def speak(self):
        return f"{self.name} 喵喵叫"

class Dog(Animal):  # Dog 继承 Animal
    def speak(self):
        return f"{self.name} 汪汪叫"

cat = Cat("咪咪")
dog = Dog("旺财")

print(cat.speak())
print(dog.speak())
```

## 知识点总结

- 继承：子类获取父类的属性和方法
- 语法：`class Child(Parent):`
- 方法重写：子类重新定义父类方法
- `super()` 调用父类的方法
- 支持多层继承
- 提高代码复用，避免重复
- 体现"is-a"关系（Cat is an Animal）
