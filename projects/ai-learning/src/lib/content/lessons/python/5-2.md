# 参数与返回值

## 位置参数

函数调用时，参数按**位置顺序**传递给函数：

```python
def introduce(name, age, city):
    return f"我是{name}，{age}岁，来自{city}"

# 位置参数：按顺序传递
print(introduce("小明", 20, "北京"))   # 我是小明，20岁，来自北京
print(introduce("小红", 22, "上海"))   # 我是小红，22岁，来自上海
```

## 默认参数

在函数定义时为参数指定默认值，调用时可以省略：

```python
def introduce(name, age, city="北京"):
    """city 有默认值"北京"，调用时可省略"""
    return f"我是{name}，{age}岁，来自{city}"

# 使用默认值
print(introduce("小明", 20))           # 我是小明，20岁，来自北京

# 覆盖默认值
print(introduce("小红", 22, "上海"))   # 我是小红，22岁，来自上海
```

> 注意：默认参数必须放在非默认参数之后！

## 关键字参数

调用时指定参数名，可以不按顺序：

```python
def introduce(name, age, city="北京"):
    return f"我是{name}，{age}岁，来自{city}"

# 关键字参数：顺序不限
print(introduce(name="小红", age=22, city="上海"))
print(introduce(age=22, name="小红", city="深圳"))
```

## 混合使用

```python
# 位置参数 + 关键字参数
# 规则：位置参数必须在关键字参数之前
print(introduce("小明", age=20, city="广州"))
```

## 返回值

函数可以返回任何类型的值：

```python
# 返回数字
def square(n):
    return n * n

# 返回字符串
def shout(text):
    return text.upper() + "!"

# 返回列表
def get_numbers():
    return [1, 2, 3, 4, 5]

# 返回多个值（实际上是返回元组）
def get_point():
    return 10, 20  # 等价于 return (10, 20)

x, y = get_point()
```

## 在编辑器中练习

```python
# 参数类型

def introduce(name, age, city="北京"):
    """介绍自己"""
    return f"我是{name}，{age}岁，来自{city}"

# 位置参数
print(introduce("小明", 20))

# 关键字参数
print(introduce(name="小红", age=22, city="上海"))
```

1. 定义一个函数 `power(base, exp=2)`，计算 base 的 exp 次方，exp 默认为 2
2. 定义一个函数 `greet(name, greeting="你好")`，返回问候语，greeting 默认为"你好"
3. 定义一个函数，返回矩形的面积和周长（返回多个值）
4. 定义一个带默认参数的函数 `create_profile(name, age, city="未知")`，创建用户资料字典
5. 尝试混合使用位置参数和关键字参数

## 知识点总结

- **位置参数**：按顺序传递
- **默认参数**：定义时指定默认值，调用可省略
- **关键字参数**：指定参数名，顺序不限
- 默认参数必须在非默认参数之后
- 位置参数必须在关键字参数之前
- `return` 返回值，无 return 则返回 `None`
- 一个函数可以返回多个值（实际返回元组）
