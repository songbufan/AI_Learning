# 列表基础

## 什么是列表？

列表（List）是 Python 中最常用的数据结构，用于存储**有序的、可变的**元素集合。你可以把列表理解为一个可以随时修改内容的购物清单。

## 创建列表

```python
# 空列表
empty = []

# 有元素的列表
fruits = ["苹果", "香蕉", "橙子"]
numbers = [1, 2, 3, 4, 5]
mixed = ["小明", 25, True, 1.75]  # 可以包含不同类型
```

## 访问元素

列表使用**索引**访问元素，索引从 0 开始：

```python
fruits = ["苹果", "香蕉", "橙子", "西瓜"]

print(fruits[0])   # 苹果（第一个）
print(fruits[2])   # 橙子（第三个）
print(fruits[-1])  # 西瓜（最后一个）
print(fruits[-2])  # 橙子（倒数第二个）
```

## 修改元素

列表是可变的，可以直接修改元素：

```python
fruits = ["苹果", "香蕉", "橙子"]
fruits[1] = "葡萄"  # 将"香蕉"改为"葡萄"
print(fruits)  # ["苹果", "葡萄", "橙子"]
```

## 添加元素

```python
fruits = ["苹果", "香蕉"]

# append() - 在末尾添加一个元素
fruits.append("橙子")

# insert() - 在指定位置插入
fruits.insert(1, "葡萄")

print(fruits)  # ["苹果", "葡萄", "香蕉", "橙子"]
```

## 删除元素

```python
fruits = ["苹果", "香蕉", "橙子", "西瓜"]

# remove() - 删除指定值的元素
fruits.remove("香蕉")

# pop() - 删除指定索引的元素（默认删除最后一个）
last = fruits.pop()
```

## 列表长度

```python
fruits = ["苹果", "香蕉", "橙子"]
print(len(fruits))  # 3
```

## 在编辑器中练习

```python
# 列表（List）基础
fruits = ["苹果", "香蕉", "橙子"]

# 访问元素
print(fruits[0])  # 第一个元素
print(fruits[-1])  # 最后一个元素

# 修改元素
fruits[1] = "葡萄"
print(fruits)

# 添加元素
fruits.append("西瓜")
print(fruits)
```

## 知识点总结

- 列表用 `[]` 定义，元素用逗号分隔
- 索引从 0 开始，负数索引从末尾开始
- 列表是**可变的**（mutable），可以增删改
- `append()` 添加元素到末尾
- `insert()` 在指定位置插入
- `remove()` 删除指定值的元素
- `pop()` 删除指定索引的元素
- `len()` 获取列表长度
