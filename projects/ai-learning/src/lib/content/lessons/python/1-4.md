# 数字运算

## 算术运算符

Python 支持基本的算术运算：

| 运算符 | 说明 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `10 + 3` | `13` |
| `-` | 减法 | `10 - 3` | `7` |
| `*` | 乘法 | `10 * 3` | `30` |
| `/` | 除法（返回浮点数） | `10 / 3` | `3.333...` |
| `//` | 整除（向下取整） | `10 // 3` | `3` |
| `%` | 取余（取模） | `10 % 3` | `1` |
| `**` | 幂运算 | `2 ** 3` | `8` |

## 运算符优先级

运算符的运算顺序（从高到低）：

1. `**` （幂运算）
2. `*`、`/`、`//`、`%` （乘除取余）
3. `+`、`-` （加减）

使用括号 `()` 可以改变运算顺序：

```python
# 没有括号
result = 2 + 3 * 4    # 3 * 4 = 12, 2 + 12 = 14

# 有括号
result = (2 + 3) * 4  # 2 + 3 = 5, 5 * 4 = 20
```

## 在编辑器中练习

```python
# 基本算术运算
a = 10
b = 3

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} * {b} = {a * b}")
print(f"{a} / {b} = {a / b}")
print(f"{a} // {b} = {a // b}")  # 整除
print(f"{a} % {b} = {a % b}")    # 取余
print(f"{a} ** {b} = {a ** b}")  # 幂运算
```

## 知识点总结

- Python 支持 `+`、`-`、`*`、`/`、`//`、`%`、`**` 运算符
- `/` 返回浮点数，`//` 返回整数（向下取整）
- `%` 取余运算，`**` 幂运算
- 运算符有优先级，可用括号改变顺序
