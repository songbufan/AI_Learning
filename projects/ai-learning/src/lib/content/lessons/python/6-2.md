# 逐行读取

## 为什么逐行读取？

当处理大文件时，一次性读取全部内容会占用大量内存。逐行读取可以：
- 节省内存
- 逐行处理数据
- 实时处理流式数据

## 逐行读取的三种方式

### 方式一：for 循环（推荐）

```python
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())  # strip() 去除换行符
```

Python 的文件对象本身就是可迭代的，每次迭代返回一行。

### 方式二：readline()

```python
with open("data.txt", "r", encoding="utf-8") as f:
    line = f.readline()
    while line:
        print(line.strip())
        line = f.readline()
```

### 方式三：readlines()

```python
with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()  # 一次性读取所有行到列表

for line in lines:
    print(line.strip())
```

## 三种方式对比

| 方式 | 内存占用 | 适用场景 |
|------|----------|----------|
| for 循环 | 最低（逐行） | 大文件、流式处理 |
| readline() | 低 | 需要控制读取节奏 |
| readlines() | 高（全部加载） | 小文件、需要随机访问 |

## 行处理技巧

```python
# 去除换行符
line = line.strip()

# 分割行内容
parts = line.split(",")

# 跳过空行
if not line.strip():
    continue

# 跳过注释行（以 # 开头）
if line.startswith("#"):
    continue
```

## 在编辑器中练习

```python
# 逐行读取文件（语法演示）

lines = ["第一行", "第二行", "第三行"]

for line in lines:
    print(f"读取: {line}")
```

3. 读取 CSV 文件（每行逗号分隔），解析为列表

5. 逐行读取两个文件，逐行合并输出

## 知识点总结

- `for line in f` 是最推荐的逐行读取方式
- `strip()` 去除首尾空白字符（包括换行 `\n`）
- `split()` 分割字符串为列表
- 大文件务必用逐行读取，避免 `read()` 一次性加载
- `startswith()` 检查字符串前缀
- 逐行处理是处理日志、CSV 等文本文件的标准方式
