# 实例变量与类变量

## 两种变量类型

类中可以定义两种变量：

- **实例变量**：每个对象独立拥有，互不影响
- **类变量**：所有对象共享，属于类本身

## 实例变量

在 `__init__` 中通过 `self` 定义的变量：

```python
class Student:
    def __init__(self, name):
        self.name = name  # 实例变量，每个对象独立

s1 = Student("小明")
s2 = Student("小红")

print(s1.name)  # 小明
print(s2.name)  # 小红
```

## 类变量

在类内部、方法外部定义的变量：

```python
class Student:
    school = "Python 学校"  # 类变量，所有实例共享

    def __init__(self, name):
        self.name = name    # 实例变量

s1 = Student("小明")
s2 = Student("小红")

print(s1.school)  # Python 学校
print(s2.school)  # Python 学校
print(s1.school is s2.school)  # True（同一个对象）
```

## 修改类变量的影响

```python
class Counter:
    count = 0  # 类变量

    def __init__(self, name):
        self.name = name
        Counter.count += 1  # 修改类变量

c1 = Counter("A")
c2 = Counter("B")
print(Counter.count)  # 2（所有实例共享）
```

## 实例变量 vs 类变量

| 特性 | 实例变量 | 类变量 |
|------|----------|--------|
| 定义位置 | `__init__` 内 `self.` | 类内部，方法外部 |
| 归属 | 每个对象独立 | 类本身，所有实例共享 |
| 访问方式 | `self.var` / `obj.var` | `ClassName.var` / `self.var` |
| 修改影响 | 只影响当前对象 | 影响所有实例 |
| 内存 | 每个对象一份 | 只有一份 |

## 在编辑器中练习

```python
# 实例变量 vs 类变量
class Student:
    school = "Python 学校"  # 类变量（所有实例共享）

    def __init__(self, name):
        self.name = name  # 实例变量（每个实例独立）

s1 = Student("小明")
s2 = Student("小红")

print(f"{s1.name} 在 {s1.school}")
print(f"{s2.name} 在 {s2.school}")
print(f"学校是同一个: {s1.school is s2.school}")
```

## 练习任务

1. 创建一个 `Counter` 类，用类变量统计创建了多少个实例
2. 修改类变量后，观察所有实例的变化
3. 创建一个 `Car` 类，类变量 `wheels = 4`，实例变量 `brand`、`color`
4. 创建一个 `User` 类，类变量 `role = "user"`，实例变量 `username`
5. 对比实例变量和类变量的内存占用

## 知识点总结

- 实例变量：`self.xxx`，每个对象独立
- 类变量：类内部定义，所有实例共享
- 类变量通过 `ClassName.var` 访问
- 修改类变量影响所有实例
- 实例变量屏蔽同名类变量（就近原则）
- 类变量适合存储公共数据（如计数器、配置）
