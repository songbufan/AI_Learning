# 猜数字游戏

## 项目概述

综合运用循环、条件判断、随机数等知识，实现一个经典的猜数字游戏。

## 游戏规则

1. 系统随机生成一个 1-100 的整数
2. 玩家输入猜测的数字
3. 系统提示"太大"、"太小"或"猜对了"
4. 记录猜测次数
5. 玩家可以随时退出

## 代码实现

```python
import random

def guess_number():
    """猜数字游戏主函数"""
    secret = random.randint(1, 100)
    attempts = 0

    print("=" * 40)
    print("🎮 猜数字游戏！")
    print("我已经想好了一个 1-100 的数字。")
    print("输入 -1 可以退出游戏。")
    print("=" * 40)

    while True:
        try:
            guess = int(input(f"\n第 {attempts + 1} 次猜测，请输入: "))

            if guess == -1:
                print(f"游戏结束！答案是 {secret}")
                break

            attempts += 1

            if guess == secret:
                print(f"🎉 恭喜！第 {attempts} 次猜对了！答案是 {secret}")
                break
            elif guess < secret:
                print("📈 太小了！再大一点")
            else:
                print("📉 太大了！再小一点")

        except ValueError:
            print("⚠️ 请输入有效的数字！")

    print(f"总共猜测了 {attempts} 次")

# 启动游戏
guess_number()
```

## 关键知识点

- `random.randint()` 生成随机数
- `while True` 无限循环 + `break` 退出
- `try-except` 处理无效输入
- 计数器变量记录猜测次数

## 在编辑器中练习

```python
# 猜数字游戏
import random

secret = random.randint(1, 100)
attempts = 0

print("猜数字游戏！我已经想好了一个 1-100 的数字。")
print("输入 -1 可以退出游戏。")

# 游戏主循环（演示 5 轮）
for i in range(5):
    guess = random.randint(1, 100)  # 模拟猜测
    attempts += 1

    if guess == secret:
        print(f"第 {attempts} 次：你猜对了！答案是 {secret}")
        break
    elif guess < secret:
        print(f"第 {attempts} 次：{guess} 太小了！")
    else:
        print(f"第 {attempts} 次：{guess} 太大了！")
```
