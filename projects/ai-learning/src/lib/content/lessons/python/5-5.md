# 递归函数

## 什么是递归？

递归是函数**调用自身**的编程技巧。一个递归函数需要：
1. **基线条件（Base Case）**：终止条件，停止递归
2. **递归条件（Recursive Case）**：调用自身的条件

## 递归的比喻

想象你在一排座位里找人，你不知道具体位置：

```
函数 find(位置):
    如果 位置上是目标: 返回找到
    否则: 找下一个位置（调用自己）
```

## 经典示例：阶乘

```python
def factorial(n):
    """计算 n 的阶乘（n! = n × (n-1) × ... × 1）"""
    if n <= 1:          # 基线条件
        return 1
    return n * factorial(n - 1)  # 递归条件

print(factorial(5))  # 5! = 5×4×3×2×1 = 120
print(factorial(10)) # 3628800
```

执行过程（factorial(3)）：

```
factorial(3)
→ 3 * factorial(2)
→ 3 * (2 * factorial(1))
→ 3 * (2 * 1)
→ 6
```

## 经典示例：斐波那契数列

```python
def fibonacci(n):
    """计算斐波那契数列第 n 项（1, 1, 2, 3, 5, 8, 13...）"""
    if n <= 1:          # 基线条件
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)  # 递归条件

print(fibonacci(10))  # 55
```

斐波那契数列规律：`F(n) = F(n-1) + F(n-2)`

```
F(5) = F(4) + F(3)
     = (F(3) + F(2)) + (F(2) + F(1))
     = ...
```

## 递归的优缺点

### 优点
- 代码简洁优雅
- 适合解决具有自相似结构的问题（树、图）

### 缺点
- 递归深度受限于 Python 最大递归深度（默认 1000）
- 重复计算（如斐波那契）
- 性能不如迭代

## 递归深度限制

```python
import sys
print(sys.getrecursionlimit())  # 默认 1000

# 可以修改（不推荐）
sys.setrecursionlimit(2000)
```

## 在编辑器中练习

```python
# 递归函数：计算阶乘

def factorial(n):
    """计算 n 的阶乘"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

# 递归计算斐波那契数列

def fibonacci(n):
    """计算斐波那契数列第 n 项"""
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(f"5! = {factorial(5)}")
print(f"fib(10) = {fibonacci(10)}")
```

## 知识点总结

- 递归：函数调用自身
- **基线条件**：必须要有，否则无限递归
- **递归条件**：逐步缩小问题规模
- 每次递归调用都会创建新的栈帧（消耗内存）
- 最大递归深度默认 1000
- 递归适合树形结构、分治算法
- 能用迭代解决的问题通常迭代更高效

> 💡 递归思维：把大问题拆成相同的小问题，直到小问题可以直接解决。
