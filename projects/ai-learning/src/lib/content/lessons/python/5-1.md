# 函数定义与调用

## 什么是函数？

函数是**一段可重复使用的代码块**，用于执行特定任务。使用函数可以：
- 避免重复代码
- 提高代码可读性
- 便于维护和调试

## 定义函数

使用 `def` 关键字定义函数：

```python
def greet():
    """打招呼"""
    print("Hello, World!")

# 调用函数
greet()  # 输出: Hello, World!
```

## 函数结构

```
def 函数名(参数):
    """文档字符串（可选）"""
    函数体
    return 返回值（可选）
```

## 带参数的函数

```python
def greet(name):
    """向指定的人打招呼"""
    print(f"Hello, {name}!")

greet("小明")   # Hello, 小明!
greet("小红")   # Hello, 小红!
```

## 带返回值的函数

```python
def add(a, b):
    """计算两个数的和"""
    return a + b

result = add(3, 5)
print(result)  # 8
```

## 文档字符串（Docstring）

用三个引号包裹的函数说明：

```python
def multiply(a, b):
    """
    计算两个数的乘积

    参数:
        a: 第一个数
        b: 第二个数
    返回:
        两个数的乘积
    """
    return a * b

# 查看文档字符串
help(multiply)
print(multiply.__doc__)
```

## 在编辑器中练习

```python
# 函数定义与调用

def greet(name):
    """打招呼函数"""
    return f"你好，{name}！"

message = greet("小明")
print(message)
```

3. 定义一个函数 `greet(name, age)`，返回 `"你好，我是[name]，[age]岁"`

5. 给函数添加文档字符串，用 help() 查看

## 知识点总结

- `def` 关键字定义函数
- 函数名后跟圆括号 `()` 和冒号 `:`
- 函数体必须缩进
- 参数：函数接收的输入
- 返回值：函数输出的结果（`return` 关键字）
- 文档字符串：用 `"""` 包裹的函数说明
- 调用：`函数名(参数)`
