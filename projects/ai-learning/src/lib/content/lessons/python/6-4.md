# with 语句与上下文管理器

## 什么是上下文管理器？

上下文管理器是一种**确保资源正确释放**的机制。最典型的使用场景就是文件操作——确保文件在使用后被正确关闭。

## with 语句的原理

```python
# 普通写法
f = open("file.txt", "r")
try:
    content = f.read()
finally:
    f.close()  # 必须手动关闭

# with 语句（自动管理）
with open("file.txt", "r") as f:
    content = f.read()
# 退出 with 块后，文件自动关闭
```

## 上下文管理器协议

一个对象要成为上下文管理器，必须实现两个方法：

- `__enter__()` — 进入上下文时调用，返回值赋给 `as` 后的变量
- `__exit__()` — 退出上下文时调用，用于清理资源

```python
class Timer:
    """计时器上下文管理器"""

    def __enter__(self):
        import time
        self.start = time.time()
        return self  # 返回值赋给 as 后的变量

    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        self.end = time.time()
        elapsed = self.end - self.start
        print(f"耗时: {elapsed:.4f} 秒")
        # 返回 False 表示不抑制异常
        return False

# 使用上下文管理器
with Timer() as timer:
    total = sum(range(1000000))
    print(f"计算完成: {total}")
```

## 常见上下文管理器

| 对象 | 资源 | 自动释放 |
|------|------|----------|
| `open()` | 文件句柄 | 自动关闭 |
| `threading.Lock()` | 线程锁 | 自动释放 |
| `sqlite3.connect()` | 数据库连接 | 自动关闭 |

## 自定义上下文管理器（装饰器方式）

使用 `@contextmanager` 装饰器可以更简洁地创建：

```python
from contextlib import contextmanager

@contextmanager
def timer():
    import time
    start = time.time()
    yield  # 暂停，执行 with 块内的代码
    end = time.time()
    print(f"耗时: {end - start:.4f} 秒")

# 使用
with timer():
    total = sum(range(1000000))
```

## 在编辑器中练习

```python
# with 语句确保资源正确释放

class Timer:
    def __enter__(self):
        import time
        self.start = time.time()
        return self

    def __exit__(self, *args):
        import time
        self.end = time.time()

with Timer():

```

## 知识点总结

- `with` 语句确保资源正确释放
- 上下文管理器实现 `__enter__` 和 `__exit__`
- `__enter__` 返回值赋给 `as` 变量
- `__exit__` 用于清理，返回 `False` 不抑制异常
- `@contextmanager` 装饰器简化创建
- 适用场景：文件、锁、数据库连接、网络连接

> 💡 使用 with 语句是 Python 的最佳实践之一，养成使用习惯可以避免很多资源泄漏问题。
