# 异常基础

## 什么是异常？

异常（Exception）是程序运行过程中发生的错误。Python 提供了异常处理机制，让程序可以**优雅地处理错误**，而不是直接崩溃。

## 常见异常类型

| 异常 | 说明 | 示例 |
|------|------|------|
| `ZeroDivisionError` | 除零错误 | `1 / 0` |
| `ValueError` | 值错误 | `int("abc")` |
| `TypeError` | 类型错误 | `"hello" + 1` |
| `IndexError` | 索引越界 | `[1,2][5]` |
| `KeyError` | 字典键不存在 | `{}["missing"]` |
| `FileNotFoundError` | 文件不存在 | `open("no.txt")` |
| `ImportError` | 导入失败 | `import nonexistent` |

## try-except 基本语法

```python
try:
    # 可能出错的代码
    num = int(input("请输入数字: "))
    result = 100 / num
    print(f"100 / {num} = {result}")
except ValueError:
    # 值错误时执行
    print("错误：请输入有效的数字！")
except ZeroDivisionError:
    # 除零错误时执行
    print("错误：不能除以零！")
```

## 捕获所有异常

```python
try:
    # 可能出错的代码
    risky_operation()
except Exception as e:
    # 捕获所有异常
    print(f"发生错误: {e}")
```

## 完整的异常处理

```python
try:
    num = int(input("请输入数字: "))
    result = 100 / num
except ValueError:
    print("错误：请输入有效的数字！")
except ZeroDivisionError:
    print("错误：不能除以零！")
except Exception as e:
    print(f"未知错误: {e}")
else:
    # 没有异常时执行
    print(f"结果是: {result}")
finally:
    # 无论是否异常都执行
    print("程序结束")
```

## 手动抛出异常

使用 `raise` 关键字主动抛出异常：

```python
def set_age(age):
    if age < 0 or age > 150:
        raise ValueError(f"年龄 {age} 不合法！")
    return f"年龄设置为 {age}"

try:
    set_age(-5)
except ValueError as e:
    print(f"捕获异常: {e}")
```

## 在编辑器中练习

```python
# 异常处理基础（浏览器环境，使用固定值代替 input）
try:
    num = 10  # 模拟用户输入的数字
    result = 100 / num
    print(f"100 / {num} = {result}")
except ValueError:
    print("错误：请输入有效的数字！")
except ZeroDivisionError:
    print("错误：不能除以零！")
except Exception as e:
    print(f"未知错误: {e}")
```

> 💡 在浏览器中无法使用 `input()` 获取用户输入，请直接修改变量值来测试不同的情况。

## 知识点总结

- `try-except` 捕获并处理异常
- 异常按顺序匹配，第一个匹配的被执行
- `Exception` 是所有异常的基类
- `raise` 主动抛出异常
- `as e` 获取异常信息
- 异常处理让程序更健壮，避免崩溃
