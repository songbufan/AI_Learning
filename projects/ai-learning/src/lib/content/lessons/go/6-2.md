## main.go

```go
package main

import (
    "fmt"
    "log"
    "net/http"
    "os"

    "go-webapp/internal/handlers"
    "go-webapp/internal/middleware"
)

func main() {
    mux := http.NewServeMux()

    // 公开路由
    mux.HandleFunc("GET /articles", handlers.ListArticles)
    mux.HandleFunc("GET /articles/{id}", handlers.GetArticle)
    mux.HandleFunc("POST /articles", handlers.CreateArticle)

    // 应用中间件链
    handler := middleware.Logging(mux)
    handler = middleware.CORS(handler)
    handler = middleware.Recovery(handler)

    port := os.Getenv("PORT")
    if port == "" {
        port = "8080"
    }

    fmt.Printf("服务器启动: http://localhost:%s\n", port)
    log.Fatal(http.ListenAndServe(":"+port, handler))
}
```

## 中间件实现

```go
package middleware

import (
    "fmt"
    "net/http"
    "time"
)

func Logging(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        start := time.Now()
        next.ServeHTTP(w, r)
        fmt.Printf("%s %s %v\n", r.Method, r.URL.Path, time.Since(start))
    })
}

func CORS(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        w.Header().Set("Access-Control-Allow-Origin", "*")
        w.Header().Set("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE")
        w.Header().Set("Access-Control-Allow-Headers", "Content-Type, Authorization")
        next.ServeHTTP(w, r)
    })
}

func Recovery(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        defer func() {
            if err := recover(); err != nil {
                fmt.Printf("Panic: %v\n", err)
                http.Error(w, "内部服务器错误", http.StatusInternalServerError)
            }
        }()
        next.ServeHTTP(w, r)
    })
}
```

## 练习任务

1. 创建一个 `/health` 健康检查端点
2. 添加 `Content-Type` 设置中间件
3. 理解 `http.ServeMux` 和自定义路由的区别
4. 中间件链的执行顺序是怎样的？

## 知识点总结

- `http.NewServeMux()` 创建路由器
- 中间件通过 `http.Handler` 包装实现
- 中间件链按注册顺序嵌套执行
- `go.mod` 定义模块路径和依赖

> 💡 提示：Go 1.22+ 的 `net/http` 支持 `{param}` 路径参数，不再需要第三方路由库。
