# 并发安全与同步

## sync.WaitGroup

`WaitGroup` 等待一组 goroutine 完成：

```go
package main

import (
    "fmt"
    "sync"
    "time"
)

func worker(id int, wg *sync.WaitGroup) {
    defer wg.Done() // 任务完成时递减计数器
    fmt.Printf("Worker %d 开始\n", id)
    time.Sleep(time.Duration(id*100) * time.Millisecond)
    fmt.Printf("Worker %d 完成\n", id)
}

func main() {
    var wg sync.WaitGroup

    for i := 1; i <= 3; i++ {
        wg.Add(1) // 增加计数器
        go worker(i, &wg)
    }

    wg.Wait() // 等待所有 goroutine 完成
    fmt.Println("所有 worker 完成")
}
```

输出：

```
Worker 1 开始
Worker 2 开始
Worker 3 开始
Worker 1 完成
Worker 2 完成
Worker 3 完成
所有 worker 完成
```

## sync.Mutex

`Mutex`（互斥锁）保护共享数据：

```go
package main

import (
    "fmt"
    "sync"
)

type SafeCounter struct {
    mu    sync.Mutex
    count int
}

func (c *SafeCounter) Inc() {
    c.mu.Lock()
    c.count++
    c.mu.Unlock()
}

func (c *SafeCounter) Value() int {
    c.mu.Lock()
    defer c.mu.Unlock()
    return c.count
}

func main() {
    counter := &SafeCounter{}
    var wg sync.WaitGroup

    // 100 个 goroutine 各加 1000 次
    for i := 0; i < 100; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for j := 0; j < 1000; j++ {
                counter.Inc()
            }
        }()
    }

    wg.Wait()
    fmt.Printf("最终计数: %d\n", counter.Value())
}
```

输出：

```
最终计数: 100000
```

## 知识点总结

- `WaitGroup` 等待 goroutine 组完成
- `Mutex` 保护共享资源，`Lock()`/`Unlock()` 成对使用
- `defer mu.Unlock()` 确保解锁，防止 panic
- 优先使用 channel 通信，必要时用 sync 同步

> 💡 提示：Go 的哲学是「通过通信来共享内存，而不是通过共享内存来通信」。优先使用 channel。
