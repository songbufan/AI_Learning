# Map 与集合

## Map 基础操作

Map 是 Go 的内置哈希表实现：

```go
package main

import "fmt"

func main() {
    // 创建 map
    ages := map[string]int{
        "Alice": 25,
        "Bob":   30,
        "Carol": 28,
    }

    // 添加/修改
    ages["David"] = 35
    ages["Bob"] = 31

    // 读取（ok-idiom）
    if age, ok := ages["Alice"]; ok {
        fmt.Printf("Alice 的年龄: %d\n", age)
    } else {
        fmt.Println("Alice 不存在")
    }

    // 删除
    delete(ages, "Carol")

    // 遍历
    for name, age := range ages {
        fmt.Printf("%s: %d岁\n", name, age)
    }

    fmt.Printf("map 长度: %d\n", len(ages))
}
```

输出：

```
Alice 的年龄: 25
Alice: 25岁
Bob: 31岁
David: 35岁
map 长度: 3
```

## 嵌套 Map

```go
package main

import "fmt"

func main() {
    // map of maps
    config := map[string]map[string]string{
        "server": {
            "host": "localhost",
            "port": "8080",
        },
        "database": {
            "host": "127.0.0.1",
            "port": "5432",
            "name": "mydb",
        },
    }

    for service, settings := range config {
        fmt.Printf("[%s]\n", service)
        for key, val := range settings {
            fmt.Printf("  %s = %s\n", key, val)
        }
    }
}
```

输出：

```
[server]
  host = localhost
  port = 8080
[database]
  host = 127.0.0.1
  port = 5432
  name = mydb
```

## 知识点总结

- `map[KeyType]ValueType` 定义映射
- 未初始化的 map 是 `nil`，不能写入
- `val, ok := m[key]` 安全读取模式
- `range` 遍历 map 是无序的

> 💡 提示：创建 map 用 `make(map[KeyType]ValueType)`，不要用 `var m map[...]` 然后赋值，后者得到的是 nil map。
