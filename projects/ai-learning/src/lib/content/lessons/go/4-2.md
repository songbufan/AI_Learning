# Channel 通信

## Channel 的类型和方向

Channel 在 Go 中是有方向性的，用于确保类型安全：

```go
package main

import (
    "fmt"
    "time"
)

// 只发送通道：只能发送，不能接收
func sender(ch chan<- int) {
    for i := 1; i <= 5; i++ {
        ch <- i
        fmt.Printf("发送: %d\n", i)
    }
    close(ch)
}

// 只接收通道：只能接收，不能发送
func receiver(ch <-chan int, done chan<- bool) {
    for num := range ch {
        fmt.Printf("接收: %d (×3 = %d)\n", num, num*3)
    }
    done <- true
}

func main() {
    ch := make(chan int, 2) // 带缓冲的 channel，容量 2
    done := make(chan bool)

    go sender(ch)
    go receiver(ch, done)

    <-done
    close(done)
    fmt.Println("通信完成")
}
```

输出：

```
发送: 1
接收: 1 (×3 = 3)
发送: 2
接收: 2 (×3 = 6)
发送: 3
接收: 3 (×3 = 9)
发送: 4
接收: 4 (×3 = 12)
发送: 5
接收: 5 (×3 = 15)
通信完成
```

## 无缓冲 vs 带缓冲 Channel

| 类型 | 创建方式 | 特点 | 适用场景 |
|------|---------|------|---------|
| 无缓冲 | `make(chan T)` | 发送方阻塞直到接收方就绪 | 同步通信 |
| 带缓冲 | `make(chan T, n)` | 缓冲区满才阻塞 | 异步处理 |

```go
package main

import (
    "fmt"
    "time"
)

func main() {
    // 无缓冲 channel：同步通信
    syncCh := make(chan string)
    go func() {
        fmt.Println("发送前")
        syncCh <- "同步消息"
        fmt.Println("发送后")
    }()
    time.Sleep(100 * time.Millisecond)
    fmt.Println("接收:", <-syncCh)

    // 带缓冲 channel：异步通信
    bufCh := make(chan string, 2)
    bufCh <- "消息1"
    bufCh <- "消息2"
    fmt.Println("缓冲区大小:", cap(bufCh))
    fmt.Println("当前元素:", len(bufCh))
    fmt.Println(<-bufCh)
    fmt.Println(<-bufCh)
}
```

输出：

```
发送前
接收: 同步消息
发送后
缓冲区大小: 2
当前元素: 2
消息1
消息2
```

4. 从已关闭的 channel 接收会怎样？

## 知识点总结

- Channel 有方向：`chan T`（双向）、`chan<- T`（只发）、`<-chan T`（只收）
- `make(chan T)` 无缓冲，`make(chan T, n)` 带缓冲
- `close(ch)` 关闭 channel
- 向已关闭 channel 发送会 panic，接收零值直到为空

> 💡 提示：Channel 方向在函数签名中使用，编译器会检查类型安全。
