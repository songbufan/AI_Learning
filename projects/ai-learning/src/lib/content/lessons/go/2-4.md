# 错误处理

## error 类型

Go 使用 `error` 接口进行错误处理，而不是异常：

```go
package main

import (
    "errors"
    "fmt"
)

// error 接口定义
// type error interface {
//     Error() string
// }

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("除数不能为零")
    }
    return a / b, nil
}

func sqrt(n float64) (float64, error) {
    if n < 0 {
        return 0, fmt.Errorf("无法计算负数 %v 的平方根", n)
    }
    // 简化计算
    return n * 0.5, nil
}

func main() {
    result, err := divide(10, 3)
    if err != nil {
        fmt.Println("错误:", err)
    } else {
        fmt.Printf("10 / 3 = %.2f\n", result)
    }

    // 链式错误处理
    val, err := sqrt(-4)
    if err != nil {
        fmt.Println("错误:", err)
    } else {
        fmt.Printf("结果: %.2f\n", val)
    }
}
```

输出：

```
10 / 3 = 3.33
错误: 无法计算负数 -4 的平方根
```

## panic 和 recover

```go
package main

import "fmt"

func mayPanic() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Printf("恢复自 panic: %v\n", r)
        }
    }()
    panic("发生严重错误")
}

func main() {
    fmt.Println("正常开始")
    mayPanic()
    fmt.Println("程序继续执行")
}
```

输出：

```
正常开始
恢复自 panic: 发生严重错误
程序继续执行
```

## 错误处理最佳实践

```go
package main

import (
    "fmt"
    "os"
)

func readConfig(path string) (string, error) {
    // 模拟文件读取
    if path == "" {
        return "", fmt.Errorf("配置路径为空")
    }
    if path == "missing" {
        return "", os.ErrNotExist
    }
    return "config=ok", nil
}

func main() {
    _, err := readConfig("missing")
    if err != nil {
        switch {
        case os.IsNotExist(err):
            fmt.Println("配置文件不存在")
        case os.IsPermission(err):
            fmt.Println("无权限访问")
        default:
            fmt.Printf("其他错误: %v\n", err)
        }
    }
}
```

输出：

```
配置文件不存在
```

## 知识点总结

- Go 没有 try/catch，使用 `error` 返回值
- `error` 接口只有一个 `Error() string` 方法
- `panic` 用于不可恢复的错误，`recover` 用于捕获
- 最佳实践：总是检查并处理 error

> 💡 提示：Go 1.13 引入了 `errors.Is()` 和 `errors.As()`，用于错误包装和判断。
