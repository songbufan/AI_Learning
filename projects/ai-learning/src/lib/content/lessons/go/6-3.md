# 数据库操作与日志

## SQLite 集成

Go 中常用的数据库驱动：

| 数据库 | 驱动包 | 特点 |
|--------|--------|------|
| SQLite | `modernc.org/sqlite` | 嵌入式，零配置 |
| PostgreSQL | `pgx/v5` | 高性能，功能全 |
| MySQL | `go-sql-driver/mysql` | 最流行 |

## 使用 database/sql

```go
package main

import (
    "database/sql"
    "fmt"
    "log"

    _ "modernc.org/sqlite"
)

type Article struct {
    ID      int
    Title   string
    Content string
    Author  string
}

func main() {
    // 打开数据库
    db, err := sql.Open("sqlite", "./articles.db")
    if err != nil {
        log.Fatal(err)
    }
    defer db.Close()

    // 创建表
    _, err = db.Exec(`
        CREATE TABLE IF NOT EXISTS articles (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            title TEXT NOT NULL,
            content TEXT,
            author TEXT,
            created_at DATETIME DEFAULT CURRENT_TIMESTAMP
        )
    `)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println("表创建成功")

    // 插入数据
    result, _ := db.Exec(
        "INSERT INTO articles (title, content, author) VALUES (?, ?, ?)",
        "Go 入门", "Go 语言基础教程...", "张三")
    id, _ := result.LastInsertId()
    fmt.Printf("插入文章 ID: %d\n", id)

    // 查询
    var article Article
    db.QueryRow("SELECT id, title, content, author FROM articles WHERE id = ?", id).
        Scan(&article.ID, &article.Title, &article.Content, &article.Author)
    fmt.Printf("文章: %s\n", article.Title)
}
```

## 日志系统

```go
package main

import (
    "fmt"
    "os"
    "time"
)

type Logger struct {
    file *os.File
}

func NewLogger(filename string) (*Logger, error) {
    f, err := os.OpenFile(filename, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
    if err != nil {
        return nil, err
    }
    return &Logger{file: f}, nil
}

func (l *Logger) Info(msg string, fields ...interface{}) {
    l.log("INFO", msg, fields...)
}

func (l *Logger) Error(msg string, fields ...interface{}) {
    l.log("ERROR", msg, fields...)
}

func (l *Logger) log(level, msg string, fields ...interface{}) {
    line := fmt.Sprintf("[%s] %s: %s %v\n",
        time.Now().Format(time.RFC3339), level, msg, fields)
    fmt.Print(line)     // 输出到控制台
    l.file.WriteString(line) // 写入文件
}

func main() {
    logger, _ := NewLogger("app.log")
    defer logger.file.Close()

    logger.Info("服务器启动", "port", 8080)
    logger.Error("连接失败", "host", "db.example.com")
}
```

## 知识点总结

- `database/sql` 是 Go 标准库的数据库抽象层
- 驱动通过 `_ "驱动包"` 注册
- 使用 `?` 占位符防止 SQL 注入
- 日志系统支持多输出（控制台 + 文件）

> 💡 提示：生产环境推荐使用 `slog`（Go 1.21+）或 `zap`/`logrus` 等日志库。
