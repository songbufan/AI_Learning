# match 模式匹配

## match 表达式

`match` 是 Rust 最强大的控制流结构，类似其他语言的 `switch`，但更强大：

```rust
let number = 3;

match number {
    1 => println!("一"),
    2 => println!("二"),
    3 => println!("三"),
    _ => println!("其他"),
}
// 输出：三
```

## 穷尽性检查

Rust 编译器会检查 `match` 是否覆盖了所有可能：

```rust
let value = Some(3);

match value {
    Some(3) => println!("三"),
    Some(x) => println!("{}", x),
    None => println!("空"),
}
```

如果遗漏了 `None` 分支，编译会报错。

## 匹配多个值

```rust
let x = 1;

match x {
    1 | 2 | 3 => println!("小数字"),
    4 | 5 | 6 => println!("中数字"),
    _ => println!("大数字"),
}
```

## 范围匹配

```rust
let x = 5;

match x {
    1..=5 => println!("1 到 5 之间"),
    6..=10 => println!("6 到 10 之间"),
    _ => println!("其他"),
}
```

## 解构匹配

```rust
let point = (0, 5);

match point {
    (0, y) => println!("在 y 轴上，y={}", y),
    (x, 0) => println!("在 x 轴上，x={}", x),
    (x, y) => println!("在 ({}, {})", x, y),
}
```

## 练习任务

1. 使用 match 实现简易计算器（加减乘除）
2. 使用范围匹配判断分数等级（A/B/C/D/F）
3. 解构元组，根据坐标位置打印象限

## 知识点总结

- `match` 是表达式，有返回值
- 穷尽性检查：必须覆盖所有情况
- `_` 通配符处理未匹配
- `|` 匹配多个值，`..=` 范围匹配
- 支持解构 enum、struct、tuple

> 💡 提示：`match` 的穷尽性检查是 Rust 安全特性的重要体现，编译器不会让你遗漏任何情况。
