# 元组与数组

## 元组（Tuple）

元组可以将多个不同类型的值组合在一起：

```rust
let person: (&str, i32, f64) = ("小明", 25, 1.75);
```

### 元组解构

```rust
let (name, age, height) = person;
println!("{}，{}岁，{}米", name, age, height);
```

### 访问元素

```rust
println!("{}", person.0);  // 小明
println!("{}", person.1);  // 25
```

## 数组（Array）

数组存储相同类型的值，长度固定：

```rust
let numbers = [1, 2, 3, 4, 5];
let zeros = [0; 10];  // [0, 0, 0, ..., 0] 10 个 0
```

### 访问元素

```rust
let first = numbers[0];   // 1
let last = numbers[4];    // 5
```

### 越界访问

Rust 会在运行时检查数组索引，越界会触发 **panic**（程序崩溃）：

```rust
let x = numbers[10];  // 编译通过，运行时 panic！
```

## 切片（Slice）

切片是对数组或字符串一部分的引用：

```rust
let slice = &numbers[1..4];  // [2, 3, 4]
```

## 练习任务

1. 创建元组存储姓名、年龄、城市，解构并打印
2. 创建包含 5 个整数的数组
3. 使用范围获取数组的切片
4. 尝试访问数组越界索引，观察 panic

## 知识点总结

- 元组：不同类型组合，长度固定
- 数组：相同类型，长度固定，栈上分配
- 切片：`&[T]`，对连续内存的视图
- 索引越界：编译通过，运行时 panic

> 💡 提示：大多数情况下推荐使用 `Vec<T>`（动态数组），长度可变。数组适合已知固定大小的场景。
