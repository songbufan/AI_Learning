# 条件表达式

## if 表达式

Rust 的 `if` 是**表达式**，有返回值：

```rust
let number = 6;

let result = if number % 2 == 0 {
    "偶数"
} else {
    "奇数"
};

println!("{}", result);  // "偶数"
```

## 多条件分支

```rust
let score = 85;

let grade = if score >= 90 {
    'A'
} else if score >= 80 {
    'B'
} else if score >= 70 {
    'C'
} else {
    'F'
};

println!("等级: {}", grade);  // 'B'
```

## 条件要求

Rust 的条件必须是 `bool` 类型，**不会做隐式转换**：

```rust
let number = 3;

// 正确
if number != 0 { ... }

// 错误！编译失败
if number { ... }
```

## 在 let 中使用

```rust
let condition = true;
let number = if condition { 5 } else { 6 };

// if 和 else 返回值类型必须相同
// 下面的代码会编译错误：
// let number = if condition { 5 } else { "six" };
```

## 练习任务

1. 编写 if 表达式判断一个数是正数、负数还是零
2. 使用 if-else if-else 实现成绩等级划分
3. 尝试 if 和 else 返回不同类型的值，观察编译错误
4. 在 let 中使用 if 表达式赋值

## 知识点总结

- `if` 是表达式，有返回值
- 条件必须是 `bool`，无隐式转换
- `if` 和 `else` 返回值类型必须相同
- 可以使用 `let` 接收 `if` 表达式的返回值

> 💡 提示：Rust 没有三元运算符 `? :`，因为 `if` 表达式本身就可以实现相同功能。
