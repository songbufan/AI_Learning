# 开发环境搭建

## 安装 Rust

官方推荐的安装方式是使用 **rustup**，它是 Rust 工具链管理器。

### 安装命令

```bash
# Linux / macOS
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Windows — 下载 rustup-init.exe
# https://www.rust-lang.org/tools/install
```

### 验证安装

安装完成后，打开终端检查三个核心工具：

```bash
rustc --version   # Rust 编译器版本
cargo --version   # 包管理器版本
rustup --version  # 工具链管理器版本
```

## 工具链管理

`rustup` 可以管理多个 Rust 版本：

```bash
# 查看已安装版本
rustup show

# 安装 nightly 版本
rustup toolchain install nightly

# 切换默认版本
rustup default stable
```

## Cargo 简介

Cargo 是 Rust 的构建工具和包管理器，类似 Go 的 go 命令或 Node.js 的 npm。

| 命令 | 用途 |
|------|------|
| `cargo new <name>` | 创建新项目 |
| `cargo build` | 编译项目 |
| `cargo run` | 编译并运行 |
| `cargo test` | 运行测试 |
| `cargo check` | 快速检查（不生成二进制） |
| `cargo fmt` | 格式化代码 |
| `cargo clippy` | Lint 检查 |
| `cargo doc --open` | 生成并打开文档 |

## 练习任务

1. 按照官方指引安装 Rust
2. 使用 `cargo new hello_rust` 创建项目
3. 运行 `cargo run` 执行项目

## 知识点总结

- rustup 管理 Rust 工具链
- Cargo 是 Rust 的构建与包管理工具
- `cargo new` 创建标准项目结构
- `Cargo.toml` 是项目清单（类似 package.json）

> 💡 提示：如果安装较慢，可配置国内镜像源（如 ustc 镜像）。
