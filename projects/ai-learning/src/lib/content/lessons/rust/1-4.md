# Cargo 项目管理

## 项目结构

用 `cargo new` 创建的项目结构如下：

```
hello_rust/
├── Cargo.toml          # 项目配置
└── src/
    └── main.rs         # 源代码
```

## Cargo.toml 配置

`Cargo.toml` 是 Rust 项目的清单文件，类似 Node.js 的 `package.json`：

```toml
[package]
name = "hello_rust"
version = "0.1.0"
edition = "2021"

[dependencies]
# 外部依赖列表
serde = "1.0"
```

## 常用命令速查

| 命令 | 说明 |
|------|------|
| `cargo new <name>` | 创建新二进制项目 |
| `cargo new --lib <name>` | 创建新库项目 |
| `cargo build` | 编译到 `target/debug/` |
| `cargo build --release` | 发布编译（优化）到 `target/release/` |
| `cargo run` | 编译并运行 |
| `cargo check` | 只检查，不生成二进制（快） |
| `cargo test` | 运行测试 |
| `cargo fmt` | 代码格式化 |
| `cargo clippy` | Lint 静态分析 |
| `cargo doc --open` | 生成并打开文档 |
| `cargo update` | 更新依赖 |

## 工作空间

大型项目可以使用 Cargo Workspace 管理多个包：

```toml
[workspace]
members = [
    "crates/core",
    "crates/cli",
    "crates/web",
]
```

## 练习任务

1. 创建新项目并查看 `Cargo.toml` 内容
2. 运行 `cargo check` 对比 `cargo build` 的速度
3. 尝试 `cargo doc --open` 查看标准库文档

## 知识点总结

- `Cargo.toml` 管理项目元数据和依赖
- `cargo build --release` 启用优化编译
- `cargo check` 只检查类型，不生成二进制
- `cargo fmt` 和 `cargo clippy` 是必备工具

> 💡 提示：`cargo check` 在开发时频繁使用，速度远快于 `cargo build`。
