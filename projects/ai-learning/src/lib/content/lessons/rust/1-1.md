# Rust 简介

## Rust 是什么？

Rust 是一门系统编程语言，专注于**安全**、**并发**和**性能**。由 Mozilla 研究院开发，2015 年发布 1.0 版本。

## 核心设计哲学

Rust 的核心承诺：**不需要垃圾回收（GC）也能保证内存安全**。

| 特性 | 说明 |
|------|------|
| 内存安全 | 编译期检查，无段错误、无悬垂指针 |
| 零成本抽象 | 高级语法不产生运行时开销 |
|  fearless 并发 | 类型系统防止数据竞争 |
| 强大的类型系统 | 代数数据类型、trait 系统 |
| 宏系统 | 编译时代码生成 |

## 应用场景

- **系统编程** — 操作系统、驱动程序
- **WebAssembly** — 浏览器高性能计算
- **网络服务** — 高并发后端服务
- **嵌入式** — 微控制器、IoT 设备
- **区块链** — Solana、Polkadot 等公链
