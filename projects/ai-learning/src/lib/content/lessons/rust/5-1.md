# 结构体

## 什么是结构体？

结构体（struct）是将多个相关值组合在一起的自定义数据类型，类似 Python 的类（无方法）或 C 的结构体。

## 定义结构体

```rust
struct User {
    username: String,
    email: String,
    active: bool,
}
```

## 创建实例

```rust
let user1 = User {
    username: String::from("xiaoming"),
    email: String::from("xm@example.com"),
    active: true,
};
```

## 访问字段

```rust
println!("{}", user1.username);  // "xiaoming"

user1.email = String::from("new@example.com");  // 修改（需要 mut）
```

## 可变结构体

```rust
let mut user2 = User {
    username: String::from("xiaohong"),
    email: String::from("xh@example.com"),
    active: true,
};

user2.active = false;
```

## 结构体更新语法

```rust
let user3 = User {
    username: String::from("xiaogang"),
    ..user1  // 其余字段从 user1 复制
};
```

## 元组结构体

没有命名字段的简洁结构体：

```rust
struct Color(i32, i32, i32);

let black = Color(0, 0, 0);
```

## 练习任务

1. 定义 `Person` 结构体（name, age, city）
2. 创建 `Person` 实例并打印
3. 修改某个字段的值
4. 使用结构体更新语法创建新实例

## 知识点总结

- `struct` 定义自定义数据类型
- 字段默认私有，外部无法直接修改
- `mut` 使整个结构体可变
- `..instance` 更新语法

> 💡 提示：Rust 没有继承。通过 `impl` 块为结构体添加方法，通过 trait 实现代码复用。
