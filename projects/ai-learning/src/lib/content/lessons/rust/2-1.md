# 变量与可变性

## 变量声明

Rust 使用 `let` 关键字声明变量：

```rust
let x = 5;
```

## 不可变变量（默认）

Rust 的变量**默认不可变**：

```rust
let x = 5;
x = 10;  // 编译错误！不能修改不可变变量
```

这与许多其他语言不同，Rust 鼓励不可变性以增强安全性和并发性。

## 可变变量（mut 关键字）

使用 `mut` 关键字使变量可变：

```rust
let mut x = 5;
x = 10;  // OK！
```

## 遮蔽（Shadowing）

可以用同名新变量覆盖旧变量，甚至可以改变类型：

```rust
let x = 5;
let x = x + 1;     // x = 6
let x = "hello";   // x 从 int 变成 &str
```

遮蔽与 `mut` 的区别：
- 遮蔽可以改变类型
- 遮蔽是创建新变量（原变量在作用域内仍存在逻辑）
- `mut` 只是修改同一变量

## 常量

使用 `const` 声明常量，必须指定类型：

```rust
const MAX_POINTS: u32 = 100_000;
```

常量总是不可变，命名规范是大写下划线。

## 练习任务

1. 声明一个不可变变量，尝试修改，观察编译错误
2. 使用 `mut` 声明可变变量并修改
3. 演示遮蔽：声明整数，然后用字符串覆盖
4. 声明一个常量 `PI: f64 = 3.14159`

## 知识点总结

- `let` 声明变量，默认不可变
- `mut` 使变量可变
- 遮蔽（shadowing）允许同名新变量，可改类型
- `const` 声明编译期常量

> 💡 提示：Rust 默认不可变的设计是为了让编译器帮你发现意外的修改。只在需要时才用 `mut`。
