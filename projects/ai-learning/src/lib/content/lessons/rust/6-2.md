# 数据结构设计

## 枚举定义

使用枚举建模任务的优先级状态：

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum Priority {
    Low,
    Medium,
    High,
}

impl Priority {
    pub fn as_str(&self) -> &str {
        match self {
            Priority::Low => "low",
            Priority::Medium => "medium",
            Priority::High => "high",
        }
    }
}
```

## 结构体定义

```rust
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct Task {
    pub id: u32,
    pub title: String,
    pub priority: Priority,
    pub done: bool,
    pub created_at: String,
}
```

## Derive 宏

`#[derive(...)]` 让编译器自动实现常用 trait：

| 宏 | 用途 |
|----|------|
| `Debug` | 支持 `{:?}` 格式化打印 |
| `Clone` | 支持 `.clone()` 深拷贝 |
| `PartialEq` | 支持 `==` 比较 |
| `Serialize`/`Deserialize` | 支持 JSON 序列化 |

## 任务管理器

```rust
pub struct TodoList {
    pub tasks: Vec<Task>,
    pub next_id: u32,
}
```

## 实现方法

```rust
impl TodoList {
    pub fn new() -> Self {
        TodoList {
            tasks: Vec::new(),
            next_id: 1,
        }
    }

    pub fn add(&mut self, title: String, priority: Priority) -> &Task {
        let task = Task {
            id: self.next_id,
            title,
            priority,
            done: false,
            created_at: chrono::Local::now().format("%Y-%m-%d").to_string(),
        };
        self.next_id += 1;
        self.tasks.push(task);
        self.tasks.last().unwrap()
    }
}
```

## 练习任务

1. 定义 `Task` 结构体和 `Priority` 枚举
2. 为 `Priority` 实现 `as_str()` 方法
3. 实现 `TodoList::add()` 方法
4. 实现 `TodoList::complete()` 方法

## 知识点总结

- `enum` 建模有穷集合
- `struct` 组织数据
- `derive` 宏减少样板代码
- `impl` 块定义关联方法

> 💡 提示：Rust 的类型系统是其主要优势。好的类型设计能让非法状态无法表示。
