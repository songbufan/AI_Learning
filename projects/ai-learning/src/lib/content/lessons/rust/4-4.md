# 切片

## 什么是切片？

切片是对数组或字符串一部分的**引用**，不获取所有权。

## 字符串切片

```rust
let s = "Hello, Rust!";

let hello = &s[0..5];     // "Hello"
let rust = &s[7..11];     // "Rust"
```

### 完整切片

```rust
let slice = &s[..];       // 整个字符串
let from_start = &s[..5]; // 从开头到索引 4
let to_end = &s[7..];     // 从索引 7 到末尾
```

## 字符串字面量

字符串字面量就是切片：

```rust
let s: &str = "Hello";  // &str 是字符串切片类型
```

`&str` 是不可变引用，`String` 是堆上可变的字符串。

## String vs &str

| 类型 | 位置 | 可变性 | 用途 |
|------|------|--------|------|
| `String` | 堆 | 可变 | 构建/修改文本 |
| `&str` | 任意 | 不可变 | 函数参数、字面量 |

## 其他切片

```rust
let arr = [1, 2, 3, 4, 5];
let slice = &arr[1..3];  // [2, 3]
```

数组切片类型：`&[i32]`

## 练习任务

1. 声明 `String`，创建并打印字符串切片
2. 编写函数接受 `&str` 参数
3. 比较 `String` 和 `&str` 作为函数参数的区别
4. 尝试越界切片，观察 panic

## 知识点总结

- 切片是引用 `&[T]`，不获取所有权
- 字符串切片：`&str`
- `String` 可变，`&str` 不可变
- 字符串字面量是 `&'static str`

> 💡 提示：函数参数优先使用 `&str` 而不是 `String`，这样既接受字面量也接受 String 引用。
