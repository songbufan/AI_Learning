# if let 与 while let

## if let — 简化匹配

当只需要关心一种模式时，`if let` 是 `match` 的语法糖：

```rust
let value = Some(3);

// 冗长的写法
match value {
    Some(3) => println!("三"),
    _ => (),
}

// 简写
if let Some(3) = value {
    println!("三");
}
```

## if let else

```rust
let value = Some(6);

if let Some(x) = value {
    println!("值是: {}", x);  // 值是: 6
} else {
    println!("空值");
}
```

## while let — 条件循环

`while let` 循环直到模式不再匹配：

```rust
let mut stack = vec![1, 2, 3];

while let Some(top) = stack.pop() {
    println!("{}", top);
}
// 输出：3, 2, 1
```

## 实际应用场景

```rust
// 处理命令行参数
let args = ["program", "hello", "world"];
let mut iter = args.iter();

while let Some(arg) = iter.next() {
    println!("参数: {}", arg);
}
```

## 练习任务

1. 使用 `if let` 从 `Option<i32>` 中提取值
2. 使用 `while let` + `pop()` 弹出 Vec 中所有元素
3. 对比 `if let` 和 `match` 的适用场景
4. 用 `while let Some()` 模拟读取输入直到空

## 知识点总结

- `if let`：只处理一种模式的简化语法
- `while let`：模式匹配循环
- 两者都是 `match` 的语法糖
- 适合处理 `Option<T>` 和 `Result<T, E>`

> 💡 提示：选择 `if let` 还是 `match` 取决于是否需要穷尽性检查。`if let` 适合只关心一种情况的场景。
