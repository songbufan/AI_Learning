# 跨链桥与互操作

## 跨链桥的类型

跨链桥是连接不同区块链的协议，让资产和信息能在链间转移。

```python
print("=== 跨链桥类型 ===\n")

bridge_types = {
    "锁定-铸造 (Lock & Mint)": {
        "流程": "锁定 L1 资产 → L2 铸造等量映射资产",
        "赎回": "销毁 L2 映射资产 → L1 解锁原始资产",
        "风险": "L1 锁仓合约被攻击",
        "案例": "Polygon PoS Bridge",
    },
    "轻客户端桥": {
        "流程": "L2 维护 L1 轻客户端验证状态",
        "赎回": "无需信任第三方，数学验证",
        "风险": "验证逻辑复杂",
        "案例": "Cosmos IBC, Bitcoin SPV",
    },
    "原子交换 (Atomic Swap)": {
        "流程": "HTLC 实现跨链交换",
        "赎回": "双方在时限内提供哈希原像",
        "风险": "流动性分散",
        "案例": "闪电网络, THORChain",
    },
}

for name, info in bridge_types.items():
    print(f"【{name}】")
    for k, v in info.items():
        print(f"  {k}: {v}")
    print()
```

## 知识点总结

- 跨链桥 = 区块链互操作的核心
- 锁定-铸造最常用但中心化风险高
- 轻客户端桥最安全但实现复杂
