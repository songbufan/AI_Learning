# 比特币交易与 UTXO 模型

## UTXO（未花费输出）模型

比特币不跟踪"账户余额"，而是跟踪所有"未花费的交易输出"（Unspent Transaction Output）。

```python
# UTXO 模型演示
print("=== UTXO 模型 ===\n")

# 初始 UTXO 集
utxo_set = {
    "tx1:0": {"value": 50.0, "owner": "Alice", "script": "P2PKH"},
    "tx1:1": {"value": 30.0, "owner": "Bob",   "script": "P2PKH"},
}

print("当前 UTXO 集（可花费的输出）:")
for utxo, info in utxo_set.items():
    print(f"  {utxo}: {info['value']} BTC → {info['owner']}")

# Alice 创建一笔交易：转 20 BTC 给 Bob
print("\n=== Alice 创建交易 ===")
print("输入: tx1:0 (50 BTC, Alice)")
print("输出1: 20 BTC → Bob")
print("输出2: 29.99 BTC → Alice (找零，扣除 0.01 BTC 手续费)")

# 交易后的新 UTXO 集
new_utxo = {
    "tx1:1": {"value": 30.0, "owner": "Bob"},          # 未变
    "tx2:0": {"value": 20.0, "owner": "Bob"},          # 新输出
    "tx2:1": {"value": 29.99, "owner": "Alice"},       # 找零
}

print("\n新 UTXO 集:")
for utxo, info in new_utxo.items():
    print(f"  {utxo}: {info['value']} BTC → {info['owner']}")

print(f"\nAlice 余额变化: 50 → 29.99 BTC (发送 20, 手续费 0.01)")
print(f"Bob 余额变化: 30 → 50 BTC (收到 20)")
```

## 账户模型 vs UTXO 模型

```python
print("=== 两种模型对比 ===\n")

print("【UTXO 模型（比特币）】")
print("  优点:")
print("    并行处理交易（每个 UTXO 独立）")
print("    更好的隐私（地址可每次更换）")
print("    简单的交易验证")
print("  缺点:")
print("    智能合约复杂（无法直接实现账户逻辑）")
print("    存储开销大（UTXO 集持续增长）")

print("\n【账户模型（以太坊）】")
print("  优点:")
print("    直观（类似银行账户）")
print("    智能合约友好")
print("    存储高效")
print("  缺点:")
print("    需要处理 nonce（防止重放）")
print("    账户抽象复杂")
```

## 知识点总结

- UTXO：比特币的核心数据模型，每笔交易消耗 UTXO 并创建新 UTXO
- 账户模型：以太坊使用，直接跟踪每个地址的余额
- UTXO 集：网络中所有未花费输出的集合
- 找零输出：发送方自己接收剩余资金的输出
