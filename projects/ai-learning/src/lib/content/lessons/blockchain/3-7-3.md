# 闪电贷与套利

## 闪电贷 (Flash Loan)

闪电贷是 DeFi 最具创新性的产品之一：**无需抵押，在同一笔交易中借入和归还任意金额**。

```python
# 闪电贷原理
print("=== 闪电贷 (Flash Loan) ===\n")

print("核心特点:")
print("  1. 无需抵押 — 不需要任何保证金")
print("  2. 原子性 — 借和还在同一笔交易内完成")
print("  3. 手续费 — 通常 0.09%（比普通贷款低 100x）")
print("  4. 失败即回滚 — 还不上的话整笔交易撤销")

print("\n=== 闪电贷套利流程 ===")
steps = [
    "1. 从 Aave 闪电借入 1000 ETH",
    "2. 在 Uniswap (价格 $1800) 买入 ETH",
    "3. 在 SushiSwap (价格 $1810) 卖出 ETH",
    "4. 获利: 1000 × ($1810 - $1800) = $10,000",
    "5. 偿还 Aave 贷款 + 手续费 (1000.9 ETH)",
    "6. 净赚约 $9,000（全部在同一交易中完成）",
]
for step in steps:
    print(f"  {step}")

print("\n⚠️ 闪电贷也是攻击者常用工具")
print("    Cream Finance ($130M), bZx ($8M) 等都曾遭闪电贷攻击")
```

## 闪电贷攻击类型

```python
print("\n=== 闪电贷攻击类型 ===\n")

attack_types = [
    ("价格操控", "操控 DEX 价格池 → 影响依赖该价格的协议"),
    ("治理攻击", "借大量代币 → 投票通过恶意提案 → 归还"),
    ("清算套利", "利用清算机制的折扣价 → 低价买资产"),
]

for name, desc in attack_types:
    print(f"  {name}: {desc}")
```

## 知识点总结

- 闪电贷：无需抵押的原子性借贷
- 套利：利用不同市场的价格差异获利
- 原子性：交易成功则全部执行，失败则全部撤销
- 风险：闪电贷放大攻击能力
