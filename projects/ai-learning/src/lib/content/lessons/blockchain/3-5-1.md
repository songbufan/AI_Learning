# 比特币脚本与智能合约

## 比特币脚本系统

比特币使用一种基于栈的脚本语言（Script），用于定义花费比特币的条件。它是**非图灵完备**的（有意为之，出于安全考虑）。

```python
# 比特币脚本类型演示
print("=== 比特币脚本类型 ===\n")

script_types = [
    ("P2PKH (Pay-to-Public-Key-Hash)",
     "最常用",
     "OP_DUP OP_HASH160 <pubkey_hash> OP_EQUALVERIFY OP_CHECKSIG",
     "验证公钥哈希匹配 + 签名有效"),
    ("P2SH (Pay-to-Script-Hash)",
     "支持复杂条件",
     "OP_HASH160 <script_hash> OP_EQUAL",
     "redeemScript 可以定义任意解锁条件"),
    ("Multisig (多重签名)",
     "多签钱包",
     "OP_2 <pubkey1> <pubkey2> <pubkey3> OP_3 OP_CHECKMULTISIG",
     "需要 m/n 个签名才能花费"),
    ("Timelock (时间锁)",
     "时间条件",
     "OP_CHECKLOCKTIMEVERIFY OP_DROP ...",
     "指定时间后才能花费"),
]

for name, usage, script, desc in script_types:
    print(f"【{name}】")
    print(f"  用途: {usage}")
    print(f"  描述: {desc}")
    print(f"  脚本: {script}")
    print()
```

## P2PKH 交易验证流程

```python
# 模拟 P2PKH 验证过程
class Stack:
    def __init__(self):
        self.items = []
    
    def push(self, item):
        self.items.append(item)
    
    def pop(self):
        return self.items.pop() if self.items else None
    
    def peek(self):
        return self.items[-1] if self.items else None

print("=== P2PKH 验证流程 ===\n")

# 解锁脚本（提供者提供）
unlocking_script = ["<signature>", "<public_key>"]

# 锁定脚本（输出中定义）
locking_script = ["OP_DUP", "OP_HASH160", "<pubkey_hash>", "OP_EQUALVERIFY", "OP_CHECKSIG"]

print("步骤1: 将解锁脚本压入栈")
print(f"  输入: {unlocking_script}")

print("\n步骤2: 将锁定脚本压入栈")
print(f"  输入: {locking_script}")

print("\n步骤3-7: 逐条执行脚本")
print("  OP_DUP: 复制栈顶 → [pub_key, pub_key, pub_key_hash]")
print("  OP_HASH160: 对栈顶哈希 → [hash(pub_key), hash(pub_key), pub_key_hash]")
print("  OP_EQUALVERIFY: 比较两个哈希是否相等")
print("  OP_CHECKSIG: 验证签名是否对应该公钥")
print("  → True = 验证通过！")
```

## 知识点总结

- 比特币 Script：基于栈的、非图灵完备的脚本语言
- P2PKH：最常见的交易类型，公钥哈希支付
- P2SH：支付到脚本哈希，支持复杂条件
- 非图灵完备是安全设计：防止无限循环攻击
