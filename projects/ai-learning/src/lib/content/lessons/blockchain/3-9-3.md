# NFT 市场与版税

## NFT 交易市场

NFT 市场是 NFT 生态的核心基础设施，支持 mint、买卖和拍卖。

```python
print("=== NFT 交易市场 ===\n")

marketplaces = {
    "OpenSea": {"fee": "2.5%", "chain": "多链", "type": "链下撮合"},
    "Blur": {"fee": "0.5%", "chain": "以太坊", "type": "链上竞价"},
    "LooksRare": {"fee": "1.5%", "chain": "以太坊", "type": "社区驱动"},
}

print("主要 NFT 市场:")
for name, info in marketplaces.items():
    print(f"  {name}: 手续费 {info['fee']}, 链: {info['chain']}")
```

## EIP-2981 版税标准

```python
print("\n=== EIP-2981 版税标准 ===\n")

price = 100  # ETH
royalty_bps = 500  # 5%
royalty = price * royalty_bps / 10000
creator = price - royalty

print(f"售价: {price} ETH")
print(f"版税 (5%): {royalty} ETH → 创作者")
print(f"卖家收入: {creator} ETH")
```

## 知识点总结

- EIP-2981：版税通用标准
- 版税由市场在转售时自动支付
- 市场是否遵守版税是自愿的
- Blur 等平台可选是否支付版税
