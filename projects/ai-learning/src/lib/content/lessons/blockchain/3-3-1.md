# 共识问题与拜占庭容错

## 分布式共识的核心难题

在分布式系统中，多个节点需要就某个值达成一致。当存在可能作恶的节点时，这个问题变得极具挑战性。

```python
# 拜占庭将军问题（Byzantine Generals Problem）
import random

print("=== 拜占庭将军问题 ===\n")

# 模拟：5 个将军，2 个叛徒
generals = [
    {"name": "将军A", "loyal": True},
    {"name": "将军B", "loyal": True},
    {"name": "将军C", "loyal": True},
    {"name": "将军D", "loyal": False},  # 叛徒
    {"name": "将军E", "loyal": False},  # 叛徒
]

loyal_count = sum(1 for g in generals if g["loyal"])
traitor_count = len(generals) - loyal_count

print(f"总将军数: {len(generals)}")
print(f"忠诚: {loyal_count}, 叛徒: {traitor_count}")
print(f"BFT 条件: 忠诚 > 叛徒 → {loyal_count} > {traitor_count} = {loyal_count > traitor_count}")
```

## 拜占庭容错理论

```python
print("\n=== BFT 核心理论 ===\n")

print("Lamport 证明：")
print("  在异步网络中，要容忍 f 个叛徒，需要至少 3f+1 个总节点")
print("  n >= 3f + 1 → f <= (n-1) / 3")

# 计算不同规模下的最大容错数
for n in [4, 7, 10, 13, 20]:
    f_max = (n - 1) // 3
    print(f"  n={n} 节点 → 最多容忍 {f_max} 个叛徒 ({f_max/n*100:.0f}%)")
```

## 知识点总结

- 拜占庭容错 (BFT)：部分节点作恶时仍能达成一致
- 容错上限：⌊(n-1)/3⌋ 个叛徒
- 区块链共识：PoW → PoS → BFT 的演进
- 不同场景需要不同的共识机制
