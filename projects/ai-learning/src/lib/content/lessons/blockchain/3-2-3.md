# 数字签名

## 数字签名的三大作用

1. **身份认证** — 证明交易是谁发起的
2. **不可否认** — 发送者无法抵赖
3. **完整性** — 交易内容未被篡改

```python
import hashlib

class DigitalSignature:
    @staticmethod
    def sign(message, private_key):
        combined = message + private_key
        return hashlib.sha256(combined.encode()).hexdigest()[:16]

    @staticmethod
    def verify(message, signature, public_key):
        expected = hashlib.sha256((message + public_key).encode()).hexdigest()[:16]
        return signature == expected

# Alice 签名交易
alice_priv = "alice_secret_key"
alice_pub = "alice_public_key"
tx = "Alice -> Bob: 10 BTC"

sig = DigitalSignature.sign(tx, alice_priv)
print(f"签名: {sig}")
print(f"验证: {DigitalSignature.verify(tx, sig, alice_pub)}")
print(f"篡改验证: {DigitalSignature.verify('Alice -> Bob: 999', sig, alice_pub)}")
```

## 知识点总结

- 数字签名 = 私钥签名 + 公钥验签
- 比特币使用 ECDSA（secp256k1 曲线）
- 私钥 = 身份，必须保密
- 公钥 → 地址（SHA256 + RIPEMD160）
