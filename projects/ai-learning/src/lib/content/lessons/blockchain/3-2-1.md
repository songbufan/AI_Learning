# 哈希函数

## 什么是哈希函数？

哈希函数（Hash Function）是一种将任意长度输入转换为固定长度输出的数学函数。它是区块链的**密码学基石**。

## 核心特性

```python
# 哈希函数四大特性
print("=== SHA-256 哈希函数特性 ===\n")

features = [
    ("1. 确定性", "相同输入 → 永远相同输出"),
    ("2. 快速计算", "给定输入，快速计算出哈希值"),
    ("3. 雪崩效应", "输入微小变化 → 输出完全不同"),
    ("4. 不可逆", "从哈希值无法反推原始输入"),
    ("5. 抗碰撞", "很难找到两个不同输入产生相同哈希"),
]

for name, desc in features:
    print(f"{name}: {desc}")

# 演示雪崩效应
def simple_hash(text):
    """模拟哈希：每个字符的 ASCII 码累加取模"""
    return str(sum(ord(c) for c in text) % 256)

msg1 = "Hello, Blockchain!"
msg2 = "Hello, Blockchian!"  # 少了一个 'a'

print(f"\nhash('{msg1}') = {simple_hash(msg1)}")
print(f"hash('{msg2}') = {simple_hash(msg2)}")
print("一个字母之差，哈希值完全不同！")
```

## 在区块链中的应用

```python
# 模拟区块链中的哈希链
import hashlib

class Block:
    def __init__(self, data, prev_hash="0000"):
        self.data = data
        self.prev_hash = prev_hash
        self.nonce = 0
    
    def compute_hash(self):
        content = f"{self.data}{self.prev_hash}{self.nonce}"
        return hashlib.sha256(content.encode()).hexdigest()[:16]

# 创建链
b1 = Block("创世区块", "0000")
b1_hash = b1.compute_hash()
print(f"区块1: {b1_hash}")

b2 = Block("Alice -> Bob: 10", b1_hash)
b2_hash = b2.compute_hash()
print(f"区块2: {b2_hash}")

b3 = Block("Bob -> Carol: 5", b2_hash)
b3_hash = b3.compute_hash()
print(f"区块3: {b3_hash}")

print("\n篡改检测：修改区块2的数据")
b2.data = "Alice -> Bob: 999"
b2_new_hash = b2.compute_hash()
print(f"区块2新哈希: {b2_new_hash}（与之前不同！）")
print("后续所有区块的哈希链全部断裂 → 篡改被立即发现")
```

## 知识点总结

- 哈希函数：输入任意长度 → 输出固定长度摘要
- SHA-256：比特币/以太坊使用的哈希算法
- 雪崩效应：输入微小变化 → 输出完全不同
- 哈希链：每个区块包含前一个区块的哈希 → 不可篡改
