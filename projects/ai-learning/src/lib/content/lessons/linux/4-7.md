# 文件内容查看命令

## cat — 显示文件全部内容

`cat`（concatenate）将文件内容输出到终端。

```bash
cat file.txt               # 显示文件全部内容
cat file1 file2            # 同时显示多个文件
cat -n file.txt            # 显示行号
cat -b file.txt            # 显示行号（跳过空行）
```

### cat 的其他用途

```bash
# 合并文件
cat part1.txt part2.txt > combined.txt

# 创建文件（通过重定向）
cat > newfile.txt          # 输入内容，Ctrl+D 结束

# 追加内容到文件
cat >> existing.txt        # 追加模式（>>）
```

## less — 分页查看

`less` 是最强大的文件查看工具，适合查看大文件。

```bash
less file.txt              # 打开文件进行分页查看
less +/keyword file.txt    # 打开后直接搜索 keyword
```

### less 操作快捷键

| 按键 | 功能 |
|------|------|
| `↑` / `↓` / `j` / `k` | 上下滚动一行 |
| `PgUp` / `PgDn` / `Space` | 上下翻页 |
| `g` / `G` | 跳到文件开头/结尾 |
| `/pattern` | 向下搜索 |
| `?pattern` | 向上搜索 |
| `n` / `N` | 下一个/上一个匹配 |
| `q` | 退出 |
| `F` | 实时跟踪（同 tail -f） |

## head — 查看文件开头

`head` 显示文件的前 N 行（默认 10 行）。

```bash
head file.txt              # 查看前 10 行
head -n 20 file.txt        # 查看前 20 行
head -5 file.txt            # 简写：查看前 5 行
```

## tail — 查看文件末尾

`tail` 显示文件的最后 N 行，非常适合查看日志。

```bash
tail file.txt              # 查看最后 10 行
tail -n 20 file.txt        # 查看最后 20 行
tail -f logfile.txt        # 实时跟踪文件变化（follow）
tail -F logfile.txt        # 跟踪文件，即使被轮转也继续
```

### tail -f 的用途

`tail -f` 是查看日志的必备命令：

```bash
# 实时监控系统日志
tail -f /var/log/syslog

# 实时监控 Nginx 访问日志
tail -f /var/log/nginx/access.log
```

## 输出重定向

```bash
command > file.txt         # 覆盖写入（stdout）
command >> file.txt        # 追加写入（stdout）
command 2> file.txt        # 错误输出单独保存（stderr）
command > file.txt 2>&1    # stdout 和 stderr 合并
```

## 管道

管道 `|` 将一个命令的输出作为另一个命令的输入：

```bash
ls -la | grep ".txt"       # 列出 .txt 文件
cat file.txt | wc -l       # 统计文件行数
cat file.txt | sort        # 对文件内容排序
cat file.txt | grep -i "error" | head -20  # 搜索错误并显示前20行
```

## 练习任务

1. 创建一个包含 20 行的文本文件 `practice.txt`
2. 用 `cat practice.txt` 查看全部内容
3. 用 `head -5 practice.txt` 查看前 5 行
4. 用 `tail -5 practice.txt` 查看后 5 行
5. 用 `less practice.txt` 分页查看，练习搜索（`/keyword`）
6. 用 `cat -n practice.txt | head -10` 查看前 10 行（含行号）

## 知识点总结

- `cat` 显示全部内容，适合小文件
- `less` 分页查看大文件，功能最强大
- `head`/`tail` 查看文件首尾，`tail -f` 实时跟踪日志
- `|` 管道连接命令，实现数据流处理
- 重定向 `>` 覆盖写入，`>>` 追加写入

> 💡 提示：`less` 比 `more` 更强大（支持上下滚动），是查看大文件的首选工具。记住 `man less` 查看更多快捷键。
