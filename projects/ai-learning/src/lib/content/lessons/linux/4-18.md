# 服务器部署实战

## 部署流程概述

一个完整的服务器部署流程包含以下步骤：

```
系统初始化 → 环境配置 → 应用部署 → 服务管理 → 监控运维
```

## 步骤 1：系统初始化

### 更新系统

```bash
sudo apt update                    # 更新软件源
sudo apt upgrade -y                # 升级已安装的软件包
sudo apt install -y curl vim git   # 安装基础工具
```

### 创建部署用户

```bash
# 创建专用部署用户
sudo useradd -m -s /bin/bash deploy

# 设置密码
sudo passwd deploy

# 添加 sudo 权限
sudo usermod -aG sudo deploy
```

### 配置防火墙

```bash
# Ubuntu 使用 ufw
sudo ufw allow 22/tcp              # SSH
sudo ufw allow 80/tcp              # HTTP
sudo ufw allow 443/tcp             # HTTPS
sudo ufw enable                    # 启用防火墙
sudo ufw status                    # 查看状态
```

## 步骤 2：安装运行环境

### 安装 Nginx

```bash
sudo apt install nginx -y
sudo systemctl enable nginx        # 设置开机自启
sudo systemctl start nginx         # 启动服务
curl http://localhost               # 测试 Nginx 是否运行
```

### 安装 Node.js

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs -y
node --version
```

### 安装 Python

```bash
sudo apt install python3 python3-pip python3-venv -y
python3 --version
```

## 步骤 3：部署应用

```bash
# 1. 克隆代码
git clone https://github.com/user/app.git /var/www/app
cd /var/www/app

# 2. 安装依赖
npm install

# 3. 环境配置
cp .env.example .env
nano .env                          # 编辑环境变量

# 4. 构建
npm run build
```

## 步骤 4：配置 Nginx 反向代理

```bash
sudo nano /etc/nginx/sites-available/app
```

```nginx
server {
    listen 80;
    server_name yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/app /etc/nginx/sites-enabled/
sudo nginx -t                       # 测试配置
sudo systemctl reload nginx         # 重载 Nginx
```

## 步骤 5：Systemd 服务

```bash
sudo nano /etc/systemd/system/app.service
```

```ini
[Unit]
Description=My App
After=network.target

[Service]
Type=simple
User=deploy
WorkingDirectory=/var/www/app
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable app.service
sudo systemctl start app.service
sudo systemctl status app.service
```

## 步骤 6：SSL 证书

```bash
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d yourdomain.com
# 自动配置 HTTPS 并设置证书自动续期
```

## 步骤 7：监控与日志

```bash
# 查看服务日志
sudo journalctl -u app.service -f

# 查看 Nginx 日志
tail -f /var/log/nginx/access.log
tail -f /var/log/nginx/error.log

# 系统资源
htop                    # 进程监控
df -h                   # 磁盘使用
free -h                 # 内存使用
```

## 自动化部署脚本

```bash
#!/bin/bash
# deploy.sh

cd /var/www/app
git pull origin main
npm install
npm run build
sudo systemctl restart app.service
sleep 3
sudo systemctl status app.service
```

## 知识点总结

- 部署流程：系统初始化 → 环境配置 → 应用部署 → 反向代理 → 服务管理
- Systemd 管理后台服务进程
- Nginx 作为反向代理，将外部请求转发到应用
- Let's Encrypt 提供免费的自动化 SSL 证书
- 自动化脚本提升部署效率

> 💡 提示：生产环境部署还应包括：日志轮转（logrotate）、监控告警、备份策略、CI/CD 流水线。建议进一步学习 Docker 容器化部署来简化环境管理。
