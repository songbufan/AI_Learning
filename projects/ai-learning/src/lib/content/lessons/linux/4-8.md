# 文件搜索命令

## find — 按条件搜索文件

`find` 是最强大的文件搜索工具，可以按名称、大小、时间、类型等条件搜索。

```bash
find . -name '*.txt'       # 当前目录递归查找所有 .txt 文件
find /home -size +10M      # 查找大于 10MB 的文件
find . -mtime -7           # 查找 7 天内修改的文件
find . -type f             # 只查找文件（排除目录）
find . -user alice         # 查找 alice 用户的文件
find . -perm 755           # 查找权限为 755 的文件
find . -name '*.log' -delete  # 查找并删除匹配文件
```

### find 常用条件

| 条件 | 含义 |
|------|------|
| `-name 'pattern'` | 按文件名匹配 |
| `-iname 'pattern'` | 忽略大小写匹配 |
| `-size +10M` | 大于 10MB（+大于，-小于） |
| `-mtime -7` | 7 天内修改过 |
| `-type f` | 文件（d=目录, l=链接） |
| `-perm 755` | 权限匹配 |
| `-user alice` | 属主匹配 |

## grep — 在文件中搜索文本

`grep`（Global Regular Expression Print）搜索文件内容中的文本模式。

```bash
grep "pattern" file.txt              # 搜索包含 pattern 的行
grep -i "pattern" file.txt           # 忽略大小写
grep -n "pattern" file.txt           # 显示匹配行的行号
grep -c "pattern" file.txt           # 统计匹配行数
grep -v "pattern" file.txt           # 反向搜索（显示不包含 pattern 的行）
grep -r "pattern" /path/to/dir/      # 递归搜索目录
```

### 正则表达式

```bash
grep "^hello" file.txt     # 以 hello 开头的行（^ 表示行首）
grep "end$" file.txt       # 以 end 结尾的行（$ 表示行尾）
grep "^$" file.txt         # 匹配空行
grep "[0-9]" file.txt      # 包含数字的行
grep -E "[0-9]{3}" file   # 包含3个连续数字（-E 扩展正则）
```

## locate — 快速文件名搜索

`locate` 通过预建的数据库快速查找文件：

```bash
locate filename           # 快速查找文件名
locate '*.txt'            # 查找所有 .txt 文件
locate -i filename        # 忽略大小写
```

> 注意：`locate` 的数据库可能不是最新的，使用前可以先运行 `updatedb` 更新。

## which 与 whereis

```bash
which python3             # 查找命令的路径（在 PATH 中）
whereis python3           # 查找命令的二进制、源码、手册位置
type python3              # 显示命令类型（别名/函数/内置/外部）
```

## 综合示例

```bash
# 查找大文件
find / -size +100M 2>/dev/null

# 在日志中搜索错误
grep -i "error" /var/log/syslog | tail -20

# 查找并统计
find . -name '*.py' | xargs wc -l
```

## 练习任务

1. 使用 `find /tmp -name "*.txt"` 查找 /tmp 下的所有 .txt 文件
2. 使用 `find . -size +1M` 查找大于 1MB 的文件
3. 创建一个包含多行文本的文件，用 `grep` 搜索特定关键词
4. 使用 `grep -n` 显示匹配行的行号
5. 使用 `locate` 查找系统中的一个配置文件
6. 用 `which` 查找常用命令的路径（`which python3`, `which git`）

## 知识点总结

- `find` 功能最强大，支持多种搜索条件，但较慢
- `grep` 搜索文件内容，支持正则表达式
- `locate` 最快，但依赖数据库（可能不是最新的）
- `which` 查找命令路径，`whereis` 查找命令的所有相关信息

> 💡 提示：日常使用中，`find` 最灵活，`grep` 最常用。`locate` 适合快速定位文件名。组合使用如 `find . -name '*.log' | xargs grep 'error'` 可以同时按文件名和内容搜索。
