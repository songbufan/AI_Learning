# SSH 远程连接与安全

## 什么是 SSH

**SSH（Secure Shell）** 是一种加密的网络协议，用于安全地远程登录和管理服务器。

```bash
# 基本 SSH 连接
ssh user@host                    # 通过用户名和主机名连接
ssh user@192.168.1.100           # 通过 IP 地址连接
ssh -p 2222 user@host            # 指定非默认端口连接
```

## SSH 密钥认证

密码认证方式容易被暴力破解，**密钥认证**是更安全的方式。

### 生成密钥对

```bash
# 生成 Ed25519 密钥对（推荐）
ssh-keygen -t ed25519 -C "your@email.com"

# 生成 RSA 密钥对（兼容性好但较慢）
ssh-keygen -t rsa -b 4096 -C "your@email.com"
```

生成的密钥文件：
- 私钥：`~/.ssh/id_ed25519`（⚠️ 绝对不能泄露）
- 公钥：`~/.ssh/id_ed25519.pub`（可以公开）

### 复制公钥到远程服务器

```bash
# 方法1：使用 ssh-copy-id（推荐）
ssh-copy-id user@remote_host

# 方法2：手动复制
cat ~/.ssh/id_ed25519.pub | ssh user@host \
    "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

### 验证免密登录

```bash
ssh user@remote_host    # 首次连接可能需要确认指纹
# 如果配置正确，无需输入密码即可登录
```

## SCP — 安全文件传输

`scp`（secure copy）通过 SSH 加密传输文件。

```bash
# 上传文件到远程
scp file.txt user@host:/remote/path/

# 从远程下载文件
scp user@host:/remote/path/file.txt ./

# 上传目录
scp -r local_dir/ user@host:/remote/path/

# 指定端口
scp -P 2222 file.txt user@host:/path/
```

## SSH 配置文件

在 `~/.ssh/config` 中配置常用服务器：

```bash
# ~/.ssh/config
Host myserver
    HostName 192.168.1.100
    User deploy
    Port 22
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60

Host github
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519
```

配置后简写连接：
```bash
ssh myserver                    # 代替 ssh deploy@192.168.1.100
scp file.txt myserver:/path/    # 上传到配置的服务器
```

## 安全最佳实践

```bash
# 1. 禁用 root 远程登录
# 编辑 /etc/ssh/sshd_config：
# PermitRootLogin no

# 2. 禁用密码认证（仅使用密钥）
# PasswordAuthentication no

# 3. 修改默认端口
# Port 2222

# 4. 使用 fail2ban 防止暴力破解
sudo apt install fail2ban
```

## SSH 代理

```bash
# 避免重复输入密钥密码
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

# 查看已添加的密钥
ssh-add -l

# 删除密钥
ssh-add -d ~/.ssh/id_ed25519
```

## 练习任务

1. 检查是否有 SSH 密钥：`ls ~/.ssh/`
2. 如果没有密钥，生成一个：`ssh-keygen -t ed25519`
3. 将公钥复制到测试服务器：`ssh-copy-id user@host`
4. 配置 `~/.ssh/config` 添加常用服务器
5. 使用 SCP 上传和下载文件测试
6. 使用 `ssh user@host "hostname && whoami"` 远程执行单条命令

## 知识点总结

- SSH 提供安全的远程 Shell 访问和文件传输
- 密钥认证比密码更安全，推荐使用 Ed25519 类型
- SCP 通过 SSH 加密传输文件
- `~/.ssh/config` 简化常用服务器的连接配置
- 禁用 root 远程登录和使用 fail2ban 是 SSH 安全加固的基础

> 💡 提示：使用 `ssh-copy-id` 一键部署公钥是最方便的方式。记得为密钥设置密码短语（passphrase）增加额外保护。
