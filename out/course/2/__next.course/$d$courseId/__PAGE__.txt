3:T1102,# AI Agent 概述

## 课程简介

AI Agent（人工智能代理）是当前人工智能领域最热门的方向之一。与传统的聊天机器人不同，Agent 能够自主感知环境、做出决策、执行行动，并从中学习。本课时将带你了解 Agent 的核心概念、发展历程和分类方式。

## 什么是 AI Agent

AI Agent 是一个能够**自主行动**以达成目标的软件系统。它的核心特征包括：

| 特征 | 说明 |
|------|------|
| **自主性** | 无需人类逐步指令，可自主决策 |
| **感知能力** | 通过传感器或 API 获取环境信息 |
| **行动能力** | 执行具体操作（调用 API、生成内容等） |
| **目标导向** | 围绕特定目标进行规划和执行 |

## Agent 的核心组件

一个典型的 AI Agent 由以下四个核心组件构成：

### 1. 大语言模型（LLM）

LLM 是 Agent 的"大脑"，负责：
- 理解用户意图
- 生成推理过程
- 做出决策
- 生成自然语言回复

### 2. 规划（Planning）

规划能力让 Agent 能够将复杂任务分解为可执行的子任务：

```
用户请求："帮我策划一次去日本的旅行"

Agent 规划：
  1. 查询日本热门旅游景点
  2. 查询机票价格和航班信息
  3. 查询酒店推荐
  4. 整理行程建议
  5. 生成旅行计划文档
```

### 3. 记忆（Memory）

记忆系统让 Agent 能够：
- **短期记忆**：记住当前对话的上下文
- **长期记忆**：持久化用户偏好和历史信息
- **工作记忆**：在复杂任务中跟踪中间状态

### 4. 工具使用（Tool Use）

工具使用让 Agent 超越纯文本生成：

```python
# Agent 可以调用的工具示例
tools = [
    {"name": "search_web", "description": "搜索互联网"},
    {"name": "calculator", "description": "执行数学计算"},
    {"name": "send_email", "description": "发送邮件"},
    {"name": "query_database", "description": "查询数据库"},
]
```

## Agent 的分类

### 按自主程度分类

| 类型 | 自主程度 | 示例 |
|------|----------|------|
| 反射 Agent | 低 | 简单规则引擎 |
| 基于模型 Agent | 中 | 保留内部世界模型 |
| 目标导向 Agent | 高 | 有明确目标和规划能力 |
| 效用 Agent | 最高 | 基于效用函数做最优决策 |

### 按架构分类

| 架构 | 特点 | 代表 |
|------|------|------|
| ReAct | 推理与行动交替 | LangChain ReAct Agent |
| Plan-and-Execute | 先规划后执行 | Plan-and-Solve |
| MRKL | 模块化专家系统 | Google MRKL |
| BabyAGI | 递归任务分解 | BabyAGI、AutoGPT |

## Agent 的发展历程

```
2022 年之前：规则引擎 + 传统 NLP
     |
2022 年：ChatGPT 发布 → LLM 能力突破
     |
2023 年：LangChain 发布 → Agent 框架成熟
     |
2024 年：AutoGPT、CrewAI → 多 Agent 协作
     |
2025 年：Manus、OpenAI Operator → 计算机控制 Agent
```

## 代码示例：最简单的 Agent

```python
# 一个最简单的反射型 Agent
class SimpleAgent:
    def __init__(self, llm):
        self.llm = llm
        self.memory = []

    def perceive(self, user_input):
        """感知用户输入"""
        self.memory.append({"role": "user", "content": user_input})
        return user_input

    def think(self, user_input):
        """思考：使用 LLM 生成响应"""
        context = self._build_context()
        response = self.llm.generate(context + "\nAssistant:")
        return response

    def act(self, response):
        """行动：输出响应并更新记忆"""
        self.memory.append({"role": "assistant", "content": response})
        return response

    def run(self, user_input):
        perception = self.perceive(user_input)
        thought = self.think(perception)
        action = self.act(thought)
        return action
```

5:T109d,# LLM 基础与 Prompt Engineering

## 课程简介

大语言模型（LLM）是 AI Agent 的"大脑"。本课时将深入了解 LLM 的工作原理，并学习如何通过 Prompt Engineering（提示工程）引导 LLM 产出高质量的回答。

## 大语言模型基础

### Transformer 架构

现代 LLM 基于 Transformer 架构，核心组件包括：

```
输入文本 → Tokenization → Embedding → Transformer Blocks → Output Probabilities → 生成文本
```

### Token 的概念

LLM 处理文本的基本单位是 Token：

| 文本 | Token 数量 | 说明 |
|------|-----------|------|
| "Hello" | 1 | 英文单词通常对应 1 个 Token |
| "你好世界" | 4 | 中文字通常每个字对应 1-2 个 Token |
| "PyTorch" | 1-2 | 常见词通常是 1 个 Token |

### 上下文窗口

上下文窗口决定了 LLM 能"看到"多少内容：

```
GPT-4:      128K tokens (~300 页文本)
Claude:     200K tokens (~500 页文本)
Gemini:     1M tokens (~3000 页文本)
```

## Prompt Engineering 核心技巧

### 1. 角色设定

给 LLM 分配一个明确的角色：

```python
# 不好的 Prompt
"解释 Python"

# 好的 Prompt
"你是一位拥有 10 年教学经验的 Python 讲师。
请用通俗易懂的语言向初学者解释 Python 的列表推导式，
并提供 3 个由浅入深的代码示例。"
```

### 2. 任务分解

将复杂任务拆分为清晰的步骤：

```python
# 不好的 Prompt
"帮我做一个网站"

# 好的 Prompt
"请帮我规划一个个人博客网站，分三个步骤：
1. 列出需要实现的功能清单
2. 推荐合适的技术栈
3. 给出项目目录结构建议"
```

### 3. 提供示例（Few-shot）

让 LLM 通过示例理解期望的输出格式：

```python
# 不好的 Prompt
"把下面的句子翻译成英文"

# 好的 Prompt（Few-shot）
"将中文句子翻译成英文：

示例 1：
中文：今天天气真好
英文：The weather is really nice today.

示例 2：
中文：我喜欢学习编程
英文：I love learning programming.

现在请翻译：
中文：人工智能正在改变世界
英文："
```

### 4. 输出格式控制

明确指定输出的格式和结构：

```python
prompt = """
分析以下 Python 代码，按以下 JSON 格式输出：

{
    "language": "语言名称",
    "lines_of_code": 行数,
    "functions": ["函数1", "函数2"],
    "complexity": "低/中/高",
    "suggestions": ["建议1", "建议2"]
}

代码：
```python
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
```
"""
```

## 代码示例：Prompt 模板化

```python
# 构建可复用的 Prompt 模板
class PromptTemplate:
    def __init__(self, template):
        self.template = template

    def format(self, **kwargs):
        return self.template.format(**kwargs)

# 定义模板
code_review_template = PromptTemplate("""
你是一位资深 Python 开发者。请 review 以下代码：

代码：
```python
{code}
```

请从以下维度给出反馈：
1. 代码风格（PEP 8 合规性）
2. 潜在 Bug
3. 性能优化建议
4. 可读性改进

请用中文回答。
""")

# 使用模板
prompt = code_review_template.format(code="""
def calc(a, b):
    return a+b
""")
```

## 常见的 Prompt 模式

| 模式 | 用途 | 示例 |
|------|------|------|
| 零样本（Zero-shot） | 简单任务 | "翻译这句话：你好" |
| 少样本（Few-shot） | 需要特定格式 | 提供 2-3 个示例 |
| 思维链（CoT） | 推理任务 | "让我们一步一步思考" |
| 自我一致性 | 提高准确率 | 多次生成，取多数答案 |
| 角色扮演 | 专业领域 | "你是一位医生..." |

## 知识点总结

- LLM 通过 Token 序列预测来生成文本
- Prompt Engineering 的核心：角色、任务、示例、格式
- 好的 Prompt = 清晰的角色 + 具体的任务 + 明确的输出格式
- 善用模板化，提高 Prompt 复用性

> 提示：Prompt Engineering 的本质是"与 LLM 的沟通艺术"——越具体、越结构化，结果越可预期。
6:T189a,# ReAct 推理框架

## 课程简介

ReAct（Reasoning + Acting）是由 Google 在 2022 年提出的 Agent 推理框架。它的核心思想是让大语言模型交替进行**推理（Thought）**和**行动（Action）**，而不是像传统 Chain-of-Thought 那样只做推理，或者像传统 Agent 那样只做行动。

## ReAct 的核心思想

```
传统 CoT（仅推理）：
  Question → Thought → Thought → Answer

传统 Agent（仅行动）：
  Question → Action → Observation → Action → Answer

ReAct（推理 + 行动交替）：
  Question → Thought → Action → Observation → Thought → Action → Observation → Answer
```

## ReAct 的工作流程

以"巴黎的法国大革命开始于哪一年？"为例：

```
Step 1:
  Thought: 我需要查找法国大革命开始的年份
  Action: Search["法国大革命开始年份"]
  Observation: 法国大革命通常被认为开始于 1789 年

Step 2:
  Thought: 已获得答案，验证一下准确性
  Action: Finish[1789]
```

## ReAct 的 Prompt 模板

```python
REACT_PROMPT = """
你是一个智能助手，可以思考和行动。

每次回复包含以下部分：
1. Thought: 你的思考过程
2. Action: 要执行的操作（搜索/计算/查询等）
3. Action Input: 操作所需的输入
4. Observation: 观察到的结果（由系统提供）
5. 当你有足够信息时输出：Final Answer: [你的答案]

可用工具：
- Search[query]: 搜索互联网获取信息
- Calculator[expr]: 执行数学计算
- Lookup[key]: 从知识库中查找信息

问题：{question}

让我们开始：
"""
```

## 代码示例：实现一个 ReAct Agent

```python
import re
import json

class ReActAgent:
    """基于 ReAct 框架的简单 Agent"""

    def __init__(self, llm, tools):
        self.llm = llm
        self.tools = {tool["name"]: tool for tool in tools}
        self.max_steps = 5

    def _parse_output(self, text):
        """解析 LLM 输出，提取 Thought、Action、Action Input"""
        thought_match = re.search(r"Thought: (.+)", text)
        action_match = re.search(r"Action: (.+)", text)
        input_match = re.search(r"Action Input: (.+)", text)
        answer_match = re.search(r"Final Answer: (.+)", text)

        return {
            "thought": thought_match.group(1) if thought_match else None,
            "action": action_match.group(1) if action_match else None,
            "action_input": input_match.group(1) if input_match else None,
            "answer": answer_match.group(1) if answer_match else None,
        }

    def _execute_action(self, action_name, action_input):
        """执行工具调用"""
        if action_name not in self.tools:
            return f"错误：未知工具 {action_name}"

        tool = self.tools[action_name]
        if tool["type"] == "search":
            return f"搜索结果：{action_input} 的相关信息..."
        elif tool["type"] == "calculator":
            try:
                result = eval(action_input)
                return f"计算结果：{result}"
            except:
                return "计算错误：无效的表达式"
        elif tool["type"] == "lookup":
            knowledge = {
                "法国大革命": "1789 年开始",
                "美国独立": "1776 年",
                "工业革命": "18 世纪 60 年代",
            }
            return knowledge.get(action_input, "知识库中未找到该信息")

        return "未知工具类型"

    def run(self, question):
        """运行 ReAct 循环"""
        prompt = f"""你是一个智能助手，可以思考和行动。

可用工具：Search, Calculator, Lookup

问题：{question}

让我们开始一步一步思考："""

        for step in range(self.max_steps):
            response = self.llm.generate(prompt + f"\n\nStep {step + 1}:\nThought:")
            parsed = self._parse_output(response)

            if parsed["answer"]:
                return parsed["answer"]

            if parsed["action"] and parsed["action_input"]:
                observation = self._execute_action(
                    parsed["action"].strip(),
                    parsed["action_input"].strip()
                )
                prompt += f"\nThought: {parsed['thought']}\n"
                prompt += f"Action: {parsed['action']}\n"
                prompt += f"Action Input: {parsed['action_input']}\n"
                prompt += f"Observation: {observation}\n"

        return "达到最大步数，未能得出结论"


# 使用示例
tools = [
    {"name": "Search", "type": "search", "description": "搜索互联网"},
    {"name": "Calculator", "type": "calculator", "description": "数学计算"},
    {"name": "Lookup", "type": "lookup", "description": "知识库查询"},
]

# agent = ReActAgent(llm=your_llm, tools=tools)
# answer = agent.run("法国大革命开始于哪一年？")
```

## ReAct vs 其他框架对比

| 框架 | 推理方式 | 行动方式 | 适用场景 |
|------|----------|----------|----------|
| **ReAct** | Thought + Action 交替 | 工具调用 | 通用任务 |
| CoT | 连续推理 | 无 | 数学/逻辑推理 |
| ToT | 多路径探索 | 无 | 复杂规划问题 |
| Reflexion | 推理 + 自我反思 | 工具调用 | 需要迭代改进的任务 |

## ReAct 的优缺点

### 优点
- **可解释性强**：Thought 过程透明可见
- **纠错能力**：通过 Observation 发现错误并修正
- **灵活性强**：支持任意工具组合

### 缺点
- **消耗 Token 多**：Thought + Action + Observation 三段式输出
- **不稳定**：LLM 可能不遵循格式要求
- **速度慢**：多步推理增加响应时间

## 课程简介

工具使用（Tool Use）是 AI Agent 超越纯文本生成的关键能力。通过 Function Calling，LLM 可以输出结构化的工具调用请求，让 Agent 具备与外部世界交互的能力——查询数据库、发送邮件、操作 API 等。

## 什么是 Function Calling

Function Calling 是 LLM 提供商（OpenAI、Anthropic 等）提供的一种能力，允许开发者：

1. **定义工具**：向 LLM 描述可用工具的参数和用途
2. **自动选择**：LLM 根据用户请求自动判断是否需要调用工具
3. **生成参数**：LLM 自动提取调用所需的参数
4. **执行调用**：开发者代码执行工具，返回结果给 LLM

## 完整的 Function Calling 流程

```python
import json

class FunctionCallingAgent:
    """支持 Function Calling 的 Agent"""

    def __init__(self, llm_client, tools):
        self.llm = llm_client
        self.tools = {t["name"]: t for t in tools}

    def call_llm(self, messages):
        """调用 LLM API"""
        response = self.llm.chat.completions.create(
            model="gpt-4",
            messages=messages,
            tools=self._format_tools(),
            tool_choice="auto",
        )
        return response.choices[0].message

    def _format_tools(self):
        """格式化工具定义"""
        return [
            {
                "type": "function",
                "function": {
                    "name": tool["name"],
                    "description": tool["description"],
                    "parameters": tool["parameters"],
                }
            }
            for tool in self.tools.values()
        ]

    def execute_tool(self, tool_call):
        """执行工具调用"""
        func_name = tool_call.function.name
        func_args = json.loads(tool_call.function.arguments)

        if func_name not in self.tools:
            return f"错误：未知工具 {func_name}"

        if func_name == "get_weather":
            return self._get_weather(func_args["city"], func_args.get("unit", "celsius"))
        elif func_name == "search_web":
            return self._search_web(func_args["query"])
        elif func_name == "send_email":
            return self._send_email(func_args["to"], func_args["subject"], func_args["body"])

        return "未知工具"

    def run(self, user_message):
        """运行 Agent 循环"""
        messages = [{"role": "user", "content": user_message}]

        while True:
            response = self.call_llm(messages)
            messages.append(response)

            if not response.tool_calls:
                return response.content

            for tool_call in response.tool_calls:
                result = self.execute_tool(tool_call)
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": result,
                })

            continue
```

### 记忆检索（Retrieval）

从长期记忆中检索相关信息：

```python
class MemoryRetriever:
    """基于关键词的简单记忆检索"""

    def __init__(self, memory_store):
        self.store = memory_store

    def search(self, query, top_k=3):
        """根据查询检索相关记忆"""
        results = []
        for key, value in self.store.items():
            score = self._similarity(query, str(value))
            if score > 0.3:
                results.append({"key": key, "value": value, "score": score})

        results.sort(key=lambda x: x["score"], reverse=True)
        return results[:top_k]

    def _similarity(self, query, text):
        """简单的关键词匹配相似度"""
        query_words = set(query.lower().split())
        text_words = set(text.lower().split())
        if not query_words:
            return 0
        return len(query_words & text_words) / len(query_words)
```

### 记忆遗忘（Forgetting）

```python
def forget_old_memories(memory, days_to_keep=30):
    """清理过期的短期记忆"""
    cutoff = datetime.now() - timedelta(days=days_to_keep)
    memory["short_term"] = [
        msg for msg in memory["short_term"]
        if datetime.fromisoformat(msg.get("timestamp", "")) > cutoff
    ]
    return memory
```

## 课程简介

RAG（Retrieval-Augmented Generation，检索增强生成）是当前 AI Agent 最核心的技术之一。它通过从外部知识库中检索相关信息，增强 LLM 的回答质量和时效性。本课时将深入学习 RAG 的原理、架构和实现方法。

## 为什么需要 RAG

### LLM 的固有局限

| 问题 | 说明 | RAG 解决方案 |
|------|------|-------------|
| 知识截止 | 训练数据有截止日期 | 检索最新的文档 |
| 幻觉问题 | LLM 可能生成不准确的信息 | 基于检索到的原文回答 |
| 领域知识 | 通用 LLM 缺乏专业知识 | 注入领域文档 |
| 隐私数据 | 不能将敏感数据用于训练 | 仅检索不暴露原始数据 |

## 代码示例：完整 RAG 实现

```python
from typing import List, Dict
import numpy as np

class SimpleRAG:
    """简化版 RAG 系统"""

    def __init__(self, embedding_dim=128):
        self.documents = []      # 文档库
        self.embeddings = []     # 文档向量
        self.embedding_dim = embedding_dim

    def add_documents(self, docs: List[str]):
        """添加文档到知识库"""
        for doc in docs:
            self.documents.append(doc)
            embedding = self._simple_embed(doc)
            self.embeddings.append(embedding)

    def _simple_embed(self, text: str) -> List[float]:
        """简单的词袋模型嵌入（生产环境应使用 sentence-transformers）"""
        # 基于字符频率的简单嵌入
        vocab = {}
        for char in set(text):
            vocab[char] = text.count(char) / len(text)

        embedding = [0.0] * self.embedding_dim
        for i, char in enumerate(sorted(vocab.keys())):
            if i < self.embedding_dim:
                embedding[i] = vocab[char]
        return embedding

    def _cosine_similarity(self, a, b):
        """计算余弦相似度"""
        a, b = np.array(a), np.array(b)
        return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

    def retrieve(self, query: str, top_k: int = 3) -> List[Dict]:
        """检索最相关的文档片段"""
        query_embedding = self._simple_embed(query)

        scores = []
        for i, doc_embedding in enumerate(self.embeddings):
            score = self._cosine_similarity(query_embedding, doc_embedding)
            scores.append({
                "index": i,
                "score": score,
                "content": self.documents[i],
            })

        scores.sort(key=lambda x: x["score"], reverse=True)
        return scores[:top_k]

    def generate_response(self, query: str, llm) -> str:
        """RAG 生成回答"""
        # 1. 检索相关文档
        relevant_docs = self.retrieve(query, top_k=3)

        # 2. 构建增强 Prompt
        context = "\n\n".join([
            f"[参考 {i+1}]: {doc['content']}"
            for i, doc in enumerate(relevant_docs)
        ])

        prompt = f"""基于以下参考信息回答问题。如果参考信息中没有答案，请明确说明。

参考信息：
{context}

问题：{query}

回答："""

        # 3. 让 LLM 生成回答
        response = llm.generate(prompt)
        return response


# 使用示例
knowledge_base = [
    "Python 是一种高级编程语言，由 Guido van Rossum 于 1991 年创建。",
    "Python 的设计哲学强调代码的可读性和简洁性。",
    "Python 支持多种编程范式：面向对象、函数式、过程式。",
    "Python 的标准库非常丰富，包括网络、数据库、GUI 等模块。",
    "Python 是数据科学和人工智能领域最流行的语言之一。",
    "Django 和 Flask 是 Python 最流行的 Web 框架。",
    "Python 的 GIL（全局解释器锁）限制了多线程 CPU 密集型任务的性能。",
]

rag = SimpleRAG()
rag.add_documents(knowledge_base)

# 查询
query = "Python 是谁创建的？有什么特点？"
results = rag.retrieve(query)
print("检索到的相关内容:")
for r in results:
    print(f"  [{r['score']:.3f}] {r['content']}")
```

## 文档切分策略

```python
class DocumentSplitter:
    """文档切分器"""

    def split_by_chars(self, text, chunk_size=500, overlap=50):
        """按字符数切分"""
        chunks = []
        start = 0
        while start < len(text):
            end = start + chunk_size
            chunk = text[start:end]
            chunks.append(chunk)
            start = end - overlap  # 重叠区域保证上下文连续性
        return chunks

    def split_by_tokens(self, text, chunk_size=100, overlap=10):
        """按 Token 数切分（更精确）"""
        tokens = text.split()
        chunks = []
        start = 0
        while start < len(tokens):
            end = start + chunk_size
            chunk = " ".join(tokens[start:end])
            chunks.append(chunk)
            start = end - overlap
        return chunks

    def split_by_semantic(self, text):
        """按语义边界切分（按段落/标题）"""
        # 按 Markdown 标题切分
        sections = []
        current_section = ""
        for line in text.split("\n"):
            if line.startswith("#"):
                if current_section:
                    sections.append(current_section.strip())
                current_section = line + "\n"
            else:
                current_section += line + "\n"
        if current_section:
            sections.append(current_section.strip())
        return sections
```

## 高级 RAG 技术

### 1. 混合搜索（Hybrid Search）

结合向量搜索和关键词搜索：

```python
def hybrid_search(query, vector_db, keyword_index, alpha=0.5):
    """混合搜索：向量相似度 + 关键词匹配"""
    # 向量搜索
    vector_results = vector_db.search(query, top_k=10)

    # 关键词搜索
    keyword_results = keyword_index.search(query, top_k=10)

    # 融合排序（ Reciprocal Rank Fusion）
    scores = {}
    for rank, result in enumerate(vector_results):
        scores[result["id"]] = scores.get(result["id"], 0) + alpha * (1 / (rank + 1))
    for rank, result in enumerate(keyword_results):
        scores[result["id"]] = scores.get(result["id"], 0) + (1 - alpha) * (1 / (rank + 1))

    return sorted(scores.items(), key=lambda x: x[1], reverse=True)
```

### 2. 重排序（Reranking）

检索后再用交叉编码器精排：

```
初步检索（向量搜索，召回 20 条）
        │
        ▼
重排序模型（Cross-Encoder，精排 Top 5）
        │
        ▼
返回最相关的 5 条给 LLM
```

## 课程简介

单 Agent 有能力和知识边界的限制。多 Agent 协作通过让多个专业化的 Agent 协同工作，可以完成更复杂的任务。本课时将学习多 Agent 架构设计和 Agent 间通信协议。

## 为什么需要多 Agent

### 单 Agent 的局限

| 问题 | 说明 |
|------|------|
| 知识局限 | 一个 LLM 无法精通所有领域 |
| 角色冲突 | 同一个 Agent 难以同时扮演多个专业角色 |
| 效率低下 | 串行处理复杂任务耗时长 |
| 缺乏监督 | 单一 Agent 容易产生幻觉或偏离目标 |

### 多 Agent 的优势

```
单 Agent：一个人做所有事
  多 Agent：团队协作
    架构师设计 → 开发者编码 → 测试员验证 → 产品经理验收
```

## 多 Agent 架构模式

### 1. 层次式（Hierarchical）

```
        Manager Agent
        (任务分配与监督)
       /       |       \
   Worker 1   Worker 2   Worker 3
  (搜索)      (分析)      (写作)
```

```python
class ManagerAgent:
    def __init__(self, workers):
        self.workers = workers

    def delegate(self, task):
        best_worker = self._select_worker(task)
        result = best_worker.execute(task)
        return self._review_result(result)

    def _select_worker(self, task):
        if "code" in task.lower():
            return self.workers["developer"]
        elif "design" in task.lower():
            return self.workers["designer"]
        return self.workers["general"]
```

### 2. 扁平式（Peer-to-Peer）

```
 Agent A ←→ Agent B
 (搜索)     (分析)
    |         |
    v         v
 Agent C ←→ Agent D
 (写作)     (审核)
```

### 3. 管道式（Pipeline）

```
 Agent 1 → Agent 2 → Agent 3 → Agent 4
 (输入)    (处理)    (优化)    (输出)
```

```python
from dataclasses import dataclass, field
from typing import List, Dict, Optional
import json
import uuid
from datetime import datetime

# ============================================================
# 1. 记忆系统
# ============================================================

class MemorySystem:
    """记忆系统：管理短期和长期记忆"""

    def __init__(self):
        self.short_term: List[Dict] = []
        self.long_term: Dict = {}
        self.max_short_term = 20

    def add_message(self, role: str, content: str):
        self.short_term.append({
            "role": role, "content": content,
            "timestamp": datetime.now().isoformat(),
        })
        if len(self.short_term) > self.max_short_term:
            self._summarize_old_messages()

    def remember(self, key: str, value: any):
        self.long_term[key] = {
            "value": value,
            "created_at": datetime.now().isoformat(),
        }

    def recall(self, key: str) -> Optional[any]:
        entry = self.long_term.get(key)
        return entry["value"] if entry else None

    def get_context(self, max_messages: int = 10) -> List[Dict]:
        return self.short_term[-max_messages:]

    def _summarize_old_messages(self):
        old = self.short_term[:10]
        summary = f"[早期对话摘要：{len(old)} 条消息已压缩]"
        self.short_term = [{"role": "system", "content": summary}] + self.short_term[10:]


# ============================================================
# 2. 工具定义与执行
# ============================================================

class Tool:
    def __init__(self, name, description, parameters, func):
        self.name = name
        self.description = description
        self.parameters = parameters
        self.func = func

class ToolRegistry:
    def __init__(self):
        self.tools: Dict[str, Tool] = {}

    def register(self, tool: Tool):
        self.tools[tool.name] = tool

    def get_schema(self) -> List[Dict]:
        return [
            {"name": t.name, "description": t.description, "parameters": t.parameters}
            for t in self.tools.values()
        ]

    def execute(self, name: str, args: Dict) -> str:
        if name not in self.tools:
            return f"错误：未知工具 {name}"
        try:
            return self.tools[name].func(**args)
        except Exception as e:
            return f"工具执行错误：{str(e)}"


# ============================================================
# 3. ReAct 推理引擎
# ============================================================

class ReActEngine:
    def __init__(self, llm, tool_registry: ToolRegistry):
        self.llm = llm
        self.tools = tool_registry
        self.max_steps = 5

    def run(self, user_input: str, memory: MemorySystem) -> str:
        memory.add_message("user", user_input)
        context = self._build_prompt(user_input, memory)

        for step in range(self.max_steps):
            response = self.llm.generate(context)
            thought, action, action_input, answer = self._parse(response)

            if answer:
                memory.add_message("assistant", answer)
                return answer

            if action and action_input:
                observation = self.tools.execute(action, action_input)
                memory.add_message("system", f"[{action}] {observation}")
                context += f"\nThought: {thought}\nAction: {action}\nObservation: {observation}\n"

        return "抱歉，我无法完成这个任务。"

    def _build_prompt(self, user_input: str, memory: MemorySystem) -> str:
        tool_schemas = json.dumps(self.tools.get_schema(), ensure_ascii=False, indent=2)
        user_name = memory.recall("user_name") or "用户"
        return f"""你是小智，一个个人助手。你可以使用以下工具：

{tool_schemas}

请按照以下格式输出：
Thought: 你的思考过程
Action: 工具名称
Action Input: {{"参数名": "参数值"}}
（如果有答案）
Final Answer: 你的回答

当前用户：{user_name}
对话历史：{json.dumps(memory.get_context(), ensure_ascii=False)}

用户请求：{user_input}"""

    def _parse(self, text: str):
        import re
        thought = re.search(r"Thought: (.+)", text)
        action = re.search(r"Action: (.+)", text)
        action_input = re.search(r"Action Input: (.+)", text)
        answer = re.search(r"Final Answer: (.+)", text)
        return (
            thought.group(1) if thought else None,
            action.group(1) if action else None,
            action_input.group(1) if action_input else None,
            answer.group(1) if answer else None,
        )


# ============================================================
# 4. 个人助手 Agent
# ============================================================

class PersonalAssistantAgent:
    def __init__(self, llm):
        self.memory = MemorySystem()
        self.tool_registry = ToolRegistry()
        self.react = ReActEngine(llm, self.tool_registry)
        self._register_tools()

    def _register_tools(self):
        self.tool_registry.register(Tool(
            name="get_weather",
            description="查询指定城市的天气",
            parameters={
                "type": "object",
                "properties": {"city": {"type": "string"}},
                "required": ["city"]
            },
            func=lambda city: f"{city}今天晴天，气温 25度C，微风。",
        ))
        self.tool_registry.register(Tool(
            name="add_todo",
            description="添加待办事项",
            parameters={
                "type": "object",
                "properties": {"task": {"type": "string"}},
                "required": ["task"]
            },
            func=self._add_todo,
        ))
        self.tool_registry.register(Tool(
            name="list_todos",
            description="列出所有待办事项",
            parameters={"type": "object", "properties": {}},
            func=self._list_todos,
        ))

    def chat(self, user_input: str) -> str:
        return self.react.run(user_input, self.memory)

    def _add_todo(self, task: str) -> str:
        todos = self.memory.recall("todos") or []
        todos.append({"task": task, "done": False})
        self.memory.remember("todos", todos)
        return f"已添加待办：{task}"

    def _list_todos(self) -> str:
        todos = self.memory.recall("todos") or []
        if not todos:
            return "暂无待办事项"
        return "\n".join([f"{'x' if t['done'] else 'o'} {t['task']}" for t in todos])
