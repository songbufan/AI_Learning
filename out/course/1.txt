# 类与对象

## 什么是面向对象编程？

面向对象编程（OOP）是一种编程范式，将程序组织为**对象**的集合，每个对象包含**数据**（属性）和**行为**（方法）。

## 类与对象的关系

- **类（Class）**：对象的蓝图/模板，定义属性和方法
- **对象（Object）**：类的实例，是具体的实体

```python
# 类比：类 = 建筑图纸，对象 = 实际建筑
class Dog:
    pass

dog1 = Dog()  # 第一个实例
dog2 = Dog()  # 第二个实例
```

## 定义类

```python
class Dog:
    """狗类"""

    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} 汪汪叫！"

    def introduce(self):
        return f"我是 {self.name}，品种是 {self.breed}"
```

## `__init__` 构造方法

`__init__` 是类的构造方法，在创建对象时自动调用：

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name    # 实例属性
        self.breed = breed
```

## `self` 关键字

`self` 指代**实例本身**，必须作为方法的第一个参数：

```python
class Dog:
    def __init__(self, name):
        self.name = name  # self.name 是实例属性

    def bark(self):
        print(f"{self.name} 叫了")  # self 访问实例属性
```

## 创建和使用对象

```python
# 创建对象实例
dog1 = Dog("旺财", "金毛")
dog2 = Dog("来福", "柴犬")

# 调用方法
print(dog1.introduce())  # 我是 旺财，品种是 金毛
print(dog2.bark())       # 来福 汪汪叫！

# 访问属性
print(dog1.name)   # 旺财
print(dog2.breed)  # 柴犬
```

## 在编辑器中练习

```python

    """狗类"""
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} 汪汪叫！"

    def introduce(self):
        return f"我是 {self.name}，品种是 {self.breed}"

# 创建对象实例
dog1 = Dog("旺财", "金毛")
dog2 = Dog("来福", "柴犬")

print(dog1.introduce())
print(dog2.bark())
```

## 练习任务

1. 定义一个 `Circle` 类，有 `radius` 属性，计算面积和周长的方法
2. 定义一个 `Student` 类，有 `name`、`age`、`score` 属性和一个 `get_grade()` 方法
3. 定义一个 `Book` 类，有 `title`、`author` 属性和一个 `describe()` 方法
4. 创建两个 `Dog` 对象，分别设置不同的名字和品种
5. 给 `Dog` 类添加一个 `age` 属性和 `get_age()` 方法

## 知识点总结

- 类用 `class` 关键字定义
- `__init__` 构造方法，创建对象时自动调用
- `self` 指代实例本身，必须作为第一个参数
- 实例属性：`self.xxx = value`
- 实例方法：`def method(self, ...)`
- 创建对象：`obj = ClassName(args)`
- 调用方法：`obj.method()`
- 访问属性：`obj.attribute`

# 实例变量与类变量

## 两种变量类型

类中可以定义两种变量：

- **实例变量**：每个对象独立拥有，互不影响
- **类变量**：所有对象共享，属于类本身

## 实例变量

在 `__init__` 中通过 `self` 定义的变量：

```python
class Student:
    def __init__(self, name):
        self.name = name  # 实例变量，每个对象独立

s1 = Student("小明")
s2 = Student("小红")

print(s1.name)  # 小明
print(s2.name)  # 小红
```

## 类变量

在类内部、方法外部定义的变量：

```python
class Student:
    school = "Python 学校"  # 类变量，所有实例共享

    def __init__(self, name):
        self.name = name    # 实例变量

s1 = Student("小明")
s2 = Student("小红")

print(s1.school)  # Python 学校
print(s2.school)  # Python 学校
print(s1.school is s2.school)  # True（同一个对象）
```

## 修改类变量的影响

```python
class Counter:
    count = 0  # 类变量

    def __init__(self, name):
        self.name = name
        Counter.count += 1  # 修改类变量

c1 = Counter("A")
c2 = Counter("B")
print(Counter.count)  # 2（所有实例共享）
```

## 实例变量 vs 类变量

| 特性 | 实例变量 | 类变量 |
|------|----------|--------|
| 定义位置 | `__init__` 内 `self.` | 类内部，方法外部 |
| 归属 | 每个对象独立 | 类本身，所有实例共享 |
| 访问方式 | `self.var` / `obj.var` | `ClassName.var` / `self.var` |
| 修改影响 | 只影响当前对象 | 影响所有实例 |
| 内存 | 每个对象一份 | 只有一份 |

## 在编辑器中练习

```python
# 实例变量 vs 类变量
class Student:
    school = "Python 学校"  # 类变量（所有实例共享）

    def __init__(self, name):
        self.name = name  # 实例变量（每个实例独立）

s1 = Student("小明")
s2 = Student("小红")

print(f"{s1.name} 在 {s1.school}")
print(f"{s2.name} 在 {s2.school}")
print(f"学校是同一个: {s1.school is s2.school}")
```

## 练习任务

1. 创建一个 `Counter` 类，用类变量统计创建了多少个实例
2. 修改类变量后，观察所有实例的变化
3. 创建一个 `Car` 类，类变量 `wheels = 4`，实例变量 `brand`、`color`
4. 创建一个 `User` 类，类变量 `role = "user"`，实例变量 `username`
5. 对比实例变量和类变量的内存占用

## 知识点总结

- 实例变量：`self.xxx`，每个对象独立
- 类变量：类内部定义，所有实例共享
- 类变量通过 `ClassName.var` 访问
- 修改类变量影响所有实例
- 实例变量屏蔽同名类变量（就近原则）
- 类变量适合存储公共数据（如计数器、配置）

# 继承

## 什么是继承？

继承允许一个类（子类）**获取另一个类（父类）的属性和方法**，实现代码复用。

## 基本语法

```python
# 父类（基类）
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "发出声音"

# 子类（派生类）
class Cat(Animal):  # Cat 继承 Animal
    def speak(self):
        return f"{self.name} 喵喵叫"

class Dog(Animal):  # Dog 继承 Animal
    def speak(self):
        return f"{self.name} 汪汪叫"
```

## 方法重写（Override）

子类可以重新定义父类的方法：

```python
class Animal:
    def speak(self):
        return "发出声音"

class Cat(Animal):
    def speak(self):  # 重写父类方法
        return "喵喵"

class Dog(Animal):
    def speak(self):  # 重写父类方法
        return "汪汪"
```

## super() 调用父类方法

在子类中调用父类的方法：

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Cat(Animal):
    def __init__(self, name, color):
        super().__init__(name)  # 调用父类的 __init__
        self.color = color

    def introduce(self):
        return f"我是{self.name}，颜色是{self.color}"
```

## 多层继承

```python
class Animal:
    pass

class Mammal(Animal):  # 继承 Animal
    pass

class Cat(Mammal):      # 继承 Mammal（间接继承 Animal）
    pass
```

## 在编辑器中练习

```python
# 类继承

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "发出声音"

class Cat(Animal):  # Cat 继承 Animal
    def speak(self):
        return f"{self.name} 喵喵叫"

class Dog(Animal):  # Dog 继承 Animal
    def speak(self):
        return f"{self.name} 汪汪叫"

cat = Cat("咪咪")
dog = Dog("旺财")

print(cat.speak())
print(dog.speak())
```

2. 创建 `Car` 和 `Bike` 子类，分别重写 `start()` 方法
3. 创建 `ElectricCar` 继承 `Car`，添加 `battery` 属性
4. 用 `super()` 调用父类的 `__init__`
5. 创建一个动物类层次结构：Animal → Mammal → Cat/Dog

## 知识点总结

- 继承：子类获取父类的属性和方法
- 语法：`class Child(Parent):`
- 方法重写：子类重新定义父类方法
- `super()` 调用父类的方法
- 支持多层继承
- 提高代码复用，避免重复
- 体现"is-a"关系（Cat is an Animal）

# 多态

## 什么是多态？

多态（Polymorphism）意为"多种形态"。在 OOP 中，多态指**不同类型的对象可以对相同的方法调用做出不同的响应**。

## 多态的三种形式

### 1. 方法重写（Run-time Polymorphism）

```python
class Cat:
    def speak(self):
        return "喵喵"

class Dog:
    def speak(self):
        return "汪汪"

class Cow:
    def speak(self):
        return "哞哞"

# 多态函数
def make_sound(animal):
    print(animal.speak())

make_sound(Cat())   # 喵喵
make_sound(Dog())   # 汪汪
make_sound(Cow())   # 哞哞
```

不同类型的对象传入同一个函数，调用相同的方法名 `speak()`，产生不同的行为。

## 2. 鸭子类型（Duck Typing）

Python 是动态类型语言，不关心对象的类型，只关心对象是否有需要的方法：

```python
class Cat:
    def speak(self):
        return "喵喵"

class Dog:
    def speak(self):
        return "汪汪"

# 不关心类型，只要有 speak() 方法就行
def make_sound(animal):
    print(animal.speak())

make_sound(Cat())
make_sound(Dog())
```

> "如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子。"

## 3. 抽象基类（ABC）

用 `abc` 模块强制实现多态：

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def speak(self):
        pass

class Cat(Animal):
    def speak(self):
        return "喵喵"

class Dog(Animal):
    def speak(self):
        return "汪汪"
```

## 在编辑器中练习

```python

        return "喵喵"

    def speak(self):
        return "汪汪"

class Cow:
    def speak(self):
        return "哞哞"

# 多态函数

    print(animal.speak())

make_sound(Cat())
make_sound(Dog())
make_sound(Cow())
```

4. 用鸭子类型实现：不同类型的对象都可以调用 `display()` 方法
5. 对比多态和条件判断的优劣

## 知识点总结

- 多态：不同对象对同一方法的不同响应
- 提高代码灵活性和可扩展性
- 鸭子类型：Python 特有的多态方式
- 抽象基类（ABC）：强制子类实现特定方法
- `@abstractmethod` 定义抽象方法
- 多态 + 继承 = 强大的代码复用

# 封装与私有属性

## 什么是封装？

封装是 OOP 的三大特性之一（封装、继承、多态）。它将**数据**和**操作数据的方法**捆绑在一起，并隐藏内部实现细节。

## 私有属性

Python 中使用双下划线 `__` 前缀定义私有属性：

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance  # 双下划线表示私有

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            return f"存入 {amount}，余额: {self.__balance}"
        return "金额必须大于零"

    def get_balance(self):
        return self.__balance

account = BankAccount("小明", 100)
print(account.deposit(50))     # 存入 50，余额: 150
print(account.get_balance())   # 150
# print(account.__balance)     # 报错！无法直接访问
```

## Python 的私有机制

Python 的私有是**名称修饰（Name Mangling）**，不是真正的私有：

```python
class Example:
    def __init__(self):
        self.__private = 42

obj = Example()
# obj.__private     # 报错（但不是真正不可访问）
print(obj._Example__private)  # 42（名称修饰后可以访问）
```

> 约定：单下划线 `_var` 表示"内部使用，不要外部访问"（君子协定），双下划线 `__var` 表示更强的私有。

## Getter 和 Setter

通过方法控制属性的访问：

```python
class Person:
    def __init__(self, name, age):
        self.__name = name
        self.__age = age

    # Getter
    @property
    def name(self):
        return self.__name

    # Setter
    @name.setter
    def name(self, value):
        if not value:
            raise ValueError("名字不能为空")
        self.__name = value

    @property
    def age(self):
        return self.__age

    @age.setter
    def age(self, value):
        if not 0 <= value <= 150:
            raise ValueError("年龄不合法")
        self.__age = value
```

## 在编辑器中练习

```python

        return self.__balance

```

## 知识点总结

- 封装：隐藏内部细节，只暴露必要接口
- `__var`：双下划线私有（名称修饰）
- `_var`：单下划线，约定"内部使用"
- Getter/Setter：通过方法控制访问
- `@property`：将方法变为属性访问
- `@xxx.setter`：设置属性的 setter
- 封装提高代码安全性和可维护性

## 什么是 random 模块？

`random` 模块提供生成随机数的功能，用于模拟随机事件、游戏开发、数据抽样等场景。

## 常用函数

### randint() — 随机整数

```python
import random

# 生成 [a, b] 范围内的随机整数
num = random.randint(1, 100)
print(num)  # 1 到 100 之间的随机整数
```

### choice() — 随机选择

```python
import random

fruits = ["苹果", "香蕉", "橙子", "葡萄"]
fruit = random.choice(fruits)
print(fruit)  # 随机选一个水果
```

### shuffle() — 随机打乱

```python
import random

cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(cards)  # 随机排列
```

### sample() — 随机抽样

```python
import random

# 从列表中随机抽取 n 个不重复元素
lucky = random.sample(range(1, 50), 6)
print(lucky)  # 6 个不重复的随机数
```

## 更多随机函数

```python
import random

# random() - [0.0, 1.0) 的随机浮点数
print(random.random())

# uniform(a, b) - [a, b] 范围内的随机浮点数
print(random.uniform(1.5, 3.5))

# randrange(start, stop, step) - 范围随机整数
print(random.randrange(0, 100, 10))  # 0,10,20,...,90

# seed() - 设置随机种子（用于复现结果）
random.seed(42)
print(random.randint(1, 100))  # 每次运行结果相同
```

# datetime 模块

## 什么是 datetime？

`datetime` 模块提供处理日期和时间的类，用于：
- 获取当前时间
- 日期计算（加减天数）
- 日期格式化
- 时间差计算

## 核心类

| 类 | 说明 | 示例 |
|----|------|------|
| `datetime` | 日期+时间 | `datetime(2024, 1, 15)` |
| `date` | 仅日期 | `date(2024, 1, 15)` |
| `time` | 仅时间 | `time(14, 30, 0)` |
| `timedelta` | 时间差 | `timedelta(days=7)` |

## 获取当前时间

```python
from datetime import datetime

now = datetime.now()
print(now)  # 2024-01-15 14:30:00.123456

# 格式化输出
print(now.strftime("%Y-%m-%d"))       # 2024-01-15
print(now.strftime("%H:%M:%S"))       # 14:30:00
print(now.strftime("%Y年%m月%d日"))   # 2024年01月15日
```

## 日期格式化代码

| 代码 | 说明 | 示例 |
|------|------|------|
| `%Y` | 四位年份 | `2024` |
| `%y` | 两位年份 | `24` |
| `%m` | 两位月份 | `01` |
| `%d` | 两位日期 | `15` |
| `%H` | 24小时制小时 | `14` |
| `%I` | 12小时制小时 | `02` |
| `%M` | 分钟 | `30` |
| `%S` | 秒 | `00` |
| `%A` | 星期名称 | `Monday` |
| `%B` | 月份名称 | `January` |

## 日期计算

```python
from datetime import datetime, timedelta

now = datetime.now()

# 加/减时间
tomorrow = now + timedelta(days=1)
next_week = now + timedelta(weeks=1)
yesterday = now - timedelta(days=1)

print(f"明天: {tomorrow.strftime('%Y-%m-%d')}")
print(f"下周: {next_week.strftime('%Y-%m-%d')}")
```

## 时间差计算

```python
from datetime import datetime

start = datetime(2024, 1, 1)
end = datetime(2024, 12, 31)
delta = end - start
print(delta.days)  # 365 天
```

# collections 模块

## 什么是 collections？

`collections` 模块提供了一些**高级数据结构**，是对 Python 内置数据类型的扩展。

## Counter — 计数器

统计元素出现次数：

```python
from collections import Counter

text = "hello world hello python"
counter = Counter(text.split())
print(counter)
# Counter({'hello': 2, 'world': 1, 'python': 1})

# 获取出现最多的元素
print(counter.most_common(1))  # [('hello', 2)]
```

## defaultdict — 带默认值的字典

访问不存在的键时返回默认值：

```python
from collections import defaultdict

# 默认值为列表
grades = defaultdict(list)
grades["小明"].append(90)
grades["小明"].append(85)
grades["小红"].append(95)

print(grades["小明"])  # [90, 85]
print(grades["小刚"])  # []（自动创建空列表）
```

## deque — 双端队列

高效地在两端添加/删除元素：

```python
from collections import deque

dq = deque([1, 2, 3])

# 两端操作
dq.append(4)        # 右端添加: [1, 2, 3, 4]
dq.appendleft(0)    # 左端添加: [0, 1, 2, 3, 4]
dq.pop()            # 右端删除: 4
dq.popleft()        # 左端删除: 0
```

## namedtuple — 命名元组

创建有字段名的元组：

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(10, 20)
print(p.x)    # 10
print(p.y)    # 20
```

## OrderedDict — 有序字典

保持插入顺序的字典（Python 3.7+ 中 dict 默认有序）：

```python
from collections import OrderedDict

od = OrderedDict()
od["a"] = 1
od["b"] = 2
od["c"] = 3

for key, value in od.items():
    print(f"{key}: {value}")
```

# 猜数字游戏

## 项目概述

综合运用循环、条件判断、随机数等知识，实现一个经典的猜数字游戏。

## 游戏规则

1. 系统随机生成一个 1-100 的整数
2. 玩家输入猜测的数字
3. 系统提示"太大"、"太小"或"猜对了"
4. 记录猜测次数
5. 玩家可以随时退出

## 代码实现

```python
import random

def guess_number():
    """猜数字游戏主函数"""
    secret = random.randint(1, 100)
    attempts = 0

    print("=" * 40)
    print("🎮 猜数字游戏！")
    print("我已经想好了一个 1-100 的数字。")
    print("输入 -1 可以退出游戏。")
    print("=" * 40)

    while True:
        try:
            guess = int(input(f"\n第 {attempts + 1} 次猜测，请输入: "))

            if guess == -1:
                print(f"游戏结束！答案是 {secret}")
                break

            attempts += 1

            if guess == secret:
                print(f"🎉 恭喜！第 {attempts} 次猜对了！答案是 {secret}")
                break
            elif guess < secret:
                print("📈 太小了！再大一点")
            else:
                print("📉 太大了！再小一点")

        except ValueError:
            print("⚠️ 请输入有效的数字！")

    print(f"总共猜测了 {attempts} 次")

# 启动游戏
guess_number()
```

# 简易计算器

## 项目概述

综合运用函数、异常处理等知识，实现一个命令行计算器。

## 功能需求

1. 支持 `+`、`-`、`*`、`/` 四种运算
2. 处理除零错误
3. 处理无效输入
4. 支持连续计算
5. 清晰的用户界面

## 代码实现

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        raise ZeroDivisionError("除数不能为零")
    return a / b

# 运算符映射
operations = {
    "+": add,
    "-": subtract,
    "*": multiply,
    "/": divide,
}

def calculator():
    """计算器主函数"""
    print("=" * 40)
    print("🧮 简易计算器")
    print("支持运算: + - * /")
    print("输入 'quit' 退出")
    print("=" * 40)

    while True:
        # 获取用户输入
        user_input = input("\n请输入表达式（如: 10 + 5）: ").strip()

        if user_input.lower() == "quit":
            print("再见！")
            break

        # 解析输入
        parts = user_input.split()
        if len(parts) != 3:
            print("⚠️ 格式错误！请使用: 数字 运算符 数字")
            continue

        num1_str, op, num2_str = parts

        # 类型转换
        try:
            num1 = float(num1_str)
            num2 = float(num2_str)
        except ValueError:
            print("⚠️ 请输入有效的数字！")
            continue

        # 执行运算
        if op not in operations:
            print(f"⚠️ 不支持的运算符: {op}")
            continue

        try:
            result = operations[op](num1, num2)
            print(f"结果: {num1} {op} {num2} = {result}")
        except ZeroDivisionError:
            print("⚠️ 错误：除数不能为零！")

# 启动计算器
calculator()
```

## 关键知识点

- 函数映射（字典映射运算符到函数）
- 异常处理（`try-except`）
- 字符串解析（`split()`）
- 循环 + 用户交互

# 待办事项列表

## 项目概述

综合运用列表、字典、函数等知识，实现一个简单的待办事项（Todo）管理程序。

## 功能需求

1. 添加待办事项
2. 标记完成
3. 删除待办事项
4. 查看所有待办
5. 数据持久化（列表存储）

## 代码实现

```python
# 待办事项列表
todos = []

def add_task(task):
    """添加待办事项"""
    todos.append({"task": task, "done": False})
    print(f"✅ 已添加: {task}")

def complete_task(index):
    """标记完成"""
    if 0 <= index < len(todos):
        todos[index]["done"] = True
        print(f"🎉 已完成: {todos[index]['task']}")
    else:
        print("⚠️ 无效的序号")

def remove_task(index):
    """删除待办事项"""
    if 0 <= index < len(todos):
        removed = todos.pop(index)
        print(f"🗑️ 已删除: {removed['task']}")
```

# 学生成绩管理系统

## 项目概述

综合运用类、字典、可变参数等知识，实现一个学生成绩管理系统。

## 功能需求

1. 添加学生（姓名 + 多门成绩）
2. 计算学生平均分
3. 显示所有学生信息
4. 查询指定学生
5. 班级统计分析

## 代码实现

```python
class StudentManager:
    """学生成绩管理器"""

    def __init__(self):
        self.students = {}  # 字典存储学生信息

    def add_student(self, name, *scores):
        """添加学生及成绩"""
        avg = sum(scores) / len(scores) if scores else 0
        self.students[name] = {
            "scores": list(scores),
            "average": avg,
        }
        print(f"✅ 已添加: {name}，平均分: {avg:.1f}")

    def get_student(self, name):
        """查询学生信息"""
        if name in self.students:
            return self.students[name]
        return None

    def show_all(self):
        """显示所有学生"""
        if not self.students:
            print("📭 暂无学生数据")
            return

        print("\n" + "=" * 40)
        print("📊 所有学生成绩")
        print("=" * 40)

        for name, data in self.students.items():
            scores_str = ", ".join(map(str, data["scores"]))
            print(f"  👤 {name}")
            print(f"     成绩: {scores_str}")
            print(f"     平均: {data['average']:.1f}")
            print()

    def class_average(self):
        """计算全班平均分"""
        if not self.students:
            return 0
        total = sum(d["average"] for d in self.students.values())
        return total / len(self.students)

    def top_student(self):
        """找出最高分学生"""
        if not self.students:
            return None
        return max(self.students.items(), key=lambda x: x[1]["average"])

# 使用示例
manager = StudentManager()
manager.add_student("小明", 85, 90, 78)
manager.add_student("小红", 92, 88, 95)
manager.add_student("小刚", 70, 65, 80)

manager.show_all()
print(f"全班平均分: {manager.class_average():.1f}")

top_name, top_data = manager.top_student()
print(f"最高分学生: {top_name} ({top_data['average']:.1f}分)")
```
