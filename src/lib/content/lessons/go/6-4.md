# 项目部署

## 编译与打包

Go 支持交叉编译，可编译为任意平台的可执行文件：

```bash
# 编译当前平台
go build -o webapp

# 编译 Linux amd64（最常用的服务器平台）
GOOS=linux GOARCH=amd64 go build -o webapp-linux

# 编译 macOS Apple Silicon
GOOS=darwin GOARCH=arm64 go build -o webapp-mac

# 查看支持的平台
go tool dist list
```

## 使用 Systemd 管理服务

创建 `/etc/systemd/system/webapp.service`：

```ini
[Unit]
Description=Go Web App
After=network.target

[Service]
Type=simple
User=deploy
WorkingDirectory=/opt/webapp
ExecStart=/opt/webapp/webapp
Restart=on-failure
RestartSec=5
Environment=PORT=8080
Environment=DB_PATH=/opt/webapp/data.db

# 安全限制
NoNewPrivileges=true
ProtectSystem=full
ProtectHome=read-only

[Install]
WantedBy=multi-user.target
```

```bash
# 部署步骤
sudo systemctl daemon-reload
sudo systemctl enable webapp
sudo systemctl start webapp
sudo systemctl status webapp
```

## Nginx 反向代理配置

```nginx
server {
    listen 80;
    server_name example.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 静态文件
    location /static/ {
        root /opt/webapp/static;
        expires 7d;
    }
}
```

## 监控与运维

```go
// 添加健康检查端点
func healthCheck(w http.ResponseWriter, r *http.Request) {
    status := map[string]string{
        "status": "ok",
        "time":   time.Now().Format(time.RFC3339),
    }
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(status)
}
```

## 知识点总结

- `GOOS`/`GOARCH` 交叉编译
- Systemd 管理服务生命周期
- Nginx 反向代理 + 负载均衡
- 生产环境需关注：日志、监控、备份

> 💡 提示：使用 `go install` 可以直接安装 Go 程序到 `$GOPATH/bin`，配合 Docker 实现一键部署。
