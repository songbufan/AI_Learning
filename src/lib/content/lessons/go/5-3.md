# HTTP 服务端

## 使用 net/http 创建服务器

Go 标准库包含强大的 HTTP 服务能力：

```go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "time"
)

type Response struct {
    Message string
    Time    string
}

func helloHandler(w http.ResponseWriter, r *http.Request) {
    if r.URL.Path != "/hello" {
        http.NotFound(w, r)
        return
    }

    resp := Response{
        Message: "Hello, Go HTTP!",
        Time:    time.Now().Format(time.RFC3339),
    }

    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(resp)
}

func userHandler(w http.ResponseWriter, r *http.Request) {
    switch r.Method {
    case "GET":
        fmt.Fprintf(w, "获取用户信息\n")
    case "POST":
        var user map[string]interface{}
        json.NewDecoder(r.Body).Decode(&user)
        fmt.Fprintf(w, "创建用户: %v\n", user)
    default:
        w.WriteHeader(http.StatusMethodNotAllowed)
    }
}

func main() {
    http.HandleFunc("/hello", helloHandler)
    http.HandleFunc("/user", userHandler)

    fmt.Println("服务器启动: http://localhost:8080")
    http.ListenAndServe(":8080", nil)
}
```

## 请求处理与路由

```go
package main

import (
    "fmt"
    "net/http"
    "strings"
)

// 简单路由
func router(w http.ResponseWriter, r *http.Request) {
    path := r.URL.Path

    switch {
    case path == "/":
        fmt.Fprintln(w, "首页")
    case strings.HasPrefix(path, "/users/"):
        id := strings.TrimPrefix(path, "/users/")
        fmt.Fprintf(w, "用户 ID: %s\n", id)
    case path == "/health":
        w.WriteHeader(http.StatusOK)
        fmt.Fprintln(w, "OK")
    default:
        http.NotFound(w, r)
    }
}

func main() {
    http.HandleFunc("/", router)
    http.ListenAndServe(":8080", nil)
}
```

## 知识点总结

- `http.HandleFunc(pattern, handler)` 注册路由
- `ResponseWriter` 写入响应，`Request` 读取请求
- `http.ListenAndServe(addr, handler)` 启动服务器
- 标准库足够构建完整 REST API

> 💡 提示：Go 标准库的 HTTP 功能非常完善，中小项目不需要第三方框架。需要高性能时再考虑 Gin、Echo 等。
