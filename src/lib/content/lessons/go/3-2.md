# 接口与多态

## 接口定义

Go 的接口是隐式实现的（鸭子类型）：

```go
package main

import "fmt"

// 定义接口
type Speaker interface {
    Speak() string
}

type Greeter interface {
    Greet() string
}

// 实现接口（隐式，不需要 implements 关键字）
type Dog struct {
    Name string
}

func (d Dog) Speak() string {
    return fmt.Sprintf("%s: 汪汪!", d.Name)
}

type Cat struct {
    Name string
}

func (c Cat) Speak() string {
    return fmt.Sprintf("%s: 喵喵~", c.Name)
}

func main() {
    // 接口类型可以持有任何实现该接口的类型
    var speakers []Speaker = []Speaker{
        Dog{Name: "旺财"},
        Cat{Name: "咪咪"},
    }

    for _, s := range speakers {
        fmt.Println(s.Speak())
    }

    // 类型断言
    for _, s := range speakers {
        if dog, ok := s.(Dog); ok {
            fmt.Printf("这是一只狗: %s\n", dog.Name)
        }
    }
}
```

输出：

```
旺财: 汪汪!
咪咪: 喵喵~
这是一只狗: 旺财
```

## 空接口与类型转换

```go
package main

import "fmt"

func describe(i interface{}) {
    switch v := i.(type) {
    case int:
        fmt.Printf("整数: %d (类型是 %T)\n", v, v)
    case string:
        fmt.Printf("字符串: %q (长度 %d)\n", v, len(v))
    case bool:
        fmt.Printf("布尔: %v\n", v)
    default:
        fmt.Printf("未知类型: %T\n", v)
    }
}

func main() {
    describe(42)
    describe("Hello")
    describe(true)
    describe([]int{1, 2, 3})
}
```

输出：

```
整数: 42 (类型是 int)
字符串: "Hello" (长度 5)
布尔: true
未知类型: []int
```

## 知识点总结

- Go 接口是隐式实现的（duck typing）
- 接口定义行为，类型实现行为
- `interface{}` 可接受任何类型
- `v.(Type)` 类型断言，`switch v.(type)` 类型选择

> 💡 提示：Go 1.18+ 推荐用 `any`（即 `interface{}` 的别名）来表示任意类型。
