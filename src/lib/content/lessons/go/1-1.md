# Go 语言简介

## 什么是 Go 语言

Go（又称 Golang）是 Google 于 2009 年推出的开源编程语言，由 **Robert Griesemer**、**Rob Pike** 和 **Ken Thompson** 设计。Go 结合了 C 语言的高性能与 Python 的简洁开发体验。

## Go 的核心特性

| 特性 | 说明 |
|------|------|
| 编译型语言 | 编译为机器码，运行速度接近 C |
| 静态类型 | 编译时类型检查，减少运行时错误 |
| 原生并发 | goroutine + channel，轻松处理高并发 |
| 自动垃圾回收 | 无需手动管理内存 |
| 简洁语法 | 关键字仅 25 个，学习曲线平缓 |

## Go 的应用场景

- **云原生应用**：Docker、Kubernetes 等容器技术
- **微服务**：高性能 API 服务
- **命令行工具**：CLI 工具开发（如 hugo、jq）
- **网络编程**：HTTP 服务、分布式系统
- **区块链**：以太坊、Cosmos SDK 等

## 安装 Go

```bash
# macOS
brew install go

# Ubuntu/Debian
sudo apt install golang-go

# 验证安装
go version
```

## Hello World

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

## 知识点总结

- Go 是 Google 开发的静态编译型语言
- 原生支持并发（goroutine、channel）
- 语法简洁，关键字仅 25 个
- 广泛用于云原生和微服务领域
