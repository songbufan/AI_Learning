# 变量与数据类型

## 变量声明方式

Go 提供了多种变量声明方式：

```go
package main

import "fmt"

func main() {
    // 方式 1：var 关键字 + 类型
    var name string = "Go"
    var version int = 1

    // 方式 2：类型推断（推荐）
    var lang = "Golang"
    year := 2009  // 短变量声明（仅函数内）

    // 方式 3：多变量声明
    var a, b, c int = 1, 2, 3
    x, y := "hello", true

    fmt.Printf("语言: %s, 版本: %d\n", name, version)
    fmt.Printf("%s, %d, %s, %t\n", lang, year, x, y)
    fmt.Printf("a=%d, b=%d, c=%d\n", a, b, c)
}
```

输出：

```
语言: Go, 版本: 1
Golang, 2009, hello, true
a=1, b=2, c=3
```

## 基本数据类型

| 类型 | 说明 | 示例值 |
|------|------|--------|
| `bool` | 布尔值 | `true`, `false` |
| `string` | 字符串 | `"hello"` |
| `int` | 有符号整数 | `42`, `-7` |
| `int8/16/32/64` | 指定大小整数 | `int8(127)` |
| `uint` | 无符号整数 | `42` |
| `float32/64` | 浮点数 | `3.14`, `2.0` |
| `complex64/128` | 复数 | `1+2i` |

## 常量

```go
package main

import "fmt"

const Pi = 3.14159
const (
    Monday = 1
    Tuesday = 2
    Wednesday = 3
)

func main() {
    fmt.Println(Pi)
    fmt.Println(Monday, Tuesday, Wednesday)
}
```

输出：

```
3.14159
1 2 3
```

2. 声明一个 `int` 和 `float64` 变量并计算它们的和
3. 理解 `:=` 为什么只能在函数内部使用

## 知识点总结

- Go 使用 `var` 和 `:=` 声明变量
- `:=` 是短声明，只能在函数内使用
- Go 是静态类型语言，类型不可变
- 支持 25 个关键字，语法简洁

> 💡 提示：Go 的变量命名推荐使用 `驼峰命名法`（camelCase），不要用下划线。
