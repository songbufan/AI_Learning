# 结构体与方法

## 结构体定义

Go 使用 `struct` 定义复合数据类型，替代其他语言的类：

```go
package main

import "fmt"

// 定义结构体
type Person struct {
    Name string
    Age  int
    City string
}

// 结构体字面量
func main() {
    // 方式 1：指定字段名
    p1 := Person{
        Name: "张三",
        Age:  25,
        City: "北京",
    }

    // 方式 2：按顺序（不推荐，容易出错）
    p2 := Person{"李四", 30, "上海"}

    // 方式 3：部分字段初始化
    p3 := Person{Name: "王五", Age: 28}

    // 访问字段
    fmt.Printf("p1: %s, %d岁, %s\n", p1.Name, p1.Age, p1.City)
    fmt.Printf("p2: %s, %d岁, %s\n", p2.Name, p2.Age, p2.City)
    fmt.Printf("p3: %s, %d岁\n", p3.Name, p3.Age)
}
```

输出：

```
p1: 张三, 25岁, 北京
p2: 李四, 30岁, 上海
p3: 王五, 28岁
```

## 方法

Go 的方法通过**接收者**（receiver）关联到结构体：

```go
package main

import "fmt"

type Rectangle struct {
    Width  float64
    Height float64
}

// 值接收者（不影响原对象）
func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

// 指针接收者（可以修改原对象）
func (r *Rectangle) Scale(factor float64) {
    r.Width *= factor
    r.Height *= factor
}

func (r Rectangle) String() string {
    return fmt.Sprintf("矩形(%.1f x %.1f)", r.Width, r.Height)
}

func main() {
    r := Rectangle{Width: 5, Height: 3}
    fmt.Printf("面积: %.1f\n", r.Area())

    r.Scale(2)
    fmt.Printf("放大后: %s\n", r.String())
}
```

输出：

```
面积: 15.0
放大后: 矩形(10.0 x 6.0)
```

## 知识点总结

- `struct` 定义结构体，支持零值初始化
- 方法通过 `(接收者) 方法名` 定义
- 值接收者 vs 指针接收者：是否需要修改原对象
- `fmt.Stringer` 接口通过 `String()` 方法实现

> 💡 提示：Go 没有继承，但通过**嵌入**（embedding）可以实现类似组合的效果。
