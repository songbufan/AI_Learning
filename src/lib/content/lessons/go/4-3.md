# Select 多路复用

## select 语句

`select` 可以同时监听多个 channel，类似 `switch` 但用于 channel：

```go
package main

import (
    "fmt"
    "time"
)

func main() {
    ch1 := make(chan string)
    ch2 := make(chan string)

    go func() {
        time.Sleep(500 * time.Millisecond)
        ch1 <- "来自 ch1（500ms）"
    }()

    go func() {
        time.Sleep(200 * time.Millisecond)
        ch2 <- "来自 ch2（200ms）"
    }()

    // select 选择最先就绪的 case
    for i := 0; i < 2; i++ {
        select {
        case msg1 := <-ch1:
            fmt.Println("收到 ch1:", msg1)
        case msg2 := <-ch2:
            fmt.Println("收到 ch2:", msg2)
        }
    }

    // 带超时的 select
    fmt.Println("\n--- 超时演示 ---")
    result := make(chan string)
    go func() {
        time.Sleep(2 * time.Second)
        result <- "太晚了"
    }()

    select {
    case r := <-result:
        fmt.Println(r)
    case <-time.After(1 * time.Second):
        fmt.Println("超时！1 秒内未收到结果")
    }
}
```

输出：

```
收到 ch2: 来自 ch2（200ms）
收到 ch1: 来自 ch1（500ms）

--- 超时演示 ---
超时！1 秒内未收到结果
```

## select 的随机选择

当多个 case 同时就绪时，select 会随机选择一个：

```go
package main

import (
    "fmt"
    "time"
)

func main() {
    ch := make(chan int, 10)

    // 预先填入数据
    for i := 0; i < 10; i++ {
        ch <- i
    }

    // 多个 case 同时就绪，随机选择
    for i := 0; i < 5; i++ {
        select {
        case v := <-ch:
            fmt.Printf("收到: %d\n", v)
        }
    }

    // default case（非阻塞 select）
    fmt.Println("\n--- 非阻塞 select ---")
    nonBlockCh := make(chan int)
    select {
    case v := <-nonBlockCh:
        fmt.Println("收到:", v)
    default:
        fmt.Println("channel 为空，执行 default")
    }
}
```

输出：

```
收到: 0
收到: 1
收到: 2
收到: 3
收到: 4

--- 非阻塞 select ---
channel 为空，执行 default
```

## 知识点总结

- `select` 监听多个 channel，类似 switch
- 多个 case 就绪时随机选择一个
- `time.After()` 配合 select 实现超时
- `default` 实现非阻塞 channel 操作

> 💡 提示：`select` 没有 `fallthrough`，每个 case 独立执行。配合 `for` 使用实现持续监听。
