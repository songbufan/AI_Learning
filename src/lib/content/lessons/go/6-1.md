# 综合项目概述

## 项目目标

通过构建一个完整的 Web 应用，综合运用 Go 的各项技能：

- HTTP 服务
- 数据存储（JSON 文件）
- 路由设计
- 中间件
- 日志系统

## 项目结构

```
go-webapp/
├── main.go          # 入口文件
├── handlers/        # 请求处理器
├── models/          # 数据模型
├── middleware/      # 中间件
├── storage/         # 数据存储
└── templates/       # 页面模板
```

## 核心功能

| 功能 | 说明 |
|------|------|
| 用户管理 | 注册、登录、查看个人资料 |
| 文章发布 | 创建、编辑、删除文章 |
| 文章列表 | 分页展示所有文章 |
| 搜索 | 按关键词搜索文章 |

## 开发流程

```
设计 → 编码 → 测试 → 部署
```

## 练习任务

1. 设计项目的 API 接口列表
2. 画出数据库 ER 图
3. 确定需要哪些中间件
4. 思考项目部署到服务器上的步骤

## 知识点总结

- 综合项目整合所有已学知识
- 模块化设计，职责分离
- API 优先设计 RESTful 接口
- 从简单功能开始逐步迭代

> 💡 提示：先从核心功能（如文章 CRUD）开始，确保基本功能运行后再添加高级功能。
