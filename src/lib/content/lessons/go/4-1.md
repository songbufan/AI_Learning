# Goroutine 基础

## 什么是 Goroutine

Goroutine 是 Go 的轻量级线程，由 Go 运行时调度。创建 goroutine 只需在函数调用前加 `go`：

```go
package main

import (
    "fmt"
    "time"
)

func say(msg string, delay time.Duration) {
    for i := 0; i < 3; i++ {
        fmt.Printf("[%s] 第 %d 次\n", msg, i+1)
        time.Sleep(delay)
    }
}

func main() {
    // 启动 goroutine
    go say("A", 100*time.Millisecond)
    go say("B", 200*time.Millisecond)

    // 等待足够时间让 goroutine 完成
    time.Sleep(1 * time.Second)
    fmt.Println("主 goroutine 结束")
}
```

输出：

```
[A] 第 1 次
[B] 第 1 次
[A] 第 2 次
[B] 第 2 次
[A] 第 3 次
[B] 第 3 次
主 goroutine 结束
```

## Goroutine 特性

| 特性 | 说明 |
|------|------|
| 轻量级 | 初始栈仅 2KB，可动态增长 |
| 多路复用 | 多个 goroutine 复用少量 OS 线程 |
| 快速创建 | 比系统线程快几个数量级 |
| 低切换成本 | 用户态调度，无需内核态切换 |

## Channel 基础

Channel 是 goroutine 之间的通信管道：

```go
package main

import "fmt"

func send(ch chan<- string) { // 只发送通道
    ch <- "Hello from goroutine"
}

func receive(ch <-chan string) { // 只接收通道
    msg := <-ch
    fmt.Println(msg)
}

func main() {
    // 创建无缓冲 channel
    ch := make(chan string)

    go send(ch)
    receive(ch)

    // 关闭 channel
    close(ch)
}
```

输出：

```
Hello from goroutine
```

## 知识点总结

- `go f()` 启动 goroutine
- Goroutine 是协作式调度
- Channel 是 goroutine 之间通信的桥梁
- Channel 有方向：`chan T`、`chan<- T`、`<-chan T`

> 💡 提示：Goroutine 不是线程，Go 运行时会将多个 goroutine 映射到少量 OS 线程上。
