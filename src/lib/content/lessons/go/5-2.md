# JSON 处理

## JSON 编解码

Go 的 `encoding/json` 包提供 JSON 序列化和反序列化：

```go
package main

import (
    "encoding/json"
    "fmt"
)

type User struct {
    Name  string `json:"name"`
    Age   int    `json:"age"`
    Email string `json:"email,omitempty"` // 空值时省略
}

func main() {
    // 结构体 → JSON（编码）
    user := User{
        Name:  "张三",
        Age:   28,
        Email: "zhangsan@example.com",
    }

    data, err := json.Marshal(user)
    if err != nil {
        panic(err)
    }
    fmt.Printf("JSON: %s\n", string(data))

    // 格式化 JSON
    pretty, _ := json.MarshalIndent(user, "", "  ")
    fmt.Printf("格式化 JSON:\n%s\n", string(pretty))

    // JSON → 结构体（解码）
    jsonStr := `{"name":"李四","age":32,"email":"lisi@test.com"}`
    var u User
    if err := json.Unmarshal([]byte(jsonStr), &u); err != nil {
        panic(err)
    }
    fmt.Printf("解码结果: %+v\n", u)
}
```

输出：

```
JSON: {"name":"张三","age":28,"email":"zhangsan@example.com"}
格式化 JSON:
{
  "name": "张三",
  "age": 28,
  "email": "zhangsan@example.com"
}
解码结果: {Name:李四 Age:32 Email:lisi@test.com}
```

## 处理任意 JSON

```go
package main

import (
    "encoding/json"
    "fmt"
)

func main() {
    // 动态 JSON 用 map 或 interface{}
    raw := `{"name":"Go","version":1.21,"isOpenSource":true,"tags":["fast","concurrent"]}`

    var result map[string]interface{}
    json.Unmarshal([]byte(raw), &result)

    fmt.Printf("名称: %v\n", result["name"])
    fmt.Printf("版本: %.0f\n", result["version"])
    fmt.Printf("开源: %v\n", result["isOpenSource"])

    tags := result["tags"].([]interface{})
    fmt.Printf("标签: %v\n", tags)
}
```

输出：

```
名称: Go
版本: 1
开源: true
标签: [fast concurrent]
```

## 练习任务

1. 定义一个包含嵌套结构体的类型，进行 JSON 编解码
2. `omitempty` 标签有什么作用？
3. 处理未知结构的 JSON 时应该用什么类型？
4. JSON 中数字默认被解析为什么类型？

## 知识点总结

- `json.Marshal` / `json.Unmarshal` 编码解码
- 结构体标签 `` `json:"fieldname"` `` 控制字段名
- `omitempty` 空值省略，`-` 忽略字段
- 动态 JSON 用 `map[string]interface{}`

> 💡 提示：`json.Number` 类型可以避免数字被解析为 float64，保留原始精度。
