# 循环与迭代

## for 循环

Go 只有 `for` 一种循环，但它可以替代 C 语言中的 `while` 和 `do-while`：

```go
package main

import "fmt"

func main() {
    // 经典 for 循环
    for i := 0; i < 5; i++ {
        fmt.Printf("第 %d 次\n", i+1)
    }

    // while 写法（只有条件）
    count := 0
    for count < 3 {
        fmt.Printf("count = %d\n", count)
        count++
    }

    // 无限循环 + break
    sum := 0
    for {
        sum++
        if sum > 10 {
            break
        }
    }
    fmt.Printf("sum = %d\n", sum)

    // continue
    for i := 1; i <= 10; i++ {
        if i%2 != 0 {
            continue
        }
        fmt.Printf("%d ", i)
    }
    fmt.Println()
}
```

输出：

```
第 1 次
第 2 次
第 3 次
第 4 次
第 5 次
count = 0
count = 1
count = 2
sum = 11
2 4 6 8 10
```

## range 迭代

`range` 用于遍历数组、切片、映射和字符串：

```go
package main

import "fmt"

func main() {
    // 遍历切片
    nums := []int{10, 20, 30, 40, 50}
    for i, v := range nums {
        fmt.Printf("索引 %d: 值 %d\n", i, v)
    }

    // 遍历 map
    colors := map[string]string{
        "red":   "#FF0000",
        "green": "#00FF00",
        "blue":  "#0000FF",
    }
    for key, val := range colors {
        fmt.Printf("%s = %s\n", key, val)
    }

    // 遍历字符串（Unicode 字符）
    str := "Go语言"
    for i, ch := range str {
        fmt.Printf("位置 %d: %c (U+%04X)\n", i, ch, ch)
    }
}
```

输出：

```
索引 0: 值 10
索引 1: 值 20
索引 2: 值 30
索引 3: 值 40
索引 4: 值 50
red = #FF0000
green = #00FF00
blue = #0000FF
位置 0: G (U+0047)
位置 1: o (U+006F)
位置 2: 语 (U+8BED)
位置 4: 言 (U+8A00)
```

## 知识点总结

- Go 只有 `for` 循环，没有 `while`/`do-while`
- `for {}` 是无限循环
- `range` 返回索引和值，适用于切片、map、字符串
- Go 的字符串是 UTF-8 编码，range 正确处理 Unicode

> 💡 提示：Go 的 `++` 是语句而不是表达式，不能写成 `a := i++`。
