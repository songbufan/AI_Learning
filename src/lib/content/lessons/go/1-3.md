# 条件判断与分支

## if/else 语句

Go 的 `if` 语句可以在条件前执行一个初始化语句：

```go
package main

import "fmt"

func grade(score int) string {
    if score >= 90 {
        return "优秀"
    } else if score >= 75 {
        return "良好"
    } else if score >= 60 {
        return "及格"
    } else {
        return "不及格"
    }
}

func main() {
    scores := []int{95, 82, 68, 45, 78}
    for _, score := range scores {
        fmt.Printf("分数 %d: %s\n", score, grade(score))
    }

    // 带初始化的 if
    if num := 10; num%2 == 0 {
        fmt.Printf("%d 是偶数\n", num)
    } else {
        fmt.Printf("%d 是奇数\n", num)
    }
}
```

输出：

```
分数 95: 优秀
分数 82: 良好
分数 68: 及格
分数 45: 不及格
分数 78: 良好
10 是偶数
```

## switch 语句

Go 的 `switch` 非常灵活，不需要 `break`：

```go
package main

import "fmt"

func dayType(day string) string {
    switch day {
    case "周一", "周二", "周三", "周四", "周五":
        return "工作日"
    case "周六", "周日":
        return "周末"
    default:
        return "未知"
    }
}

func main() {
    days := []string{"周一", "周六", "周三", "周日"}
    for _, d := range days {
        fmt.Printf("%s → %s\n", d, dayType(d))
    }

    // switch 不带参数
    num := 3
    switch {
    case num < 0:
        fmt.Println("负数")
    case num == 0:
        fmt.Println("零")
    default:
        fmt.Println("正数")
    }
}
```

输出：

```
周一 → 工作日
周六 → 周末
周三 → 工作日
周日 → 周末
正数
```

## 练习任务

1. 写一个函数，根据月份返回该月有多少天
2. 用 switch 实现一个简单的计算器
3. 理解 Go 的 switch 为什么不需要 break
4. if 的初始化语句有哪些应用场景？

## 知识点总结

- Go 的 `if` 支持初始化语句
- `switch` 自动 break，支持多值匹配
- 条件表达式不需要括号 `()`
- 必须有 `default` 分支

> 💡 提示：Go 的条件判断不需要用括号包裹条件，但花括号 `{}` 是必须的。
