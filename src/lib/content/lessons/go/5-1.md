# 文件操作

## 读取文件

Go 的 `os` 和 `io` 包提供了丰富的文件操作 API：

```go
package main

import (
    "fmt"
    "os"
)

func main() {
    // 写入文件
    content := []byte("Hello, Go 文件操作!\n这是第二行\n")
    err := os.WriteFile("test.txt", content, 0644)
    if err != nil {
        panic(err)
    }
    fmt.Println("文件写入成功")

    // 读取整个文件
    data, err := os.ReadFile("test.txt")
    if err != nil {
        panic(err)
    }
    fmt.Printf("内容:\n%s\n", string(data))

    // 逐行读取
    file, err := os.Open("test.txt")
    if err != nil {
        panic(err)
    }
    defer file.Close()

    buf := make([]byte, 1024)
    var lines []string
    for {
        n, err := file.Read(buf)
        if err != nil {
            break
        }
        lines = append(lines, string(buf[:n]))
    }
    fmt.Printf("读取行数: %d\n", len(lines))
}
```

输出：

```
文件写入成功
内容:
Hello, Go 文件操作!
这是第二行

读取行数: 1
```

## 带缓冲的读写

```go
package main

import (
    "bufio"
    "fmt"
    "os"
)

func main() {
    // 创建带缓冲的写入器
    file, _ := os.Create("output.txt")
    defer file.Close()
    writer := bufio.NewWriter(file)

    for i := 1; i <= 5; i++ {
        fmt.Fprintf(writer, "第 %d 行: Hello Go\n", i)
    }
    writer.Flush() // 刷新缓冲区
    fmt.Println("写入完成")

    // 读取带缓冲的文件
    readFile, _ := os.Open("output.txt")
    defer readFile.Close()
    scanner := bufio.NewScanner(readFile)

    lineNum := 0
    for scanner.Scan() {
        lineNum++
        fmt.Printf("第 %d 行: %s\n", lineNum, scanner.Text())
    }
}
```

输出：

```
写入完成
第 1 行: 第 1 行: Hello Go
第 2 行: 第 2 行: Hello Go
第 3 行: 第 3 行: Hello Go
第 4 行: 第 4 行: Hello Go
第 5 行: 第 5 行: Hello Go
```

## 练习任务

1. 写一个程序，读取一个文本文件并统计行数
2. 用 `bufio` 逐行读取一个大文件
3. 比较 `os.ReadFile` 和 `bufio.Scanner` 的适用场景
4. 为什么需要 `defer file.Close()`？

## 知识点总结

- `os.ReadFile` / `os.WriteFile` 最简单，适合小文件
- `bufio.Scanner` 适合逐行处理大文件
- `defer` 确保文件关闭
- `0644` 是文件权限（Unix）

> 💡 提示：处理大文件时，务必使用流式读写（bufio），避免一次性加载到内存。
