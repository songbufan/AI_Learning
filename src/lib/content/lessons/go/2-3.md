# 指针

## 指针基础

Go 有指针，但没有指针运算（不像 C 语言）：

```go
package main

import "fmt"

func main() {
    // 普通变量
    x := 42
    fmt.Printf("x = %d, x 的地址 = %p\n", x, &x)

    // 声明指针
    var p *int = &x
    fmt.Printf("p = %p, *p = %d\n", p, *p)

    // 修改指针指向的值
    *p = 100
    fmt.Printf("修改后 x = %d\n", x)
}
```

输出：

```
x = 42, x 的地址 = 0xc0000b2008
p = 0xc0000b2008, *p = 100
修改后 x = 100
```

## 指针作为函数参数

```go
package main

import "fmt"

func swap(a, b *int) {
    *a, *b = *b, *a
}

func modify(slice *[]int) {
    *slice = append(*slice, 4, 5)
}

func main() {
    a, b := 10, 20
    fmt.Printf("交换前: a=%d, b=%d\n", a, b)
    swap(&a, &b)
    fmt.Printf("交换后: a=%d, b=%d\n", a, b)

    nums := []int{1, 2, 3}
    fmt.Printf("修改前: %v\n", nums)
    modify(&nums)
    fmt.Printf("修改后: %v\n", nums)
}
```

输出：

```
交换前: a=10, b=20
交换后: a=20, b=10
修改前: [1 2 3]
修改后: [1 2 3 4 5]
```

## new() 函数

```go
package main

import "fmt"

func main() {
    // new() 返回指针，初始化为零值
    p := new(int)
    fmt.Printf("p 指向的值: %d\n", *p) // 0

    s := new(string)
    fmt.Printf("s 指向的值: %q\n", *s) // ""
}
```

输出：

```
p 指向的值: 0
s 指向的值: ""
```

## 知识点总结

- `&` 取地址，`*` 解引用
- Go 没有指针运算，更安全
- 传指针可以修改原变量，避免大对象拷贝
- `new(T)` 返回 `*T`，零值初始化

> 💡 提示：Go 中传切片已经是指针行为，不需要手动传指针。基本类型或大结构体才需要传指针。
