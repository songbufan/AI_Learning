# 函数基础

## 函数定义

Go 的函数使用 `func` 关键字，参数类型放在变量名后面：

```go
package main

import "fmt"

// 基本函数
func add(a int, b int) int {
    return a + b
}

// 连续同类型参数可合并
func multiply(a, b int) int {
    return a * b
}

// 多返回值
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("除数不能为零")
    }
    return a / b, nil
}

// 命名返回值（自动返回）
func rectangle(width, height float64) (area, perimeter float64) {
    area = width * height
    perimeter = 2 * (width + height)
    return // 自动返回 area 和 perimeter
}

func main() {
    fmt.Printf("3 + 5 = %d\n", add(3, 5))
    fmt.Printf("4 * 6 = %d\n", multiply(4, 6))

    result, err := divide(10, 3)
    if err != nil {
        fmt.Println("错误:", err)
    } else {
        fmt.Printf("10 / 3 = %.2f\n", result)
    }

    area, peri := rectangle(5, 3)
    fmt.Printf("矩形面积: %.1f, 周长: %.1f\n", area, peri)
}
```

输出：

```
3 + 5 = 8
4 * 6 = 24
10 / 3 = 3.33
矩形面积: 15.0, 周长: 16.0
```

## 可变参数

```go
package main

import "fmt"

func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

func main() {
    fmt.Println(sum(1, 2, 3))
    fmt.Println(sum(1, 2, 3, 4, 5))

    numbers := []int{10, 20, 30}
    fmt.Println(sum(numbers...)) // 切片展开
}
```

输出：

```
6
15
60
```

## 知识点总结

- Go 函数参数类型在变量名之后
- 支持多返回值（常用于返回结果 + error）
- 支持命名返回值
- `func(args ...Type)` 定义可变参数函数

> 💡 提示：Go 社区约定，最后一个返回值应该是 `error` 类型，用于表示错误。
