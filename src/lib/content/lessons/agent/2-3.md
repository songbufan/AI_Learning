# ReAct 推理框架

## 课程简介

ReAct（Reasoning + Acting）是由 Google 在 2022 年提出的 Agent 推理框架。它的核心思想是让大语言模型交替进行**推理（Thought）**和**行动（Action）**，而不是像传统 Chain-of-Thought 那样只做推理，或者像传统 Agent 那样只做行动。

## ReAct 的核心思想

```
传统 CoT（仅推理）：
  Question → Thought → Thought → Answer

传统 Agent（仅行动）：
  Question → Action → Observation → Action → Answer

ReAct（推理 + 行动交替）：
  Question → Thought → Action → Observation → Thought → Action → Observation → Answer
```

## ReAct 的工作流程

以"巴黎的法国大革命开始于哪一年？"为例：

```
Step 1:
  Thought: 我需要查找法国大革命开始的年份
  Action: Search["法国大革命开始年份"]
  Observation: 法国大革命通常被认为开始于 1789 年

Step 2:
  Thought: 已获得答案，验证一下准确性
  Action: Finish[1789]
```

## ReAct 的 Prompt 模板

```python
REACT_PROMPT = """
你是一个智能助手，可以思考和行动。

每次回复包含以下部分：
1. Thought: 你的思考过程
2. Action: 要执行的操作（搜索/计算/查询等）
3. Action Input: 操作所需的输入
4. Observation: 观察到的结果（由系统提供）
5. 当你有足够信息时输出：Final Answer: [你的答案]

可用工具：
- Search[query]: 搜索互联网获取信息
- Calculator[expr]: 执行数学计算
- Lookup[key]: 从知识库中查找信息

问题：{question}

让我们开始：
"""
```

## 代码示例：实现一个 ReAct Agent

```python
import re
import json

class ReActAgent:
    """基于 ReAct 框架的简单 Agent"""

    def __init__(self, llm, tools):
        self.llm = llm
        self.tools = {tool["name"]: tool for tool in tools}
        self.max_steps = 5

    def _parse_output(self, text):
        """解析 LLM 输出，提取 Thought、Action、Action Input"""
        thought_match = re.search(r"Thought: (.+)", text)
        action_match = re.search(r"Action: (.+)", text)
        input_match = re.search(r"Action Input: (.+)", text)
        answer_match = re.search(r"Final Answer: (.+)", text)

        return {
            "thought": thought_match.group(1) if thought_match else None,
            "action": action_match.group(1) if action_match else None,
            "action_input": input_match.group(1) if input_match else None,
            "answer": answer_match.group(1) if answer_match else None,
        }

    def _execute_action(self, action_name, action_input):
        """执行工具调用"""
        if action_name not in self.tools:
            return f"错误：未知工具 {action_name}"

        tool = self.tools[action_name]
        if tool["type"] == "search":
            return f"搜索结果：{action_input} 的相关信息..."
        elif tool["type"] == "calculator":
            try:
                result = eval(action_input)
                return f"计算结果：{result}"
            except:
                return "计算错误：无效的表达式"
        elif tool["type"] == "lookup":
            knowledge = {
                "法国大革命": "1789 年开始",
                "美国独立": "1776 年",
                "工业革命": "18 世纪 60 年代",
            }
            return knowledge.get(action_input, "知识库中未找到该信息")

        return "未知工具类型"

    def run(self, question):
        """运行 ReAct 循环"""
        prompt = f"""你是一个智能助手，可以思考和行动。

可用工具：Search, Calculator, Lookup

问题：{question}

让我们开始一步一步思考："""

        for step in range(self.max_steps):
            response = self.llm.generate(prompt + f"\n\nStep {step + 1}:\nThought:")
            parsed = self._parse_output(response)

            if parsed["answer"]:
                return parsed["answer"]

            if parsed["action"] and parsed["action_input"]:
                observation = self._execute_action(
                    parsed["action"].strip(),
                    parsed["action_input"].strip()
                )
                prompt += f"\nThought: {parsed['thought']}\n"
                prompt += f"Action: {parsed['action']}\n"
                prompt += f"Action Input: {parsed['action_input']}\n"
                prompt += f"Observation: {observation}\n"

        return "达到最大步数，未能得出结论"


# 使用示例
```

## ReAct vs 其他框架对比

| 框架 | 推理方式 | 行动方式 | 适用场景 |
|------|----------|----------|----------|
| **ReAct** | Thought + Action 交替 | 工具调用 | 通用任务 |
| CoT | 连续推理 | 无 | 数学/逻辑推理 |
| ToT | 多路径探索 | 无 | 复杂规划问题 |
| Reflexion | 推理 + 自我反思 | 工具调用 | 需要迭代改进的任务 |

## ReAct 的优缺点

### 优点
- **可解释性强**：Thought 过程透明可见
- **纠错能力**：通过 Observation 发现错误并修正
- **灵活性强**：支持任意工具组合

### 缺点
- **消耗 Token 多**：Thought + Action + Observation 三段式输出
- **不稳定**：LLM 可能不遵循格式要求
- **速度慢**：多步推理增加响应时间

## 知识点总结

- ReAct = Reasoning（推理）+ Acting（行动）交替进行
- 每步输出：Thought → Action → Observation
- ReAct Prompt 需要明确指定输出格式
- 相比 CoT，ReAct 更适合需要外部信息的任务

> 提示：ReAct 的精髓在于"边想边做"——不要等想清楚了再行动，而是在行动中不断验证和修正思考。
