# 工具调用与 Function Calling

## 课程简介

工具使用（Tool Use）是 AI Agent 超越纯文本生成的关键能力。通过 Function Calling，LLM 可以输出结构化的工具调用请求，让 Agent 具备与外部世界交互的能力——查询数据库、发送邮件、操作 API 等。

## 什么是 Function Calling

Function Calling 是 LLM 提供商（OpenAI、Anthropic 等）提供的一种能力，允许开发者：

1. **定义工具**：向 LLM 描述可用工具的参数和用途
2. **自动选择**：LLM 根据用户请求自动判断是否需要调用工具
3. **生成参数**：LLM 自动提取调用所需的参数
4. **执行调用**：开发者代码执行工具，返回结果给 LLM

## 工具定义

### OpenAI 格式

```python
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "获取指定城市的当前天气",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "城市名称，如：北京、上海"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "温度单位"
                    }
                },
                "required": ["city"]
            }
        }
    }
]
```

### Anthropic (Claude) 格式

tools = [

## 完整的 Function Calling 流程

```python
import json

class FunctionCallingAgent:
    """支持 Function Calling 的 Agent"""

    def __init__(self, llm_client, tools):
        self.llm = llm_client
        self.tools = {t["name"]: t for t in tools}

    def call_llm(self, messages):
        """调用 LLM API"""
        response = self.llm.chat.completions.create(
            model="gpt-4",
            messages=messages,
            tools=self._format_tools(),
            tool_choice="auto",
        )
        return response.choices[0].message

    def _format_tools(self):
        """格式化工具定义"""
        return [
            {
                "type": "function",
                "function": {
                    "name": tool["name"],
                    "description": tool["description"],
                    "parameters": tool["parameters"],
                }
            }
            for tool in self.tools.values()
        ]

    def execute_tool(self, tool_call):
        """执行工具调用"""
        func_name = tool_call.function.name
        func_args = json.loads(tool_call.function.arguments)

        if func_name not in self.tools:
            return f"错误：未知工具 {func_name}"

        if func_name == "get_weather":
            return self._get_weather(func_args["city"], func_args.get("unit", "celsius"))
        elif func_name == "search_web":
            return self._search_web(func_args["query"])
        elif func_name == "send_email":
            return self._send_email(func_args["to"], func_args["subject"], func_args["body"])

        return "未知工具"

    def run(self, user_message):
        """运行 Agent 循环"""
        messages = [{"role": "user", "content": user_message}]

        while True:
            response = self.call_llm(messages)
            messages.append(response)

            if not response.tool_calls:
                return response.content

            for tool_call in response.tool_calls:
                result = self.execute_tool(tool_call)
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": result,
                })

            continue
```

## 并行工具调用

现代 LLM 支持一次请求中并行调用多个工具：

```python
# 用户问："北京和上海的天气怎么样？"

# LLM 可能同时发起两个工具调用：
tool_calls = [
    {"name": "get_weather", "args": {"city": "北京"}},
    {"name": "get_weather", "args": {"city": "上海"}},
]

# 并行执行
results = [get_weather(tc["args"]) for tc in tool_calls]
```

## 工具设计最佳实践

### 1. 清晰的描述

```python
# 不好
{"name": "search", "description": "搜索"}

# 好
{"name": "search_web",
 "description": "使用搜索引擎搜索互联网上的信息。适用于需要获取最新信息、事实数据或外部知识的问题。"}
```

### 2. 合理的参数约束

```python
{"name": "send_email", "parameters": {
    "type": "object",
    "properties": {
        "to": {"type": "string", "format": "email"},
        "priority": {
            "type": "string",
            "enum": ["low", "normal", "high"],
        }
    },
    "required": ["to"]
}}
```

### 3. 错误处理

```python
def safe_execute_tool(tool_name, args):
    try:
        result = execute_tool(tool_name, args)
        return {"status": "success", "data": result}
    except ValidationError as e:
        return {"status": "error", "message": f"参数错误：{e}"}
    except TimeoutError:
        return {"status": "error", "message": "工具调用超时"}
    except Exception as e:
        return {"status": "error", "message": f"内部错误：{str(e)}"}
```

## 安全注意事项

| 风险 | 缓解措施 |
|------|----------|
| 恶意 Prompt 注入 | 在工具层做参数验证，不信任 LLM 输出 |
| 敏感数据泄露 | 工具不返回 API key、密码等敏感信息 |
| 过度授权 | 最小权限原则，每个工具只给必要权限 |
| 无限循环 | 设置最大工具调用次数上限 |

2. 实现一个简单的工具路由器，根据 LLM 返回的 tool_calls 分发到对应的 Python 函数
3. 设计 3 个工具，让 Agent 能够完成"帮我订一杯咖啡"的任务

## 知识点总结

- Function Calling 让 LLM 从"文本生成器"变成"行动者"
- 工具定义需要清晰的名称、描述和参数 schema
- Agent 循环：LLM 判断 → 执行工具 → 返回结果 → LLM 总结
- 安全第一：永远不要信任 LLM 生成的参数，工具层必须做验证

> 提示：Function Calling 的本质是"用 LLM 做路由"——让 LLM 理解用户意图后，自动选择正确的工具并提取参数。
