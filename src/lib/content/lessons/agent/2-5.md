# 记忆系统

## 课程简介

记忆是人类智能的核心能力之一——我们能够回忆起过去的对话、记住用户的偏好、从经验中学习。AI Agent 同样需要记忆系统来维持连续性和个性化。本课时将学习如何为 Agent 设计和管理记忆系统。

## 记忆的分类

### 1. 短期记忆（Short-term Memory）

等同于人类的"工作记忆"——当前对话的上下文。

```python
# 短期记忆实现：消息列表
short_term_memory = [
    {"role": "system", "content": "你是一个 helpful assistant"},
    {"role": "user", "content": "我叫小明"},
    {"role": "assistant", "content": "你好，小明！"},
    {"role": "user", "content": "我喜欢 Python"},
    {"role": "assistant", "content": "Python 是个很棒的选择！"},
]
```

**特点**：
- 容量有限（受 LLM 上下文窗口限制）
- 临时性（对话结束即丢失）
- 高保真（包含完整细节）

### 2. 长期记忆（Long-term Memory）

等同于人类的"长期记忆"——持久化的知识和经历。

```python
# 长期记忆实现：键值存储
long_term_memory = {
    "user_profile": {
        "name": "小明",
        "age": 28,
        "interests": ["Python", "AI", "摄影"],
        "learning_goals": ["构建 AI Agent", "学习 FastAPI"],
    },
    "conversation_history": [
        {"date": "2025-01-10", "topic": "Python 基础", "summary": "学习了变量和函数"},
        {"date": "2025-01-12", "topic": "FastAPI 入门", "summary": "搭建了第一个 API"},
    ],
    "knowledge_base": {
        "python_tips": ["用列表推导式代替 for 循环", "用 f-string 格式化字符串"],
        "common_mistakes": ["忘记处理 None", "混淆 == 和 is"],
    }
}
```

**特点**：
- 容量无限（受存储限制）
- 持久化（跨会话保留）
- 需要摘要（不能全量塞入上下文）

### 3. 工作记忆（Working Memory）

Agent 在解决复杂任务时的"草稿纸"——追踪中间步骤。

```python
# 工作记忆实现：任务追踪
working_memory = {
    "current_task": "规划东京旅行",
    "sub_tasks": [
        {"id": 1, "desc": "查询机票", "status": "completed", "result": "往返 ¥3500"},
        {"id": 2, "desc": "查询酒店", "status": "in_progress"},
        {"id": 3, "desc": "规划行程", "status": "pending"},
        {"id": 4, "desc": "整理文档", "status": "pending"},
    ],
    "decisions": ["选择春秋航空（便宜）", "选择新宿地区酒店（交通便利）"],
    "constraints": ["预算 5000 元", "7 天行程", "偏好文化景点"],
}
```

## 记忆管理策略

### 信息摘要（Summarization）

当对话过长时，需要压缩记忆：

```python
def summarize_memory(messages, max_tokens=2000):
    """将长对话压缩为摘要"""
    prompt = f"""请将以下对话压缩为简洁的摘要，保留关键信息：

对话内容：
{format_messages(messages)}

摘要要求：
- 保留用户的核心需求和偏好
- 保留 Agent 做出的重要决策
- 省略重复和无关内容
- 控制在 {max_tokens} tokens 以内

摘要："""

    summary = llm.generate(prompt)
    return summary
```

### 记忆检索（Retrieval）

从长期记忆中检索相关信息：

```python
class MemoryRetriever:
    """基于关键词的简单记忆检索"""

    def __init__(self, memory_store):
        self.store = memory_store

    def search(self, query, top_k=3):
        """根据查询检索相关记忆"""
        results = []
        for key, value in self.store.items():
            score = self._similarity(query, str(value))
            if score > 0.3:
                results.append({"key": key, "value": value, "score": score})

        results.sort(key=lambda x: x["score"], reverse=True)
        return results[:top_k]

    def _similarity(self, query, text):
        """简单的关键词匹配相似度"""
        query_words = set(query.lower().split())
        text_words = set(text.lower().split())
        if not query_words:
            return 0
        return len(query_words & text_words) / len(query_words)
```

### 记忆遗忘（Forgetting）

不是所有记忆都值得保留：

```python
def forget_old_memories(memory, days_to_keep=30):
    """清理过期的短期记忆"""
    cutoff = datetime.now() - timedelta(days=days_to_keep)
    memory["short_term"] = [
        msg for msg in memory["short_term"]
        if datetime.fromisoformat(msg.get("timestamp", "")) > cutoff
    ]
    return memory
```

## 向量数据库存储

对于大量长期记忆，使用向量数据库进行语义检索：

```
记忆存储流程：
  文本 → Embedding 模型 → 向量 → 向量数据库 (Pinecone/Chroma/Qdrant)
                                                     │
检索流程：                                        │
  查询 → Embedding → 向量相似度搜索 ← ← ← ← ← ← ← ┘
       → 返回最相关的记忆片段
```

```python
# 使用 Chroma 存储记忆
import chromadb

client = chromadb.PersistentClient(path="./agent_memory")
collection = client.get_or_create_collection("long_term_memory")

def store_memory(text, metadata=None):
    """存储一段记忆"""
    embedding = embedding_model.encode(text).tolist()
    collection.add(
        documents=[text],
        embeddings=[embedding],
        metadatas=[metadata or {}],
        ids=[str(uuid.uuid4())],
    )

def recall_memory(query, top_k=5):
    """检索相关记忆"""
    query_embedding = embedding_model.encode(query).tolist()
    results = collection.query(
        query_embeddings=[query_embedding],
        n_results=top_k,
    )
    return results["documents"][0]
```

## 练习任务

1. 实现一个简单的记忆管理器，支持 `remember()` 和 `recall()` 两个方法
2. 为你的 Agent 添加"用户偏好"记忆，让它在后续对话中记住用户喜欢的内容格式
3. 设计一个记忆摘要策略，当对话超过 20 轮时自动压缩早期内容

## 知识点总结

- 短期记忆 = 对话上下文（有限、临时）
- 长期记忆 = 持久化知识（无限、需要检索）
- 工作记忆 = 任务中间状态（随任务结束清空）
- 记忆管理核心：摘要（压缩）+ 检索（相关性）+ 遗忘（清理）

> 💡 提示：好的记忆系统不是记住一切，而是在正确的时间把正确的信息呈现给 LLM。
