# 比特币脚本与智能合约

## 比特币脚本系统

比特币使用基于栈的脚本语言（Script），用于定义花费比特币的条件。它是**非图灵完备**的（出于安全考虑）。

```python
print("=== 比特币脚本类型 ===\n")

script_types = [
    ("P2PKH", "Pay-to-Public-Key-Hash", "最常用", "OP_DUP OP_HASH160 <pubkey> OP_EQUALVERIFY OP_CHECKSIG"),
    ("P2SH", "Pay-to-Script-Hash", "支持复杂条件", "OP_HASH160 <script_hash> OP_EQUAL"),
    ("Multisig", "多重签名", "多签钱包", "OP_2 <pub1> <pub2> OP_3 OP_CHECKMULTISIG"),
    ("Timelock", "时间锁", "时间条件", "OP_CHECKLOCKTIMEVERIFY OP_DROP"),
]

for abbr, full, usage, script in script_types:
    print(f"【{abbr}】({full})")
    print(f"  用途: {usage}")
    print(f"  脚本: {script}\n")
```

## 非图灵完备的意义

```python
print("=== 为什么比特币脚本是非图灵完备的？ ===\n")
print("图灵完备 → 可以执行任意计算 → 包括无限循环")
print("无限循环 → 矿工无法预知执行时间 → 网络被攻击")
print("\n比特币的设计哲学:")
print("  安全 > 灵活性")
print("  简单 > 复杂")
print("  确定性 > 通用性")
```

## 知识点总结

- Script：基于栈的、非图灵完备脚本语言
- P2PKH：最常见的交易类型
- 非图灵完备是**安全特性**，不是缺陷
- 以太坊 = 图灵完备的替代方案
