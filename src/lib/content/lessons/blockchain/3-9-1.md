# NFT 标准与元数据

## NFT 核心概念

NFT（Non-Fungible Token，非同质化代币）是区块链上**唯一、不可互换**的数字资产。

```python
print("=== NFT 三要素 ===\n")

print("1. 唯一性 — 每个 NFT 有唯一的 tokenId")
print("2. 所有权 — 链上记录，不可篡改")
print("3. 可验证 — 任何人可验证真实性和所有者")

print("\n=== ERC-721 核心接口 ===")
methods = [
    ("balanceOf(address)", "查询地址持有 NFT 数量"),
    ("ownerOf(uint256)", "查询 tokenId 的所有者"),
    ("safeTransferFrom(...)", "安全转移 NFT"),
    ("approve(...)", "授权他人转移"),
    ("tokenURI(uint256)", "获取元数据 URL"),
]

for method, desc in methods:
    print(f"  {method}: {desc}")
```

## 元数据标准

```python
print("\n=== NFT 元数据标准 (ERC-721 Metadata) ===\n")

metadata = {
    "name": "Bored Ape #1234",
    "description": "一只穿着宇航服的 bored ape",
    "image": "ipfs://QmXxx...",
    "attributes": [
        {"trait_type": "Background", "value": "Blue"},
        {"trait_type": "Fur", "value": "Robot"},
        {"trait_type": "Eyes", "value": "Laser"},
    ]
}

import json
print(json.dumps(metadata, ensure_ascii=False, indent=2))
```

## 知识点总结

- ERC-721：非同质化代币标准
- tokenId：每个 NFT 的唯一标识
- 元数据：通常存储在 IPFS，通过 tokenURI 引用
- EIP-2981：版税标准
