# 权益证明 (PoS) 与其他共识机制

## 从 PoW 到 PoS

PoW 安全但能耗巨大（比特币年耗电量 ≈ 阿根廷全国）。PoS（Proof of Stake）通过质押代币获得出块权，能耗降低 99.9%。

```python
# PoS 出块选择模拟
import random

validators = [
    {"name": "Alice", "stake": 1000},
    {"name": "Bob",   "stake": 500},
    {"name": "Carol", "stake": 300},
    {"name": "Dave",  "stake": 200},
]

total_stake = sum(v["stake"] for v in validators)
weights = [v["stake"] / total_stake for v in validators]

print("=== PoS 出块节点选择 ===\n")
print(f"总质押: {total_stake} ETH\n")

chosen = random.choices(validators, weights=weights, k=10)
for i, v in enumerate(chosen, 1):
    pct = v["stake"] / total_stake * 100
    print(f"  第{i}块: {v['name']} (质押占比 {pct:.1f}%)")
```

## 主流共识对比

```python
print("\n=== 共识机制对比 ===\n")

mechanisms = [
    ("PoW", "Bitcoin", "极高", "~7 TPS", "高", "概率性最终性"),
    ("PoS", "Ethereum 2.0", "极低", "~100 TPS", "中高", "~13 分钟最终性"),
    ("DPoS", "EOS, TRON", "低", "~1000 TPS", "中", "~3 秒最终性"),
    ("PBFT", "Hyperledger", "低", "~10000 TPS", "低", "即时最终性"),
]

for name, chain, energy, tps, dec, finality in mechanisms:
    print(f"  {name} ({chain}):")
    print(f"    能耗: {energy}, TPS: {tps}, 去中心化: {dec}")
    print(f"    最终性: {finality}\n")
```

## 知识点总结

- PoS：质押代替算力，节能但"富者越富"
- 以太坊 Merge（2022）从 PoW 切换到 PoS
- 没有完美共识：去中心化、安全、效率 三者取其二
