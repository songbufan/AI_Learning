# Solidity 语言入门

## Solidity 是什么？

Solidity 是以太坊智能合约的主流编程语言，语法类似 JavaScript，专为 EVM 设计。

```python
# Solidity 合约结构
print("=== Solidity 智能合约结构 ===\n")

contract = """
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract SimpleStorage {
    uint256 public storedData;    // 状态变量
    address public owner;         // 状态变量

    constructor(uint256 init) {   // 构造函数（部署时执行）
        storedData = init;
        owner = msg.sender;
    }

    function set(uint256 val) public {  // 写入函数
        storedData = val;
    }

    function get() public view returns (uint256) {  // 读取函数
        return storedData;
    }
}
"""
print(contract)
```

## 核心概念

```python
print("=== Solidity 核心概念 ===\n")

concepts = [
    ("状态变量", "存储在链上，永久存在"),
    ("函数", "可调用的代码块"),
    ("修饰器", "函数权限控制 (onlyOwner, whenNotPaused)"),
    ("事件", "日志记录，前端可监听"),
    ("错误处理", "require(), revert(), assert()"),
]

for name, desc in concepts:
    print(f"  {name}: {desc}")
```

## 知识点总结

- Solidity：静态类型，面向合约
- 合约不可修改（部署后）
- `msg.sender` = 当前调用者
- `require()` = 条件检查
