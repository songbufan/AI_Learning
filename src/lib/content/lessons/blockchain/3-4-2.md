# 比特币交易与 UTXO 模型

## UTXO（未花费输出）模型

比特币不跟踪"账户余额"，而是跟踪所有**未花费的交易输出**（Unspent Transaction Output）。每笔交易消耗 UTXO 并创建新的 UTXO。

```python
# UTXO 模型演示
print("=== UTXO 模型 ===\n")

# 初始 UTXO 集
utxo_set = {
    "tx1:0": {"value": 50.0, "owner": "Alice"},
    "tx1:1": {"value": 30.0, "owner": "Bob"},
}

print("当前 UTXO 集:")
for utxo, info in utxo_set.items():
    print(f"  {utxo}: {info['value']} BTC → {info['owner']}")

# Alice 创建交易
print("\n=== Alice 创建交易 ===")
print("输入: tx1:0 (50 BTC)")
print("输出1: 20 BTC → Bob")
print("输出2: 29.99 BTC → Alice (找零, 手续费 0.01)")

new_utxo = {
    "tx1:1": {"value": 30.0, "owner": "Bob"},
    "tx2:0": {"value": 20.0, "owner": "Bob"},
    "tx2:1": {"value": 29.99, "owner": "Alice"},
}

print("\n新 UTXO 集:")
for utxo, info in new_utxo.items():
    print(f"  {utxo}: {info['value']} BTC → {info['owner']}")
```

## 账户模型 vs UTXO

```python
print("\n=== 两种模型对比 ===\n")

print("UTXO（比特币）:")
print("  优点: 并行处理、隐私性好、验证简单")
print("  缺点: 智能合约复杂、存储开销大")

print("\n账户模型（以太坊）:")
print("  优点: 直观、合约友好、存储高效")
print("  缺点: 需要 nonce 防重放、状态复杂")
```

## 知识点总结

- UTXO = 比特币的核心数据模型
- 每笔交易 = 消耗旧 UTXO + 创建新 UTXO
- 找零输出：发送方自己接收剩余资金
- UTXO 集：全网所有未花费输出的集合
