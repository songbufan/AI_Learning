# Checks-Effects-Interactions 模式

## CEI 模式

防止重入攻击的黄金法则：**先改状态，再交互**。

```python
print("=== CEI 模式 ===\n")

print("正确顺序:")
print("  1. Checks — 检查条件 (require)")
print("  2. Effects — 更新状态变量")
print("  3. Interactions — 与外部合约交互 (call/transfer)")

print("\n示例:")
code = """
function withdraw() public {
    uint256 amount = balances[msg.sender];
    require(amount > 0, "余额不足");

    balances[msg.sender] = 0;  // ← 先更新状态！

    (bool ok, ) = msg.sender.call{value: amount}("");
    require(ok);
}
"""
print(code)

print("为什么安全？")
print("  状态在转账前已更新 → 即使重入，余额 = 0")
```

## 知识点总结

- CEI = Checks → Effects → Interactions
- OpenZeppelin 的 `nonReentrant` 修饰器
- 永远先更新状态，再与外部交互
