# 去中心化存储 (IPFS)

## IPFS 原理

IPFS（InterPlanetary File System）是去中心化的内容寻址存储网络。

```python
print("=== IPFS 核心概念 ===\n")

print("传统 HTTP:")
print("  地址 = 服务器位置 (IP + 路径)")
print("  问题: 中心化、单点故障")

print("\nIPFS:")
print("  地址 = 内容哈希 (CID)")
print("  优点: 去中心化、内容寻址、不可篡改")

print("\n=== IPFS 工作流程 ===")
steps = [
    "1. 文件添加到 IPFS 网络",
    "2. 系统计算文件 CID (Content Identifier)",
    "3. 文件分片存储在网络节点",
    "4. 通过 CID 可从任何节点获取",
]
for step in steps:
    print(f"  {step}")
```

## 在 DApp 中的应用

```python
print("\n=== IPFS 在 DApp 中的应用 ===\n")

applications = [
    "NFT 元数据存储",
    "DApp 前端静态资源托管",
    "去中心化网页 (IPNS + DNSLink)",
    "大型文件存储（与 Filecoin 结合）",
]

for app in applications:
    print(f"  - {app}")
```

## 知识点总结

- IPFS = 内容寻址，非位置寻址
- CID = 文件内容的唯一标识符
- Filecoin = IPFS 的激励层存储市场
- 需要 "pin" 才能持久化
