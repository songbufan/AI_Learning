# 数字签名

## 数字签名原理

数字签名是区块链交易安全的核心机制，它确保了三件事：
1. **身份认证** — 证明交易是谁发起的
2. **不可否认** — 发送者无法抵赖
3. **完整性** — 交易内容未被篡改

```python
# 数字签名流程（模拟 ECDSA）
import hashlib

class DigitalSignature:
    @staticmethod
    def sign(message, private_key):
        """用私钥对消息签名"""
        combined = message + private_key
        return hashlib.sha256(combined.encode()).hexdigest()[:16]
    
    @staticmethod
    def verify(message, signature, public_key):
        """用公钥验证签名"""
        expected = hashlib.sha256((message + public_key).encode()).hexdigest()[:16]
        return signature == expected

# === 场景：Alice 发送交易 ===
alice_private = "alice_secret_key"
alice_public = "alice_public_key"
transaction = "Alice 转给 Bob 10 BTC，手续费 0.001 BTC"

# 步骤1：Alice 用私钥签名
sig = DigitalSignature.sign(transaction, alice_private)
print(f"交易内容: {transaction}")
print(f"数字签名: {sig}")

# 步骤2：交易广播到网络
print("\n交易广播到区块链网络...")

# 步骤3：矿工用 Alice 的公钥验证签名
is_valid = DigitalSignature.verify(transaction, sig, alice_public)
print(f"矿工验证签名: {is_valid}")

if is_valid:
    print("✓ 签名有效，交易可以被打包进区块")
else:
    print("✗ 签名无效，交易被拒绝")

# 步骤4：Bob 收到交易，确认是 Alice 发的
print(f"\nBob 确认发送方: {alice_public[:20]}...（Alice 的公钥）")
```

## 比特币交易结构

```python
# 比特币原始交易（简化版）
bitcoin_tx = {
    "版本": 1,
    "输入": [
        {
            "前一笔交易ID": "abcd1234...",
            "输出索引": 0,
            "解锁脚本": f"sig={sig} pubkey={alice_public}",
        }
    ],
    "输出": [
        {
            "金额": 10_000_000,  # 单位: satoshi (1 BTC = 100,000,000 satoshi)
            "锁定脚本": f"OP_DUP OP_HASH160 {alice_public} OP_EQUALVERIFY OP_CHECKSIG",
        }
    ],
    "锁定时间": 0,
}

print("比特币交易结构:")
print(f"  输入数量: {len(bitcoin_tx['输入'])}")
print(f"  输出数量: {len(bitcoin_tx['输出'])}")
print(f"  总输出: {bitcoin_tx['输出'][0]['金额'] / 1e8:.8f} BTC")
```

## 练习任务

1. 了解 ECDSA 椭圆曲线签名算法（secp256k1）
2. 理解比特币地址的生成过程（私钥 → 公钥 → 地址）
3. 了解"签名哈希类型"（SIGHASH）的作用

## 知识点总结

- 数字签名 = 私钥签名 + 公钥验签
- 确保交易不可伪造、不可抵赖
- 比特币使用 ECDSA（椭圆曲线数字签名算法）
- 每笔交易都需要签名，矿工负责验证
