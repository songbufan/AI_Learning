# ERC 标准与代币

## 什么是 ERC？

ERC（Ethereum Request for Comments）是以太坊社区提出的技术标准。遵循 ERC 标准确保你的代币/合约能与钱包、交易所、DEX 等生态工具兼容。

```python
# 主要 ERC 标准概览
print("=== 以太坊核心 ERC 标准 ===\n")

ercs = [
    {
        "name": "ERC-20",
        "type": "同质化代币",
        "用途": "加密货币、治理代币、稳定币",
        "核心函数": "transfer, approve, transferFrom, balanceOf",
        "案例": "USDT, USDC, UNI, AAVE",
        "特点": "每枚代币价值完全相同，可分割",
    },
    {
        "name": "ERC-721",
        "type": "非同质化代币 (NFT)",
        "用途": "数字艺术品、收藏品、域名",
        "核心函数": "transferFrom, approve, ownerOf, tokenURI",
        "案例": "CryptoPunks, BAYC, ENS",
        "特点": "每个 tokenId 唯一，不可分割",
    },
    {
        "name": "ERC-1155",
        "type": "多代币标准",
        "用途": "游戏道具、批量 NFT、混合代币",
        "核心函数": "safeTransferFrom (支持批量)",
        "案例": "Axie Infinity, ENS",
        "特点": "同合约内支持多种代币类型",
    },
    {
        "name": "ERC-4626",
        "type": "代币化金库",
        "用途": "DeFi 收益聚合器",
        "核心函数": "deposit, withdraw, totalAssets",
        "案例": "Yearn Finance vaults",
        "特点": "标准化收益金库接口",
    },
]

for erc in ercs:
    print(f"【{erc['name']}】{erc['type']}")
    print(f"  用途: {erc['用途']}")
    print(f"  核心函数: {erc['核心函数']}")
    print(f"  案例: {erc['案例']}")
    print(f"  特点: {erc['特点']}\n")
```

## ERC-20 接口详解

```python
# ERC-20 完整接口
print("=== ERC-20 接口 ===\n")

erc20_interface = """
// 查询
function name() public view returns (string)        // 代币名称 "USD Coin"
function symbol() public view returns (string)      // 符号 "USDC"
function decimals() public view returns (uint8)      // 小数位 6
function totalSupply() public view returns (uint256) // 总供应量
function balanceOf(address) public view returns (uint256)  // 查询余额
function allowance(address, address) public view returns (uint256) // 授权额度

// 操作（会触发 Transfer 事件）
function transfer(address to, uint256 amount) public returns (bool)   // 转账
function approve(address spender, uint256 amount) public returns (bool) // 授权
function transferFrom(address from, address to, uint256 amount) public returns (bool) // 授权转账
"""
print(erc20_interface)

print("=== 必须触发的事件 ===")
print("  event Transfer(address indexed from, address indexed to, uint256 value)")
print("  event Approval(address indexed owner, address indexed spender, uint256 value)")
```

## 知识点总结

- ERC 标准：以太坊生态的"接口协议"
- ERC-20：同质化代币（每枚相同）
- ERC-721：非同质化代币（每枚唯一）
- ERC-1155：多代币标准（一个合约多种代币）
- OpenZeppelin：经过审计的合约库，行业标准
