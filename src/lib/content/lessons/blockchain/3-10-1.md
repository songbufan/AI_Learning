# DeFi 核心概念

## DeFi（去中心化金融）概述

DeFi 的目标是在区块链上重建传统金融系统，但去掉银行、券商等中间商，实现**无需许可、透明、可组合**的金融服务。

```python
# DeFi 核心组件
print("=== DeFi 乐高积木 ===\n")

components = {
    "去中心化交易所 (DEX)": {
        "代表": "Uniswap, Curve, Balancer",
        "机制": "自动做市商 (AMM) — 流动性池 + 恒定乘积公式",
        "创新": "任何人都可以成为流动性提供者赚取手续费",
    },
    "借贷协议": {
        "代表": "Aave, Compound, MakerDAO",
        "机制": "超额抵押 + 资金池 + 动态利率",
        "创新": "存款生息，抵押借贷，实时清算",
    },
    "稳定币": {
        "代表": "USDT, USDC, DAI",
        "类型": "法币抵押 / 加密超额抵押 / 算法稳定",
        "创新": "无国界、全天候、无需银行账户",
    },
    "收益聚合器": {
        "代表": "Yearn Finance, Beefy Finance",
        "机制": "自动在多个协议间分配资产以最大化收益",
        "创新": "一键理财，自动复投",
    },
}

for name, info in components.items():
    print(f"【{name}】")
    for k, v in info.items():
        print(f"  {k}: {v}")
    print()
```

## DeFi 数据示例

```python
# DeFi 关键数据（示例）
print("=== DeFi 市场数据示例 ===\n")

defi_stats = {
    "总锁仓量 (TVL)": "$95B+",

for metric, value in defi_stats.items():
    print(f"  {metric}: {value}")

print("\n=== 主要 DeFi 协议 TVL ===")

    ("Lido (流动性质押)", "$28B"),
    ("Aave (借贷)", "$12B"),

    ("Uniswap (DEX)", "$5B"),

for name, tvl in protocols:
    print(f"  {name}: {tvl}")
```

## 知识点总结

- DeFi = 金融乐高，可组合性是核心优势
- AMM：用数学公式替代订单簿
- 超额抵押：借贷需要抵押品价值 > 借款价值
- 无常损失：LP 提供流动性时因价格变化产生的机会成本
