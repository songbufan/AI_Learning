# ERC 标准与代币

## ERC 标准概览

ERC（Ethereum Request for Comments）是以太坊的代币和合约接口标准。

```python
print("=== 主要 ERC 标准 ===\n")

ercs = [
    ("ERC-20", "同质化代币", "USDT, USDC, UNI", "transfer, approve, balanceOf"),
    ("ERC-721", "非同质化代币 (NFT)", "BAYC, CryptoPunks", "transferFrom, ownerOf, tokenURI"),
    ("ERC-1155", "多代币标准", "Axie Infinity", "safeTransferFrom (批量)"),
    ("ERC-4626", "代币化金库", "Yearn vaults", "deposit, withdraw, totalAssets"),
]

for name, type_, example, funcs in ercs:
    print(f"【{name}】{type_}")
    print(f"  案例: {example}")
    print(f"  核心: {funcs}\n")
```

## ERC-20 接口

```python
print("=== ERC-20 核心接口 ===\n")

print("查询函数:")
print("  name() → 代币名称")
print("  symbol() → 符号")
print("  decimals() → 小数位")
print("  totalSupply() → 总供应量")
print("  balanceOf(addr) → 查询余额")

print("\n操作函数（触发 Transfer 事件）:")
print("  transfer(to, amount) → 转账")
print("  approve(spender, amount) → 授权")
print("  transferFrom(from, to, amount) → 授权转账")

print("\n必须触发的事件:")
print("  event Transfer(address indexed from, address indexed to, uint256 value)")
print("  event Approval(address indexed owner, address indexed spender, uint256 value)")
```

## 知识点总结

- ERC-20：同质化（每枚相同）
- ERC-721：非同质化（每枚唯一）
- ERC-1155：批量多代币
- OpenZeppelin：经过审计的合约库
