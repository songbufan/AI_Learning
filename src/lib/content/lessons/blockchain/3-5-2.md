# 以太坊账户模型与 Gas 机制

## 以太坊账户模型

以太坊使用**账户模型**，每个地址有独立的账户状态（余额、nonce、合约代码、存储等）。

```python
print("=== 以太坊账户类型 ===\n")

accounts = {
    "EOA (外部账户)": {
        "控制方": "私钥",
        "有代码": "否",
        "可发送交易": "是",
        "类比": "银行账户",
    },
    "CA (合约账户)": {
        "控制方": "代码逻辑",
        "有代码": "是",
        "可发送交易": "只能被调用",
        "类比": "自动售货机",
    },
}

for acc_type, props in accounts.items():
    print(f"【{acc_type}】")
    for k, v in props.items():
        print(f"  {k}: {v}")
    print()

# Nonce
print("=== Nonce（交易序号）===")
print("每个 EOA 有一个 nonce，每笔交易 nonce+1")
print("矿工按 nonce 顺序执行 → 防止重放攻击")
```

## Gas 机制

```python
print("=== Gas 机制 ===\n")

print("Gas 三要素:")
print("  1. Gas Limit — 愿意支付的最大 Gas (普通转账: 21,000)")
print("  2. Gas Price — 每单位 Gas 价格 (Gwei)")
print("  3. Gas Used — 实际消耗")

# 手续费计算
gas_limit = 21000
gas_price = 20  # Gwei
fee = gas_limit * gas_price / 1e9
print(f"\n普通转账手续费: {fee:.6f} ETH")
print(f"（按 $3000/ETH 计算 ≈ ${fee * 3000:.2f}）")
```

## 知识点总结

- EOA（用户）+ CA（合约）= 账户模型
- Nonce 保证交易顺序和唯一性
- Gas 防止 EVM 无限循环
- 手续费 = Gas Used × Gas Price
