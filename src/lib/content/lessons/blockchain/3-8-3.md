# 全栈 DApp 架构

## DApp 技术栈全景

构建一个完整的 DApp 需要多层技术栈：

```python
print("=== 典型 DApp 技术栈 ===\n")

stack = {
    "前端层": {
        "框架": "React / Next.js / Vue",
        "Web3 库": "Ethers.js / Wagmi / RainbowKit",
        "组件库": "Web3Modal / ConnectKit",
    },
    "合约层": {
        "语言": "Solidity / Vyper",
        "框架": "Hardhat / Foundry",
        "测试": "Foundry / Waffle",
        "审计": "Slither / Mythril",
    },
    "链下层": {
        "索引": "The Graph (子图)",
        "存储": "IPFS / Arweave",
        "计算": "Chainlink / Gelato",
    },
    "基础设施": {
        "节点": "Infura / Alchemy / QuickNode",
        "监控": "Tenderly / Defender",
        "部署": "Vercel / Fleek / IPFS",
    },
}

for layer, services in stack.items():
    print(f"【{layer}】")
    for name, tech in services.items():
        print(f"  {name}: {tech}")
    print()
```

## 开发流程

```python
print("=== DApp 开发流程 ===\n")

steps = [
    ("1. 设计", "定义业务逻辑、代币经济、用户流程"),
    ("2. 智能合约", "Solidity 编写 → Foundry 测试 → Slither 扫描"),
    ("3. 审计", "专业审计 + Bug Bounty"),
    ("4. 部署", "多签部署 → 时间锁 → 渐进式升级"),
    ("5. 前端", "React + Ethers.js → IPFS 部署"),
    ("6. 上线", "The Graph 索引 → 监控 → 社区治理"),
]

for step, desc in steps:
    print(f"  {step}: {desc}")
```

## 知识点总结

- DApp = 智能合约 + 前端 + 索引
- The Graph：链上数据索引，替代传统数据库
- 全栈工程：前端 + 合约 + 基础设施缺一不可
