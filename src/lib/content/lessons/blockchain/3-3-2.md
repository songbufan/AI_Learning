# 共识问题与拜占庭容错

## 分布式共识难题

在分布式系统中，多个节点需要就某个值达成一致。看似简单的"投票"问题，在存在恶意节点时会变得极其复杂。

```python
# 拜占庭将军问题（简化模拟）
import random

class General:
    def __init__(self, name, is_loyal=True):
        self.name = name
        self.is_loyal = is_loyal
        self.vote = None
    
    def vote_order(self, order="进攻"):
        if not self.is_loyal:
            # 叛徒可能发送虚假消息
            order = "撤退" if order == "进攻" else "进攻"
        self.vote = order
        return f"{self.name}: {order}"

# 3 个将军，1 个叛徒
generals = [
    General("将军A", True),
    General("将军B", True),
    General("将军C", False),  # 叛徒
]

print("=== 拜占庭将军问题 ===\n")
order = "进攻"
for g in generals:
    print(g.vote_order(order))

print("\n问题：将军B 收到两条矛盾消息")
print("  从A: '进攻'")
print("  从C: '撤退'（叛徒篡改）")
print("  无法判断谁在说谎！")
```

## BFT 容错极限

```python
print("=== 拜占庭容错 (BFT) ===\n")

# n 个节点，f 个叛徒
n, f = 7, 2  # 7 个节点，最多容忍 2 个叛徒

print(f"总节点数: n = {n}")
print(f"叛徒数: f = {f}")
print(f"诚实节点: n - f = {n - f}")
print(f"BFT 条件: 诚实节点 > 叛徒节点")
print(f"  {n - f} > {f} → {n - f > f}")
print(f"  即 n > 3f，最多容忍 ⌊(n-1)/3⌋ 个叛徒")

print("\n=== 常见共识机制容错对比 ===")
mechanisms = [
    ("PoW (比特币)", "不严格 BFT，最长链原则", "~51% 算力攻击"),
    ("PBFT", "严格 BFT", "⌊(n-1)/3⌋"),
    ("PoS (以太坊)", "弱主观 BFT", "~33% 质押攻击"),
]
for name, bft_type, limit in mechanisms:
    print(f"  {name}: {bft_type}, 容错上限: {limit}")
```

## 知识点总结

- 拜占庭容错：系统在部分节点作恶时仍能达成一致
- 容错上限：最多 ⌊(n-1)/3⌋ 个叛徒
- 区块链共识：PoW（概率性）→ PoS（经济激励）→ PBFT（确定性）
- 不同共识机制在去中心化、安全、效率之间取舍
