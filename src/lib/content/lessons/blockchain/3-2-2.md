# 对称加密与非对称加密

## 两种核心加密方式

区块链使用密码学保障交易安全，主要依赖两种加密方式：

```python
# 加密方式对比
print("=== 对称加密 vs 非对称加密 ===\n")

print("【对称加密】")
print("  加密和解密使用同一把密钥")
print("  优点：速度快，适合加密大量数据")
print("  缺点：密钥分发困难（如何安全地告诉对方密钥？）")
print("  算法：AES, DES, 3DES")
print("  场景：数据库加密、文件加密")

print("\n【非对称加密】")
print("  使用一对密钥：公钥（公开）+ 私钥（保密）")
print("  公钥加密 → 私钥解密（加密通信）")
print("  私钥签名 → 公钥验签（数字签名）")
print("  优点：解决了密钥分发问题")
print("  算法：RSA, ECDSA（比特币/以太坊使用）")
print("  场景：区块链交易签名、HTTPS 证书")
```

## 非对称加密在区块链中的应用

```python
# 模拟非对称加密的数字签名流程
import hashlib

class Wallet:
    def __init__(self, address, private_key):
        self.address = address
        self.private_key = private_key
    
    def sign(self, message):
        """用私钥对消息签名"""
        combined = message + self.private_key
        return hashlib.sha256(combined.encode()).hexdigest()[:16]
    
    @staticmethod
    def verify(message, signature, public_key):
        """用公钥验证签名"""
        expected = hashlib.sha256((message + public_key).encode()).hexdigest()[:16]
        return signature == expected

# Alice 创建钱包
alice = Wallet("0xAlice123", "alice_priv_key_xyz")

# Alice 签名一笔交易
tx = "Alice -> Bob: 10 BTC"
signature = alice.sign(tx)

print(f"交易: {tx}")
print(f"签名: {signature}")
print(f"签名者地址: {alice.address}")

# 任何人可以用 Alice 的公钥验证签名
public_key = "alice_pub_key_abc"
is_valid = Wallet.verify(tx, signature, public_key)
print(f"\n签名验证: {is_valid}")

# 如果有人篡改交易
tampered_tx = "Alice -> Bob: 999 BTC"
is_valid_tampered = Wallet.verify(tampered_tx, signature, public_key)
print(f"篡改后验证: {is_valid_tampered}（篡改被检测到！）")
```

## 知识点总结

- 对称加密：同一密钥加密解密，快但密钥分发难
- 非对称加密：公钥+私钥对，解决分发问题但速度慢
- 区块链使用非对称加密：私钥签名交易，公钥作为地址
- 私钥 = 身份，必须绝对保密
