# Solidity 语言入门

## Solidity 简介

Solidity 是以太坊智能合约的主流编程语言，语法类似 JavaScript/TypeScript，但专为区块链设计。

```python
# Solidity 合约结构解析（Python 注释形式）
print("=== Solidity 智能合约结构 ===\n")

contract_structure = """
// SPDX-License-Identifier: MIT    ← 开源协议声明
pragma solidity ^0.8.20;             ← 编译器版本

contract SimpleStorage {
    // === 状态变量（永久存储在链上）===
    uint256 public storedData;
    address public owner;

    // === 构造函数（部署时执行一次）===
    constructor(uint256 initialValue) {
        storedData = initialValue;
        owner = msg.sender;
    }

    // === 写入函数 ===
    function set(uint256 newValue) public {
        storedData = newValue;
    }

    // === 读取函数 ===
    function get() public view returns (uint256) {
        return storedData;
    }
}
"""
print(contract_structure)
```

## 智能合约核心概念

```python
# 以太坊合约关键概念
print("=== 智能合约核心概念 ===\n")

concepts = [
    ("状态变量", "存储在链上，永久存在", "uint256 public count"),
    ("函数", "可调用的代码块", "function add(uint256 x) public"),
    ("修饰器", "函数权限控制", "modifier onlyOwner()"),
    ("事件", "日志记录，前端可监听", "event Transfer(address, address, uint256)"),
    ("修饰符", "function 的行为修饰", "public, private, view, pure"),
    ("错误", "异常处理", "require(), revert(), assert()"),
]

for name, desc, example in concepts:
    print(f"  {name}: {desc}")
    print(f"    示例: {example}\n")
```

## 知识点总结

- Solidity：静态类型、面向合约的语言
- 合约部署后不可修改（不可变性）
- Gas 成本：存储操作最贵，计算次之，内存最便宜
- `msg.sender`：当前调用者地址
- `require()`：条件检查，不满足则 revert
