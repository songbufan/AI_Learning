# 以太坊架构

## 以太坊 vs 比特币

以太坊不是比特币的升级版，而是完全不同的设计哲学：比特币是"数字黄金"（记账系统），以太坊是"世界计算机"（可编程平台）。

```python
# 以太坊核心架构概览
print("=== 以太坊核心组件 ===\n")

components = {
    "账户模型": {
        "EOA (外部账户)": "由私钥控制，普通用户",
        "CA (合约账户)": "由代码控制，部署后不可改",
        "区别": "比特币是 UTXO，以太坊是账户余额",
    },
    "EVM (以太坊虚拟机)": {
        "性质": "图灵完备的分布式虚拟机",
        "作用": "执行智能合约代码",
        "Gas": "每步操作收费，防止无限循环",
    },
    "状态树": {
        "类型": "Merkle Patricia Trie",
        "内容": "所有账户的状态快照",
        "作用": "轻客户端可验证任意账户状态",
    },
    "交易": {
        "类型": "转账 / 合约调用 / 合约部署",
        "字段": "from, to, value, data, gas, nonce",
        "签名": "ECDSA 签名，secp256k1 曲线",
    },
}

for category, details in components.items():
    print(f"【{category}】")
    for k, v in details.items():
        print(f"  {k}: {v}")
    print()
```

## Gas 机制

```python
# Gas 机制演示
print("=== Gas 机制 ===\n")

operations = [
    ("加法", 3, "2 个值 + 存储结果"),
    ("乘法", 5, "比加法更消耗 Gas"),
    ("存储 (SSTORE)", 20000, "写入状态最昂贵"),
    ("SHA3 哈希", 30, "密码学运算"),
    ("日志事件", 375, "触发事件通知"),
]

print("常见 EVM 操作 Gas 消耗:")
for op, gas, note in operations:
    print(f"  {op}: {gas} Gas ({note})")

# Gas 计算示例
gas_limit = 21000  # 普通转账的 Gas Limit
gas_price_gwei = 20  # Gwei
tx_fee_eth = gas_limit * gas_price_gwei / 1e9

print(f"\n普通转账手续费:")
print(f"  Gas Limit: {gas_limit}")
print(f"  Gas Price: {gas_price_gwei} Gwei")
print(f"  手续费: {tx_fee_eth:.6f} ETH (~${tx_fee_eth * 3000:.2f})")
```

## 知识点总结

- 以太坊 = 账户模型 + EVM + 智能合约
- EVM：图灵完备但受 Gas 限制
- Gas 机制：防止滥用，矿工按 Gas 收费
- 状态 Trie：高效存储和验证全节点状态
