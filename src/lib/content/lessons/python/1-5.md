# 字符串基础

## 什么是字符串？

字符串（String）是由**字符组成的序列**，用于表示文本。在 Python 中，字符串用引号包围。

```python
# 单引号
name = '小明'

# 双引号
greeting = "Hello"

# 三引号（多行字符串）
message = """这是一个
多行字符串"""
```

## 字符串拼接

使用 `+` 运算符拼接字符串：

```python
first = "Hello"
second = "World"
result = first + ", " + second + "!"
print(result)  # Hello, World!
```

## f-string 格式化（推荐）

f-string 是 Python 3.6+ 引入的格式化方式，使用 `f` 前缀：

```python
name = "小明"
age = 25

# 使用 f-string
message = f"我是{name}，今年{age}岁"
print(message)  # 我是小明，今年25岁
```

## 字符串常用方法

### 查找和统计

```python
text = "Hello, Python!"

# 查找子串位置
print(text.find("Python"))   # 7
print(text.find("Java"))     # -1（未找到）

# 统计字符出现次数
print(text.count("l"))       # 2
```

### 大小写转换

```python
text = "Hello, World!"

print(text.upper())      # HELLO, WORLD!
print(text.lower())      # hello, world!
print(text.title())      # Hello, World!
print(text.capitalize()) # Hello, world!
```

### 去除空白

```python
text = "  Hello, World!  "

print(text.strip())      # "Hello, World!"
print(text.lstrip())     # "Hello, World!  "
print(text.rstrip())     # "  Hello, World!"
```

### 字符串替换

```python
text = "I like Python"
print(text.replace("Python", "Java"))  # I like Java
```

### 字符串分割

```python
text = "apple,banana,orange"
fruits = text.split(",")
print(fruits)  # ['apple', 'banana', 'orange']
```

## 在编辑器中练习

```python
# 字符串操作
greeting = "Hello"
name = "Python"

# 字符串拼接
message = greeting + ", " + name + "!"
print(message)

# f-string 格式化（推荐）
print(f"{greeting}, {name}!")
```

## 知识点总结

- 字符串用单引号、双引号或三引号包围
- `+` 用于字符串拼接
- f-string（`f"..."`）是最推荐的格式化方式
- 常用方法：`upper()`、`lower()`、`strip()`、`replace()`、`split()`
- 字符串是不可变的（immutable），方法返回新字符串
