# datetime 模块

## 什么是 datetime？

`datetime` 模块提供处理日期和时间的类，用于：
- 获取当前时间
- 日期计算（加减天数）
- 日期格式化
- 时间差计算

## 核心类

| 类 | 说明 | 示例 |
|----|------|------|
| `datetime` | 日期+时间 | `datetime(2024, 1, 15)` |
| `date` | 仅日期 | `date(2024, 1, 15)` |
| `time` | 仅时间 | `time(14, 30, 0)` |
| `timedelta` | 时间差 | `timedelta(days=7)` |

## 获取当前时间

```python
from datetime import datetime

now = datetime.now()
print(now)  # 2024-01-15 14:30:00.123456

# 格式化输出
print(now.strftime("%Y-%m-%d"))       # 2024-01-15
print(now.strftime("%H:%M:%S"))       # 14:30:00
print(now.strftime("%Y年%m月%d日"))   # 2024年01月15日
```

## 日期格式化代码

| 代码 | 说明 | 示例 |
|------|------|------|
| `%Y` | 四位年份 | `2024` |
| `%y` | 两位年份 | `24` |
| `%m` | 两位月份 | `01` |
| `%d` | 两位日期 | `15` |
| `%H` | 24小时制小时 | `14` |
| `%I` | 12小时制小时 | `02` |
| `%M` | 分钟 | `30` |
| `%S` | 秒 | `00` |
| `%A` | 星期名称 | `Monday` |
| `%B` | 月份名称 | `January` |

## 日期计算

```python
from datetime import datetime, timedelta

now = datetime.now()

# 加/减时间
tomorrow = now + timedelta(days=1)
next_week = now + timedelta(weeks=1)
yesterday = now - timedelta(days=1)

print(f"明天: {tomorrow.strftime('%Y-%m-%d')}")
print(f"下周: {next_week.strftime('%Y-%m-%d')}")
```

## 时间差计算

```python
from datetime import datetime

start = datetime(2024, 1, 1)
end = datetime(2024, 12, 31)
delta = end - start
print(delta.days)  # 365 天
```

## 在编辑器中练习

```python
# datetime 模块
from datetime import datetime, timedelta

# 获取当前时间
now = datetime.now()
print(f"当前时间: {now.strftime('%Y-%m-%d %H:%M:%S')}")

# 日期计算
tomorrow = now + timedelta(days=1)
print(f"明天: {tomorrow.strftime('%Y-%m-%d')}")

# 日期格式化
print(f"年份: {now.year}")
print(f"月份: {now.month}")
print(f"星期: {now.strftime('%A')}")
```

## 知识点总结

- `datetime.now()`：获取当前日期时间
- `datetime(year, month, day)`：创建日期对象
- `strftime()`：格式化日期为字符串
- `strptime()`：解析字符串为日期
- `timedelta`：日期时间差
- 日期加减：`date + timedelta(days=n)`
- 常用格式化：`%Y` `%m` `%d` `%H` `%M` `%S` `%A` `%B`
