# 变量与数据类型

## 什么是变量？

变量是程序中**存储数据的容器**。你可以把变量理解为一个贴着标签的盒子，里面装着数据。

```python
name = "小明"    # name 是变量名，"小明" 是变量值
age = 25         # age 是变量名，25 是变量值
```

## 变量的命名规则

- 只能包含字母、数字和下划线（`_`）
- 不能以数字开头
- 区分大小写（`name` 和 `Name` 是不同的变量）
- 不能使用 Python 关键字（如 `if`、`for`、`class` 等）

```python
# 合法的变量名
user_name = "小明"
age2 = 25
_score = 100

# 非法的变量名
# 2age = 25        # 不能以数字开头
# if = "test"      # 不能使用关键字
```

## Python 的基本数据类型

Python 有几种内置的基本数据类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | `25`、`-10`、`0` |
| `float` | 浮点数 | `3.14`、`-0.5` |
| `str` | 字符串 | `"Hello"`、`'Python'` |
| `bool` | 布尔值 | `True`、`False` |
| `NoneType` | 空值 | `None` |

## 动态类型语言

Python 是**动态类型语言**，不需要声明变量类型，赋值时自动推断：

```python
x = 10        # x 是整数
x = "Hello"   # x 现在是字符串（类型自动改变）
x = 3.14      # x 现在是浮点数
```

## 查看变量类型

使用 `type()` 函数查看变量的类型：

```python
name = "小明"
age = 25
height = 1.75
is_student = True

print(type(name))      # <class 'str'>
print(type(age))       # <class 'int'>
print(type(height))    # <class 'float'>
print(type(is_student)) # <class 'bool'>
```

## 在编辑器中练习

```python
# 创建不同类型的变量
name = "小明"
age = 25
height = 1.75
is_student = True

print(f"姓名：{name}")
print(f"年龄：{age}")
print(f"身高：{height}")
print(f"是否是学生：{is_student}")
```

## 知识点总结

- 变量是存储数据的容器
- Python 是动态类型语言，无需声明类型
- 基本类型：`int`、`float`、`str`、`bool`
- 使用 `type()` 查看变量类型
- 变量命名要有意义，遵循蛇形命名法（`user_name`）
