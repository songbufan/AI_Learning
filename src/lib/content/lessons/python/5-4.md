# 作用域

## 什么是作用域？

作用域（Scope）决定了**变量在程序中哪些地方可以被访问**。Python 中有四种作用域，遵循 LEGB 规则。

## 四种作用域

### 1. Local（局部作用域）

函数内部定义的变量，只能在函数内部访问：

```python
def my_function():
    x = 10        # 局部变量
    print(x)      # 可以访问

my_function()
# print(x)        # 报错！x 在函数外部不可见
```

### 2. Enclosing（嵌套作用域）

嵌套函数中，内层函数可以访问外层函数的变量：

```python
def outer():
    x = 10        # Enclosing 作用域

    def inner():
        print(x)  # 可以访问外层函数的 x

    inner()

outer()
```

### 3. Global（全局作用域）

函数外部定义的变量，整个文件都可以访问：

```python
x = 10           # 全局变量

def my_function():
    print(x)     # 可以访问全局变量

my_function()
```

### 4. Built-in（内置作用域）

Python 内置的变量和函数（如 `print`、`len`、`int` 等）。

## LEGB 规则

Python 查找变量的顺序：

1. **L**ocal（局部）— 函数内部
2. **E**nclosing（嵌套）— 外层函数
3. **G**lobal（全局）— 模块级别
4. **B**uilt-in（内置）— Python 内置

```python
x = "global"     # Global

def outer():
    x = "enclosing"  # Enclosing

    def inner():
        x = "local"   # Local
        print(x)      # 先找 Local → 找到 "local"

    inner()

outer()
```

## global 关键字

在函数内部修改全局变量需要使用 `global`：

```python
x = 10

def my_function():
    global x       # 声明使用全局变量 x
    x = 20         # 修改全局变量
    print(x)       # 20

my_function()
print(x)           # 20（全局变量已被修改）
```

## nonlocal 关键字

在嵌套函数中修改外层函数的变量：

```python
def outer():
    x = 10

    def inner():
        nonlocal x     # 声明使用外层函数的 x
        x = 20
        print(x)       # 20

    inner()
    print(x)           # 20（外层函数的 x 也被修改了）

outer()
```

## 在编辑器中练习

```python
# 作用域
x = 10  # 全局变量

def my_function():
    y = 20  # 局部变量
    print(f"函数内 x = {x}")  # 可以访问全局变量
    print(f"函数内 y = {y}")

my_function()
print(f"函数外 x = {x}")
# print(y)  # 这行会报错！y 是局部变量
```

## 知识点总结

- **Local**：函数内部，函数结束后销毁
- **Enclosing**：嵌套函数的外层函数
- **Global**：模块级别，整个文件可访问
- **Built-in**：Python 内置
- 查找顺序：L → E → G → B
- `global`：在函数内声明修改全局变量
- `nonlocal`：在嵌套函数内声明修改外层变量
- 尽量避免使用 `global`，优先用参数和返回值传递数据
