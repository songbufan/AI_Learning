# 第一个 Python 程序

## print() 函数

`print()` 是 Python 中最基本的输出函数，用于将内容打印到控制台。

### 基本用法

```python
print("Hello, World!")
```

运行后，控制台会显示：

```
Hello, World!
```

### 多参数输出

`print()` 可以同时输出多个内容，用逗号分隔：

```python
print("Hello", "World", "!")
```

输出：

```
Hello World !
```

注意：逗号会自动在输出内容之间添加一个空格。

### 自定义分隔符

使用 `sep` 参数可以自定义分隔符：

```python
print("2024", "01", "15", sep="-")
```

输出：

```
2024-01-15
```

### 自定义结束符

使用 `end` 参数可以自定义结尾字符（默认是换行 `\n`）：

```python
print("Hello", end=" ")
print("World")
```

输出：

```
Hello World
```

## 在编辑器中练习

在右侧编辑器中尝试运行以下代码：

```python
print("Hello, World!")
print("欢迎学习 Python！")
print("Python", "非常", "有趣", sep="❤️")
```

## 练习任务

1. 修改第一行代码，打印你自己的名字
2. 用 `print()` 输出一个表情符号 🐍
3. 尝试在一行内打印多个内容，用 `*` 作为分隔符
4. 使用 `end` 参数，让两个 print 输出在同一行

## 知识点总结

- `print()` 是 Python 最基本的输出函数
- 字符串需要用引号（单引号或双引号）包围
- 多个参数用逗号分隔，默认用空格连接
- `sep` 参数自定义分隔符
- `end` 参数自定义结尾字符（默认换行）
- Python 支持中文和 emoji

> 💡 小技巧：字符串用单引号或双引号都可以，但要保持一致。如果字符串内部包含引号，可以用另一种引号包围。
