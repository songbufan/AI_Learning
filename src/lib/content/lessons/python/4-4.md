# 字典基础

## 什么是字典？

字典（Dictionary）是 Python 中的**键值对（key-value）映射**数据结构。就像一本真正的字典，通过"键"查找"值"。

## 创建字典

```python
# 空字典
empty = {}

# 有元素的字典
student = {
    "name": "小明",
    "age": 20,
    "grade": "A",
    "city": "北京",
}
```

## 访问值

```python
student = {"name": "小明", "age": 20}

# 通过键访问
print(student["name"])       # 小明
print(student["age"])        # 20

# get() 方法 - 键不存在时返回默认值
print(student.get("city"))       # None
print(student.get("city", "未知")) # 未知（指定默认值）
```

## 添加和修改

```python
student = {"name": "小明"}

# 添加新键值对
student["age"] = 20

# 修改已有键的值
student["name"] = "小红"

print(student)  # {"name": "小红", "age": 20}
```

## 删除元素

```python
student = {"name": "小明", "age": 20, "city": "北京"}

# del - 删除指定键
del student["city"]

# pop() - 删除并返回值
age = student.pop("age")

# popitem() - 删除最后一个键值对
student.popitem()
```

## 遍历字典

```python
student = {"name": "小明", "age": 20, "city": "北京"}

# 遍历键
for key in student:
    print(key)

# 遍历值
for value in student.values():
    print(value)

# 遍历键值对
for key, value in student.items():
    print(f"{key}: {value}")
```

## 在编辑器中练习

```python
# 字典（Dictionary）— 键值对映射
student = {
    "name": "小明",
    "age": 20,
    "grade": "A",
}

# 访问值
print(student["name"])
print(student.get("age"))

# 添加/修改
student["city"] = "北京"
student["age"] = 21

# 遍历
for key, value in student.items():
    print(f"{key}: {value}")
```

2. 用 `get()` 安全地访问一个不存在的键
3. 给字典添加新键 "email"
4. 用 for 循环遍历字典，打印所有键值对
5. 计算字典中键的数量

## 知识点总结

- 字典用 `{}` 定义，键值对用 `:` 分隔
- 键（key）必须是不可变类型（字符串、数字、元组）
- 值（value）可以是任意类型
- `dict[key]` 访问，`get()` 安全访问
- `in` 检查键是否存在：`"name" in student`
- `keys()`、`values()`、`items()` 用于遍历
