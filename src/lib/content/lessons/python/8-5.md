# 封装与私有属性

## 什么是封装？

封装是 OOP 的三大特性之一（封装、继承、多态）。它将**数据**和**操作数据的方法**捆绑在一起，并隐藏内部实现细节。

## 私有属性

Python 中使用双下划线 `__` 前缀定义私有属性：

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance  # 双下划线表示私有

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            return f"存入 {amount}，余额: {self.__balance}"
        return "金额必须大于零"

    def get_balance(self):
        return self.__balance

account = BankAccount("小明", 100)
print(account.deposit(50))     # 存入 50，余额: 150
print(account.get_balance())   # 150
# print(account.__balance)     # 报错！无法直接访问
```

## Python 的私有机制

Python 的私有是**名称修饰（Name Mangling）**，不是真正的私有：

```python
class Example:
    def __init__(self):
        self.__private = 42

obj = Example()
# obj.__private     # 报错（但不是真正不可访问）
print(obj._Example__private)  # 42（名称修饰后可以访问）
```

> 约定：单下划线 `_var` 表示"内部使用，不要外部访问"（君子协定），双下划线 `__var` 表示更强的私有。

## Getter 和 Setter

通过方法控制属性的访问：

```python
class Person:
    def __init__(self, name, age):
        self.__name = name
        self.__age = age

    # Getter
    @property
    def name(self):
        return self.__name

    # Setter
    @name.setter
    def name(self, value):
        if not value:
            raise ValueError("名字不能为空")
        self.__name = value

    @property
    def age(self):
        return self.__age

    @age.setter
    def age(self, value):
        if not 0 <= value <= 150:
            raise ValueError("年龄不合法")
        self.__age = value
```

## 知识点总结

- 封装：隐藏内部细节，只暴露必要接口
- `__var`：双下划线私有（名称修饰）
- `_var`：单下划线，约定"内部使用"
- Getter/Setter：通过方法控制访问
- `@property`：将方法变为属性访问
- `@xxx.setter`：设置属性的 setter
- 封装提高代码安全性和可维护性
