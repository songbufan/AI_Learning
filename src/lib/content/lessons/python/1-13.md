# while 循环

## 什么是 while 循环？

`while` 循环在**条件为 True 时持续执行**代码块，直到条件变为 False。

## while 循环基本语法

```python
while 条件:
    # 条件为 True 时执行的代码块
    代码块
    # 通常需要修改条件变量，否则会无限循环
```

## 基本示例

```python
count = 1

while count <= 5:
    print(f"第 {count} 次循环")
    count += 1  # 重要：每次循环更新条件变量
```

输出：

```
第 1 次循环
第 2 次循环
第 3 次循环
第 4 次循环
第 5 次循环
```

## for vs while

| 特性 | for 循环 | while 循环 |
|------|----------|------------|
| 适用场景 | 已知迭代次数 | 未知迭代次数 |
| 遍历序列 | 适合 | 不太适合 |
| 条件控制 | 隐式（遍历序列） | 显式（条件表达式） |
| 无限循环风险 | 低 | 高（需手动更新条件） |

## while 循环的典型应用

### 等待用户输入

```python
answer = ""

while answer != "yes":
    answer = input("确定要退出吗？(yes/no): ")

print("已退出")
```

### 累加计算

```python
total = 0
num = 1

while num <= 100:
    total += num
    num += 1

print(f"1 到 100 的和: {total}")  # 5050
```

## 知识点总结

- `while` 在条件为 True 时持续执行
- 必须确保条件最终会变为 False，否则**无限循环**
- 循环体内通常需要更新条件变量
- 适合不知道循环次数的场景
- 可以用 `while True` + `break` 实现无限循环 + 手动退出

> 💡 安全提示：如果 while 循环运行时间过长，可以按 Ctrl+C 强制终止。
