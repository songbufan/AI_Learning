# 类与对象

## 什么是面向对象编程？

面向对象编程（OOP）是一种编程范式，将程序组织为**对象**的集合，每个对象包含**数据**（属性）和**行为**（方法）。

## 类与对象的关系

- **类（Class）**：对象的蓝图/模板，定义属性和方法
- **对象（Object）**：类的实例，是具体的实体

```python
# 类比：类 = 建筑图纸，对象 = 实际建筑
class Dog:
    pass

dog1 = Dog()  # 第一个实例
dog2 = Dog()  # 第二个实例
```

## 定义类

```python
class Dog:
    """狗类"""

    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} 汪汪叫！"

    def introduce(self):
        return f"我是 {self.name}，品种是 {self.breed}"
```

## `__init__` 构造方法

`__init__` 是类的构造方法，在创建对象时自动调用：

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name    # 实例属性
        self.breed = breed
```

## `self` 关键字

`self` 指代**实例本身**，必须作为方法的第一个参数：

```python
class Dog:
    def __init__(self, name):
        self.name = name  # self.name 是实例属性

    def bark(self):
        print(f"{self.name} 叫了")  # self 访问实例属性
```

## 创建和使用对象

```python
# 创建对象实例
dog1 = Dog("旺财", "金毛")
dog2 = Dog("来福", "柴犬")

# 调用方法
print(dog1.introduce())  # 我是 旺财，品种是 金毛
print(dog2.bark())       # 来福 汪汪叫！

# 访问属性
print(dog1.name)   # 旺财
print(dog2.breed)  # 柴犬
```

## 在编辑器中练习

```python
# 类与对象
class Dog:
    """狗类"""
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} 汪汪叫！"

    def introduce(self):
        return f"我是 {self.name}，品种是 {self.breed}"

# 创建对象实例
dog1 = Dog("旺财", "金毛")
dog2 = Dog("来福", "柴犬")

print(dog1.introduce())
print(dog2.bark())
```

## 知识点总结

- 类用 `class` 关键字定义
- `__init__` 构造方法，创建对象时自动调用
- `self` 指代实例本身，必须作为第一个参数
- 实例属性：`self.xxx = value`
- 实例方法：`def method(self, ...)`
- 创建对象：`obj = ClassName(args)`
- 调用方法：`obj.method()`
- 访问属性：`obj.attribute`
