# collections 模块

## 什么是 collections？

`collections` 模块提供了一些**高级数据结构**，是对 Python 内置数据类型的扩展。

## Counter — 计数器

统计元素出现次数：

```python
from collections import Counter

text = "hello world hello python"
counter = Counter(text.split())
print(counter)
# Counter({'hello': 2, 'world': 1, 'python': 1})

# 获取出现最多的元素
print(counter.most_common(1))  # [('hello', 2)]
```

## defaultdict — 带默认值的字典

访问不存在的键时返回默认值：

```python
from collections import defaultdict

# 默认值为列表
grades = defaultdict(list)
grades["小明"].append(90)
grades["小明"].append(85)
grades["小红"].append(95)

print(grades["小明"])  # [90, 85]
print(grades["小刚"])  # []（自动创建空列表）
```

## deque — 双端队列

高效地在两端添加/删除元素：

```python
from collections import deque

dq = deque([1, 2, 3])

# 两端操作
dq.append(4)        # 右端添加: [1, 2, 3, 4]
dq.appendleft(0)    # 左端添加: [0, 1, 2, 3, 4]
dq.pop()            # 右端删除: 4
dq.popleft()        # 左端删除: 0
```

## namedtuple — 命名元组

创建有字段名的元组：

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(10, 20)
print(p.x)    # 10
print(p.y)    # 20
```

## OrderedDict — 有序字典

保持插入顺序的字典（Python 3.7+ 中 dict 默认有序）：

```python
from collections import OrderedDict

od = OrderedDict()
od["a"] = 1
od["b"] = 2
od["c"] = 3

for key, value in od.items():
    print(f"{key}: {value}")
```

## 在编辑器中练习

```python
# collections 模块
from collections import Counter, defaultdict

# Counter：统计元素出现次数
text = "hello world hello python"
counter = Counter(text.split())
print("词频统计:")
for word, count in counter.most_common():
    print(f"  {word}: {count}")

# defaultdict：带默认值的字典
grades = defaultdict(list)
grades["小明"].append(90)
grades["小明"].append(85)
grades["小红"].append(95)

print("\n成绩记录:")
for name, scores in grades.items():
    print(f"  {name}: {scores}")
```

## 练习任务

1. 用 Counter 统计一段文本中每个字符的出现次数
2. 用 defaultdict 统计每个字母出现的行数
3. 用 deque 实现一个简单的队列（FIFO）
4. 用 namedtuple 定义一个 `Student(name, age, score)` 结构
5. 用 Counter 找出列表中出现次数最多的 3 个元素

## 知识点总结

- `Counter`：字典子类，用于计数
- `defaultdict`：访问不存在的键时返回默认值
- `deque`：双端队列，两端操作高效 O(1)
- `namedtuple`：创建有字段名的元组
- `OrderedDict`：有序字典（Python 3.7+ dict 已默认有序）
- 适合统计、缓存、队列等场景
