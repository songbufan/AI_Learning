# 可变参数

## 为什么需要可变参数？

有时候我们不知道调用函数时会传入多少个参数。可变参数允许函数接收任意数量的参数。

## *args — 可变位置参数

`*args` 接收任意数量的位置参数，在函数内部是一个**元组**：

```python
def sum_all(*args):
    """计算任意个数的和"""
    total = 0
    for num in args:
        total += num
    return total

print(sum_all(1, 2, 3))          # 6
print(sum_all(1, 2, 3, 4, 5))   # 15
print(sum_all())                 # 0
```

`*` 是解包运算符，`args` 是约定俗成的名字（可以换其他名字）。

## **kwargs — 可变关键字参数

`**kwargs` 接收任意数量的关键字参数，在函数内部是一个**字典**：

```python
def print_info(**kwargs):
    """打印任意键值对"""
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="小明", age=20, city="北京")
# 输出:
# name: 小明
# age: 20
# city: 北京
```

## 混合参数

可以将固定参数、默认参数、可变参数混合使用：

```python
def register(name, age, *hobbies, city="北京", **extra):
    """
    注册用户信息
    - name, age: 必填
    - *hobbies: 可变位置参数（爱好列表）
    - city: 默认参数
    - **extra: 可变关键字参数（其他信息）
    """
    print(f"姓名: {name}, 年龄: {age}, 城市: {city}")
    print(f"爱好: {hobbies}")
    print(f"其他: {extra}")

register("小明", 20, "编程", "阅读", "游泳", city="上海", email="xm@test.com")
```

## 参数顺序规则

函数定义时的参数顺序必须遵守：

```
1. 普通参数
2. *args
3. 默认参数
4. **kwargs
```

```python
def func(pos1, pos2, *args, default1="val", **kwargs):
    pass
```

2. 定义一个函数 `concat_strings(*strings, sep=" ")`，用分隔符拼接多个字符串
3. 定义一个函数 `create_user(name, **info)`，返回用户信息字典
4. 定义一个函数 `flexible(a, b=10, *args, **kwargs)`，打印所有接收到的参数
5. 用 `*` 解包列表作为函数参数：`func(*[1, 2, 3])`

## 知识点总结

- `*args`：接收任意数量位置参数（函数内为元组）
- `**kwargs`：接收任意数量关键字参数（函数内为字典）
- 参数顺序：普通 → `*args` → 默认 → `**kwargs`
- `*` 也用于解包：`func(*[1, 2, 3])` 等价于 `func(1, 2, 3)`
- `**` 用于解包字典：`func(**{"a": 1})` 等价于 `func(a=1)`
