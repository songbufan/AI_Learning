# 待办事项列表

## 项目概述

综合运用列表、字典、函数等知识，实现一个简单的待办事项（Todo）管理程序。

## 功能需求

1. 添加待办事项
2. 标记完成
3. 删除待办事项
4. 查看所有待办
5. 数据持久化（列表存储）

## 代码实现

```python
# 待办事项列表
todos = []

def add_task(task):
    """添加待办事项"""
    todos.append({"task": task, "done": False})
    print(f"✅ 已添加: {task}")

def complete_task(index):
    """标记完成"""
    if 0 <= index < len(todos):
        todos[index]["done"] = True
        print(f"🎉 已完成: {todos[index]['task']}")
    else:
        print("⚠️ 无效的序号")

def remove_task(index):
    """删除待办事项"""
    if 0 <= index < len(todos):
        removed = todos.pop(index)
        print(f"🗑️ 已删除: {removed['task']}")
    else:
        print("⚠️ 无效的序号")

def show_tasks():
    """显示所有待办"""
    if not todos:
        print("\n📝 暂无待办事项")
        return

    print("\n" + "=" * 30)
    print("📋 待办事项列表")
    print("=" * 30)

    for i, item in enumerate(todos):
        status = "✓" if item["done"] else "○"
        done_tag = " [已完成]" if item["done"] else ""
        print(f"  [{status}] {i + 1}. {item['task']}{done_tag}")

    print("=" * 30)

# 使用示例
add_task("学习 Python")
add_task("完成作业")
add_task("复习笔记")
show_tasks()
complete_task(1)
show_tasks()
```

## 关键知识点

- 字典列表存储结构化数据
- `enumerate()` 获取带索引的迭代
- 列表操作方法：`append()`、`pop()`
- 布尔值状态管理
