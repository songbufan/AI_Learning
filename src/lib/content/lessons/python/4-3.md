# 元组

## 什么是元组？

元组（Tuple）是 Python 中的**不可变序列**，一旦创建就不能修改。适合存储不应该改变的数据。

## 创建元组

```python
# 空元组
empty = ()

# 单元素元组（注意逗号！）
single = (42,)        # 正确，有逗号才是元组
not_tuple = (42)      # 错误，这只是整数 42

# 多元素元组
point = (10, 20)
name = ("小明", "小红", "小刚")
mixed = (1, "hello", True, 3.14)
```

## 访问元组元素

元组的索引访问与列表相同：

```python
point = (10, 20)

print(point[0])   # 10
print(point[1])   # 20
print(point[-1])  # 20（最后一个）
```

## 元组解包

元组支持解包，将元素分配给多个变量：

```python
x, y = (10, 20)
print(x)  # 10
print(y)  # 20

# 交换两个变量的值（经典用法）
a, b = 1, 2
a, b = b, a  # 交换
print(a, b)  # 2 1
```

## 元组 vs 列表

| 特性 | 元组 | 列表 |
|------|------|------|
| 可变性 | 不可变 | 可变 |
| 语法 | `()` | `[]` |
| 性能 | 更快 | 稍慢 |
| 内存 | 更小 | 稍大 |
| 适用场景 | 固定数据 | 动态数据 |

## 为什么使用元组？

1. **性能更好**：元组比列表更轻量
2. **数据保护**：不可变确保数据不被意外修改
3. **可作为字典键**：列表不能作为字典键，元组可以

```python
# 元组作为字典键
locations = {
    (0, 0): "原点",
    (1, 0): "右方",
    (0, 1): "上方",
}

print(locations[(1, 0)])  # 右方
```

## 在编辑器中练习

```python
# 元组（Tuple）— 不可变序列
point = (10, 20)

print(f"x: {point[0]}, y: {point[1]}")

# 元组解包
x, y = point
print(f"解包: x={x}, y={y}")

# 元组常用于函数返回多个值
def get_name_age():
    return "小明", 25

name, age = get_name_age()
print(f"姓名: {name}, 年龄: {age}")
```

## 练习任务

1. 创建元组 `(1, 2, 3, 4, 5)`，计算所有元素的和
2. 用元组解包交换两个变量的值
3. 创建一个表示 2D 点的元组 `(x, y)`，计算它到原点的距离
4. 用元组存储一个人的信息（姓名、年龄、城市），解包后打印
5. 尝试修改元组的元素，观察错误信息

## 知识点总结

- 元组用 `()` 定义，不可变（immutable）
- 单元素元组必须加逗号：`(42,)`
- 索引访问与列表相同
- 元组解包：`x, y = (10, 20)`
- 可用作字典键
- 性能优于列表，适合固定数据
