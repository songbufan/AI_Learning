# 自定义异常

## 为什么要自定义异常？

Python 内置的异常类型可能不足以表达特定的业务逻辑错误。自定义异常可以：
- 更精确地描述错误类型
- 提供更有意义的错误信息
- 方便调用者区分不同的错误情况

## 定义自定义异常

自定义异常需要**继承 `Exception` 类**：

```python
class AgeError(Exception):
    """年龄异常"""
    def __init__(self, age):
        self.age = age
        super().__init__(f"年龄 {age} 不合法！必须在 0-150 之间。")

# 使用自定义异常
def set_age(age):
    if not 0 <= age <= 150:
        raise AgeError(age)
    return f"年龄设置为 {age}"

try:
    print(set_age(25))
    print(set_age(-5))
except AgeError as e:
    print(f"捕获异常: {e}")
```

## 自定义异常的层次结构

```python
# 基础异常类
class AppError(Exception):
    """应用基础异常"""
    pass

# 继承基础异常
class ValidationError(AppError):
    """数据验证错误"""
    pass

class AuthError(AppError):
    """认证错误"""
    pass

# 可以统一捕获
try:
    raise ValidationError("数据格式错误")
except AppError as e:
    print(f"应用错误: {e}")
```

## 带额外信息的异常

```python
class InsufficientFundsError(Exception):
    """余额不足异常"""
    def __init__(self, balance, amount):
        self.balance = balance
        self.amount = amount
        super().__init__(
            f"余额不足：当前余额 {balance}，尝试取出 {amount}"
        )

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(balance, amount)
    return balance - amount

try:
    withdraw(100, 200)
except InsufficientFundsError as e:
    print(f"错误: {e}")
    print(f"余额: {e.balance}, 尝试取出: {e.amount}")
```

## 异常链（raise from）

```python
def parse_config(config_str):
    try:
        import json
        return json.loads(config_str)
    except json.JSONDecodeError as e:
        # 包装原始异常，保留错误链
        raise ValueError("配置文件格式错误") from e

try:
    parse_config("invalid json")
except ValueError as e:
    print(f"错误: {e}")
    print(f"原始原因: {e.__cause__}")
```

2. 定义一个 `EmailError` 异常，邮箱格式不正确时抛出
3. 写一个注册函数，验证用户名、密码、邮箱，使用自定义异常

## 知识点总结

- 自定义异常继承 `Exception` 类
- 在 `__init__` 中设置错误信息
- 可以用 `super().__init__()` 调用父类构造
- 异常层次结构便于统一捕获
- 自定义属性可以携带额外的错误信息
- `raise ... from ...` 保留异常链
- 好的异常信息帮助快速定位问题
