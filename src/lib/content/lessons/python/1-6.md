# 类型转换

## 为什么需要类型转换？

在 Python 中，不同类型的变量不能直接进行某些操作，需要进行类型转换。

```python
# 错误：字符串和数字不能直接相加
# "25" + 1  # TypeError

# 正确：先转换类型
int("25") + 1  # 26
```

## 常用类型转换函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `int()` | 转换为整数 | `int("42")` → `42` |
| `float()` | 转换为浮点数 | `float("3.14")` → `3.14` |
| `str()` | 转换为字符串 | `str(100)` → `"100"` |
| `bool()` | 转换为布尔值 | `bool(1)` → `True` |

## 字符串 ↔ 数字

```python
# 字符串 → 整数
num_str = "42"
num_int = int(num_str)
print(num_int + 1)  # 43

# 字符串 → 浮点数
float_str = "3.14"
num_float = float(float_str)
print(num_float * 2)  # 6.28

# 数字 → 字符串
num = 100
num_str = str(num)
print("数字是：" + num_str)  # 数字是：100
```

## 布尔值转换

```python
# 以下值转换为 bool 时为 False
print(bool(0))       # False
print(bool(""))      # False
print(bool(None))    # False
print(bool([]))      # False

# 其他值转换为 True
print(bool(1))       # True
print(bool("Hello")) # True
print(bool([1, 2]))  # True
```

## 在编辑器中练习

```python
# 类型转换
num_str = "42"
num_int = int(num_str)
num_float = float(num_str)

print(f"字符串: {num_str} (类型: {type(num_str).__name__})")
print(f"整数: {num_int} (类型: {type(num_int).__name__})")
print(f"浮点数: {num_float} (类型: {type(num_float).__name__})")
```

## 练习任务

1. 将字符串 `"100"` 转换为整数，然后加 50
2. 将整数 `50` 转换为字符串，然后用 `+` 拼接 `"岁"`
3. 将浮点数 `3.14159` 转换为整数（注意取整方式）
4. 用 `bool()` 函数测试 `0`、`1`、`""`、`"0"` 的布尔值

## 知识点总结

- `int()`：字符串/浮点数 → 整数
- `float()`：字符串/整数 → 浮点数
- `str()`：任意类型 → 字符串
- `bool()`：任意类型 → 布尔值
- `"123"` 和 `123` 是完全不同的类型
- 转换失败会抛出 `ValueError` 异常（如 `int("abc")`）
