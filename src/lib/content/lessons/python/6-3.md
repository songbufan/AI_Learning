# JSON 文件处理

## 什么是 JSON？

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，广泛用于 Web 开发中传输数据。

Python 的 `json` 模块提供了 JSON 和 Python 对象之间的转换能力。

## JSON 与 Python 的对应关系

| JSON | Python |
|------|--------|
| `{}` | `dict` |
| `[]` | `list` |
| `"string"` | `str` |
| `123` | `int` |
| `true/false` | `True/False` |
| `null` | `None` |

## json.dumps() — Python 转 JSON

```python
import json

person = {"name": "小明", "age": 20, "city": "北京"}

# 转换为 JSON 字符串
json_str = json.dumps(person, ensure_ascii=False)
print(json_str)  # {"name": "小明", "age": 20, "city": "北京"}

# 格式化输出（缩进）
print(json.dumps(person, ensure_ascii=False, indent=2))
```

## json.loads() — JSON 转 Python

```python
import json

json_str = '{"name": "小明", "age": 20, "city": "北京"}'

# 转换为 Python 对象
person = json.loads(json_str)
print(person["name"])  # 小明
print(person["age"])   # 20
```

## 读写 JSON 文件

```python
import json

# 写入 JSON 文件
data = {
    "users": [
        {"name": "小明", "age": 20},
        {"name": "小红", "age": 22},
    ]
}

with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读取 JSON 文件
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
    print(data["users"][0]["name"])  # 小明
```

## 在编辑器中练习

```python
# JSON 处理
import json

# Python 对象 → JSON 字符串
person = {"name": "小明", "age": 20, "city": "北京"}
json_str = json.dumps(person, ensure_ascii=False)
print(f"JSON 字符串: {json_str}")

# JSON 字符串 → Python 对象
restored = json.loads(json_str)
print(f"恢复: {restored["name"]}, {restored["age"]}岁")
```

## 知识点总结

- `json.dumps()`：Python 对象 → JSON 字符串
- `json.dump()`：Python 对象 → JSON 文件
- `json.loads()`：JSON 字符串 → Python 对象
- `json.load()`：JSON 文件 → Python 对象
- `ensure_ascii=False`：保留中文字符
- `indent=2`：格式化输出，缩进 2 空格
- JSON 是数据交换的标准格式，Web API 常用
