# random 模块

## 什么是 random 模块？

`random` 模块提供生成随机数的功能，用于模拟随机事件、游戏开发、数据抽样等场景。

## 常用函数

### randint() — 随机整数

```python
import random

# 生成 [a, b] 范围内的随机整数
num = random.randint(1, 100)
print(num)  # 1 到 100 之间的随机整数
```

### choice() — 随机选择

```python
import random

fruits = ["苹果", "香蕉", "橙子", "葡萄"]
fruit = random.choice(fruits)
print(fruit)  # 随机选一个水果
```

### shuffle() — 随机打乱

```python
import random

cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(cards)  # 随机排列
```

### sample() — 随机抽样

```python
import random

# 从列表中随机抽取 n 个不重复元素
lucky = random.sample(range(1, 50), 6)
print(lucky)  # 6 个不重复的随机数
```

## 更多随机函数

```python
import random

# random() - [0.0, 1.0) 的随机浮点数
print(random.random())

# uniform(a, b) - [a, b] 范围内的随机浮点数
print(random.uniform(1.5, 3.5))

# randrange(start, stop, step) - 范围随机整数
print(random.randrange(0, 100, 10))  # 0,10,20,...,90

# seed() - 设置随机种子（用于复现结果）
random.seed(42)
print(random.randint(1, 100))  # 每次运行结果相同
```

## 在编辑器中练习

```python
# random 模块
import random

# 生成随机整数
print(f"1-100 随机数: {random.randint(1, 100)}")

# 从列表中随机选择
fruits = ["苹果", "香蕉", "橙子", "葡萄"]
print(f"随机水果: {random.choice(fruits)}")

# 随机打乱列表
cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(f"打乱后: {cards}")
```

## 知识点总结

- `randint(a, b)`：a 到 b 的随机整数（含边界）
- `random()`：[0.0, 1.0) 随机浮点数
- `choice(seq)`：从序列中随机选一个
- `shuffle(seq)`：原地打乱序列
- `sample(population, k)`：随机抽样 k 个
- `seed(n)`：设置种子，结果可复现
- 适用于游戏、模拟、随机抽样
