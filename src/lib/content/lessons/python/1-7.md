# 代码规范与注释

## 注释

注释是代码中不会被执行的文字，用于解释代码的功能和逻辑。

### 单行注释

使用 `#` 符号：

```python
# 这是单行注释
x = 10  # 这是行末注释
```

### 多行注释

使用三个单引号或双引号：

```python
"""
这是多行注释
可以跨越多行
通常用于函数/类的文档说明
"""

'''
这也是多行注释
和上面的效果相同
'''
```

## PEP 8 — Python 代码风格指南

PEP 8 是 Python 的官方代码风格指南，主要规范：

### 缩进

- 使用 **4 个空格**缩进（不用 Tab）
- 保持缩进一致

```python
# 正确：4 个空格缩进
def greet(name):
    print(f"Hello, {name}!")

# 错误：不要混合 Tab 和空格
```

### 每行长度

- 每行不超过 **79 个字符**
- 注释和文档字符串不超过 **72 个字符**

### 运算符两侧加空格

```python
# 正确
a + b
x = 10
if x > 5:

# 不规范
a+b
x=10
if x>5:
```

### 变量命名

| 风格 | 示例 | 适用场景 |
|------|------|----------|
| 蛇形命名法 | `user_name` | 变量、函数名 |
| 大驼峰 | `UserName` | 类名 |
| 全大写+下划线 | `MAX_SIZE` | 常量 |

```python
# 变量名（蛇形命名法）
user_name = "小明"
user_age = 25

# 函数名（蛇形命名法）
def calculate_sum():
    pass

# 类名（大驼峰）
class UserAccount:
    pass

# 常量（全大写）
MAX_CONNECTIONS = 100
```

## 在编辑器中练习

```python
# 这是单行注释

"""
这是多行注释（文档字符串）
可以跨越多行
"""

# PEP 8 规范要点：
# 1. 使用 4 个空格缩进（不用 Tab）
# 2. 每行不超过 79 个字符
# 3. 运算符两边加空格

# 正确的变量命名（蛇形命名法）
user_name = "小明"
user_age = 25

print("代码规范很重要！")
```

## 知识点总结

- `#` 用于单行注释，`'''` 或 `"""` 用于多行注释
- PEP 8 是 Python 官方代码风格指南
- 缩进使用 4 个空格
- 变量和函数用蛇形命名法（`user_name`）
- 类名用大驼峰（`UserAccount`）
- 常量用全大写（`MAX_SIZE`）
- 良好的注释和命名是专业程序员的基本素养

> 💡 记住：代码写出来是给人看的，顺便给机器运行。写出清晰、易读的代码是一种美德！
