# 集合

## 什么是集合？

集合（Set）是 Python 中的**无序、不重复**的元素集合。类似数学中的集合，支持交集、并集、差集等运算。

## 创建集合

```python
# 空集合（注意：{} 是空字典，不是空集合）
empty = set()

# 有元素的集合
fruits = {"苹果", "香蕉", "橙子", "苹果"}  # 重复元素自动去重
print(fruits)  # {"苹果", "香蕉", "橙子"}
```

## 集合的特性

1. **无序**：元素没有固定顺序，不能通过索引访问
2. **不重复**：自动去重
3. **可变**：可以添加和删除元素

```python
numbers = {1, 2, 3, 2, 1}
print(numbers)  # {1, 2, 3}

# 不能通过索引访问
# numbers[0]  # TypeError！
```

## 集合运算

### 并集（`|` 或 `union()`）

两个集合的所有元素（去重）：

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)           # {1, 2, 3, 4, 5}
print(a.union(b))      # {1, 2, 3, 4, 5}
```

### 交集（`&` 或 `intersection()`）

两个集合共有的元素：

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a & b)                 # {3}
print(a.intersection(b))     # {3}
```

### 差集（`-` 或 `difference()`）

在 a 中但不在 b 中的元素：

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a - b)             # {1, 2}
print(a.difference(b))   # {1, 2}
```

### 对称差集（`^` 或 `symmetric_difference()`）

只在其中一个集合中的元素：

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a ^ b)                       # {1, 2, 4, 5}
print(a.symmetric_difference(b))   # {1, 2, 4, 5}
```

## 集合方法

```python
fruits = {"苹果", "香蕉"}

# 添加元素
fruits.add("橙子")

# 更新（添加多个元素）
fruits.update(["西瓜", "葡萄"])

# 删除元素
fruits.remove("香蕉")     # 元素必须存在，否则报错
fruits.discard("西瓜")    # 元素不存在也不报错

# 清空集合
fruits.clear()
```

## 成员检查

```python
fruits = {"苹果", "香蕉", "橙子"}

print("苹果" in fruits)      # True
print("西瓜" in fruits)      # False
```

## 在编辑器中练习

```python
# 集合（Set）— 无序不重复
fruits = {"苹果", "香蕉", "橙子", "苹果"}
print(f"去重后: {fruits}")

# 集合运算
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(f"并集: {a | b}")
print(f"交集: {a & b}")
print(f"差集: {a - b}")
```

3. 找出两个列表的相同元素和不同元素

## 知识点总结

- 集合用 `{}` 或 `set()` 创建，自动去重
- 无序，不能通过索引访问
- `|` 并集、`&` 交集、`-` 差集、`^` 对称差集
- `add()` 添加、`remove()` 删除、`discard()` 安全删除
- `in` 检查成员
- 适合去重和集合运算
