# Python 简介

## 什么是 Python？

Python 是一种**高级、解释型、通用编程语言**，由 Guido van Rossum 于 1991 年首次发布。Python 的设计哲学强调代码的可读性和简洁性，其语法允许程序员用更少的代码行表达概念。

## Python 的特点

| 特点 | 说明 |
|------|------|
| 简单易学 | 语法清晰，接近自然语言 |
| 开源免费 | 完全开源，可免费使用和分发 |
| 跨平台 | 支持 Windows、macOS、Linux 等 |
| 丰富的库 | 拥有大量第三方库，功能强大 |
| 面向对象 | 支持面向对象编程 |

## Python 的应用领域

Python 被广泛应用于多个领域：

- **Web 开发**：Django、Flask、FastAPI 等框架
- **数据科学**：NumPy、Pandas、Matplotlib
- **人工智能**：TensorFlow、PyTorch、Scikit-learn
- **自动化脚本**：文件处理、网页爬虫
- **游戏开发**：Pygame 等

## 为什么选择 Python？

> Python 是目前最受欢迎的编程语言之一，常年位居 TIOBE 编程语言排行榜前列。

- 学习曲线平缓，适合编程入门
- 社区活跃，遇到问题容易找到解决方案
- 就业市场需求大，薪资待遇优厚

## Python 的版本

目前主要有两个版本：

- **Python 2.x**：已停止维护（2020 年 1 月）
- **Python 3.x**：当前主流版本，推荐使用

本课程使用 **Python 3** 进行教学。

## 知识点总结

- Python 是一种高级、解释型编程语言
- 由 Guido van Rossum 于 1991 年创建
- 名字来源于英国喜剧团体 Monty Python
- 广泛应用于 Web、数据科学、AI 等领域
- 推荐使用 Python 3 版本
