# 文件读写基础

## 为什么需要文件操作？

程序运行时，数据存储在内存中，程序结束后数据丢失。文件操作允许我们：
- 持久化存储数据
- 读取外部数据
- 与其他程序交换数据

## open() 函数

Python 使用 `open()` 函数打开文件：

```python
file = open("test.txt", "r", encoding="utf-8")
content = file.read()
file.close()
```

## 文件打开模式

| 模式 | 说明 |
|------|------|
| `r` | 读取（默认），文件不存在报错 |
| `w` | 写入，文件存在则覆盖，不存在则创建 |
| `a` | 追加，在文件末尾添加内容 |
| `x` | 独占创建，文件存在则报错 |
| `b` | 二进制模式（`rb`、`wb`） |
| `+` | 读写模式（`r+`、`w+`） |

## with 语句（推荐）

`with` 语句自动管理文件的打开和关闭：

```python
# 写入文件
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("Hello, File!")

# 读取文件
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
```

`with` 语句的优势：
- 自动关闭文件（即使发生异常）
- 代码更简洁

## 读取方法

```python
# read() - 读取全部内容
content = f.read()

# readline() - 读取一行
line = f.readline()

# readlines() - 读取所有行，返回列表
lines = f.readlines()
```

## 写入方法

```python
# write() - 写入字符串（不会自动换行）
f.write("Hello\n")

# writelines() - 写入字符串列表
f.writelines(["line1\n", "line2\n", "line3\n"])
```

## 知识点总结

- `open()` 打开文件，`close()` 关闭文件
- `with` 语句自动管理文件关闭，推荐使用
- 模式：`r` 读取、`w` 写入（覆盖）、`a` 追加
- `encoding="utf-8"` 处理中文编码
- `read()` 读全部、`readline()` 读一行、`readlines()` 读所有行
- `write()` 写入、`writelines()` 写入多行
