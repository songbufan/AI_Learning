# 综合练习

## 练习题：学生成绩统计

结合前面学到的列表和字典知识，完成以下任务：

### 题目

你有一个学生列表，每个学生有姓名和多门课程的成绩。请完成以下操作：

1. 计算每个学生的平均分
2. 找出分数最高的学生
3. 统计每门课程的平均分
4. 找出所有不及格（<60）的成绩

### 数据

```python
students = [
    {"name": "小明", "scores": {"语文": 85, "数学": 90, "英语": 78}},
    {"name": "小红", "scores": {"语文": 92, "数学": 88, "英语": 95}},
    {"name": "小刚", "scores": {"语文": 70, "数学": 65, "英语": 80}},
    {"name": "小美", "scores": {"语文": 88, "数学": 92, "英语": 85}},
]
```

### 在编辑器中练习

```python
# 综合练习：统计学生成绩
students = [
    {"name": "小明", "scores": [85, 90, 78]},
    {"name": "小红", "scores": [92, 88, 95]},
    {"name": "小刚", "scores": [70, 65, 80]},
]

for student in students:
    name = student["name"]
    scores = student["scores"]
    avg = sum(scores) / len(scores)
    print(f"{name}: 平均分 {avg:.1f}")
```

## 数据结构选择指南

遇到问题时，如何选择合适的数据结构？

| 场景 | 推荐数据结构 | 原因 |
|------|-------------|------|
| 有序可变的列表 | `list` | 支持索引、切片、增删 |
| 固定不变的数据 | `tuple` | 不可变、性能好 |
| 键值映射 | `dict` | 快速查找、键值关联 |
| 去重/集合运算 | `set` | 自动去重、高效成员检查 |
| 不同类型混合 | `list` 或 `tuple` | 灵活性高 |

## 常见操作速查

### 列表

```python
lst = [1, 2, 3]
lst.append(4)        # 末尾添加
lst.insert(0, 0)     # 指定位置插入
lst.remove(2)        # 删除值
lst.pop()            # 删除末尾
lst.sort()           # 排序
lst.reverse()        # 反转
len(lst)             # 长度
```

### 字典

```python
d = {"a": 1}
d["b"] = 2           # 添加/修改
d.pop("a")           # 删除
d.keys()             # 所有键
d.values()           # 所有值
d.items()            # 所有键值对
len(d)               # 键值对数
```

## 在编辑器中练习

综合运用列表和字典：

```python
# 创建一个简单的通讯录
contacts = {}

# 添加联系人
contacts["小明"] = {"phone": "13800138000", "email": "xm@example.com"}
contacts["小红"] = {"phone": "13900139000", "email": "xh@example.com"}

# 查找联系人
name = "小明"
if name in contacts:
    print(f"{name}的电话: {contacts[name]['phone']}")
else:
    print(f"{name} 不在通讯录中")

# 打印所有联系人
for name, info in contacts.items():
    print(f"{name}: {info['phone']}")
```

## 知识点总结

- 列表适合有序可变数据
- 元组适合固定不变数据
- 字典适合键值映射，查找 O(1)
- 集合适合去重和成员检查
- 合理选择数据结构是高效编程的关键
- 可以组合使用多种数据结构解决复杂问题
