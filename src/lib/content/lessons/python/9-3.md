# math 模块

## 什么是 math 模块？

`math` 模块提供数学运算函数和数学常数，包括三角函数、对数、幂运算等。

## 常用数学常数

```python
import math

print(math.pi)    # 3.141592653589793（π）
print(math.e)     # 2.718281828459045（自然常数 e）
print(math.inf)   # 无穷大
print(math.nan)   # 非数字（Not a Number）
```

## 基础运算函数

```python
import math

# 绝对值
print(abs(-5))           # 5

# 幂运算（与 ** 运算符相同）
print(math.pow(2, 10))   # 1024.0
print(2 ** 10)           # 1024

# 平方根
print(math.sqrt(16))     # 4.0
```

## 取整函数

```python
import math

print(math.ceil(3.7))    # 4（向上取整）
print(math.floor(3.7))   # 3（向下取整）
print(math.trunc(3.7))   # 3（截断取整）
print(round(3.7))        # 4（四舍五入，Python 内置）
```

## 对数函数

```python
import math

# 自然对数（底数为 e）
print(math.log(math.e))       # 1.0

# 指定底数的对数
print(math.log(100, 10))      # 2.0（log₁₀100）

# log10 - 以 10 为底
print(math.log10(1000))       # 3.0

# log2 - 以 2 为底
print(math.log2(8))           # 3.0
```

## 三角函数

```python
import math

# 注意：参数为弧度（不是角度）
print(math.sin(math.pi / 2))  # 1.0
print(math.cos(0))            # 1.0
print(math.tan(math.pi / 4))  # 1.0

# 角度转弧度
rad = math.radians(180)
print(rad)                    # 3.14159...

# 弧度转角度
deg = math.degrees(math.pi)
print(deg)                    # 180.0
```

## 其他实用函数

```python
import math

# 最大公约数
print(math.gcd(12, 18))       # 6

# 最小公倍数（Python 3.9+）
print(math.lcm(4, 6))         # 12

# 阶乘
print(math.factorial(5))      # 120

# 组合数 C(n, k)
print(math.comb(5, 2))        # 10

# 排列数 P(n, k)
print(math.perm(5, 2))        # 20
```

## 在编辑器中练习

```python
# math 模块
import math

print(f"π = {math.pi}")
print(f"e = {math.e}")

# 常用函数
print(f"sqrt(16) = {math.sqrt(16)}")
print(f"ceil(3.7) = {math.ceil(3.7)}")
print(f"floor(3.7) = {math.floor(3.7)}")
print(f"2^10 = {math.pow(2, 10)}")
print(f"log(100, 10) = {math.log(100, 10)}")
```

## 知识点总结

- `math.pi`：π 常数
- `math.e`：自然常数
- `math.sqrt(x)`：平方根
- `math.pow(x, y)`：x 的 y 次方
- `math.ceil(x)`：向上取整
- `math.floor(x)`：向下取整
- `math.log(x, base)`：对数
- `math.sin/cos/tan(x)`：三角函数（x 为弧度）
- `math.gcd(a, b)`：最大公约数
- `math.factorial(n)`：阶乘
