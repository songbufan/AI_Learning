# 多态

## 什么是多态？

多态（Polymorphism）意为"多种形态"。在 OOP 中，多态指**不同类型的对象可以对相同的方法调用做出不同的响应**。

## 多态的三种形式

### 1. 方法重写（Run-time Polymorphism）

```python
class Cat:
    def speak(self):
        return "喵喵"

class Dog:
    def speak(self):
        return "汪汪"

class Cow:
    def speak(self):
        return "哞哞"

# 多态函数
def make_sound(animal):
    print(animal.speak())

make_sound(Cat())   # 喵喵
make_sound(Dog())   # 汪汪
make_sound(Cow())   # 哞哞
```

不同类型的对象传入同一个函数，调用相同的方法名 `speak()`，产生不同的行为。

## 2. 鸭子类型（Duck Typing）

Python 是动态类型语言，不关心对象的类型，只关心对象是否有需要的方法：

```python
class Cat:
    def speak(self):
        return "喵喵"

class Dog:
    def speak(self):
        return "汪汪"

# 不关心类型，只要有 speak() 方法就行
def make_sound(animal):
    print(animal.speak())

make_sound(Cat())
make_sound(Dog())
```

> "如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子。"

## 3. 抽象基类（ABC）

用 `abc` 模块强制实现多态：

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def speak(self):
        pass

class Cat(Animal):
    def speak(self):
        return "喵喵"

class Dog(Animal):
    def speak(self):
        return "汪汪"
```

## 知识点总结

- 多态：不同对象对同一方法的不同响应
- 提高代码灵活性和可扩展性
- 鸭子类型：Python 特有的多态方式
- 抽象基类（ABC）：强制子类实现特定方法
- `@abstractmethod` 定义抽象方法
- 多态 + 继承 = 强大的代码复用
