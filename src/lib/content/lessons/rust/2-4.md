# 函数

## 函数定义

使用 `fn` 关键字定义函数：

```rust
fn greet(name: &str) {
    println!("Hello, {}!", name);
}
```

## 参数与返回值

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b  // 表达式返回值（无需 return）
}
```

Rust 中函数体中的**最后一个表达式就是返回值**（注意没有分号）。如果需要提前返回，使用 `return` 关键字。

## 语句 vs 表达式

这是 Rust 的重要概念：

- **语句（Statement）**：执行操作但不返回值，以分号 `;` 结尾
- **表达式（Expression）**：计算并返回值

```rust
let x = 5;        // 语句（赋值）
let y = {         // 块表达式
    let x = 3;
    x + 1         // 表达式（无分号 = 返回值）
};
// y = 4
```

## 函数示例

```rust
fn main() {
    let result = add(10, 20);
    println!("10 + 20 = {}", result);
}

fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

## 练习任务

1. 编写函数 `is_even(n: i32) -> bool` 判断奇偶
2. 编写函数 `factorial(n: u32) -> u32` 计算阶乘
3. 编写函数返回两个整数的最大值
4. 理解语句与表达式的区别，对比 `let x = 5;` 和 `let x = { 5 }`

## 知识点总结

- `fn` 定义函数
- 参数必须声明类型
- `-> Type` 声明返回类型
- 无分号表达式 = 返回值
- Rust 中语句不返回值

> 💡 提示：Rust 的表达式导向设计让代码更灵活。if、match、循环都是表达式，可以作为值使用。
