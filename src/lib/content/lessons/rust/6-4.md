# 构建与发布

## 编译发布版本

```bash
cargo build --release
```

`--release` 启用优化编译，输出在 `target/release/` 目录。

## 完整发布流程

```bash
# 1. 检查代码
cargo check

# 2. 格式化
cargo fmt

# 3. Lint 检查
cargo clippy -- -D warnings

# 4. 运行测试
cargo test

# 5. 构建发布版本
cargo build --release

# 6. 发布到 crates.io
cargo publish
```

## Cargo.toml 发布配置

```toml
[package]
name = "todo-cli"
version = "0.1.0"
edition = "2021"
authors = ["Your Name <email@example.com>"]
description = "A command-line todo list manager"
license = "MIT"
repository = "https://github.com/username/todo-cli"
readme = "README.md"
keywords = ["cli", "todo", "productivity"]
categories = ["command-line-utilities"]
```

## crates.io

Rust 官方的包注册中心，类似 npm 的 npmjs.com：

- 搜索包：`cargo search <name>`
- 查看文档：`docs.rs/<crate-name>`
- 发布前需要账号并配置 token

## 版本管理

Rust 使用语义化版本（SemVer）：

```
MAJOR.MINOR.PATCH
  1    .   0    .   0
```

- MAJOR：不兼容的 API 修改
- MINOR：向下兼容的功能新增
- PATCH：向下兼容的问题修复

## 练习任务

1. 运行 `cargo build --release` 并查看编译产物大小
2. 运行 `cargo clippy` 修复所有警告
3. 配置 Cargo.toml 的完整元数据
4. 注册 crates.io 账号（可选）

## 知识点总结

- `cargo build --release` 优化编译
- `cargo clippy` 是 Rust 的 Lint 工具
- `cargo publish` 发布到 crates.io
- SemVer 语义化版本管理

> 💡 提示：Rust 编译的二进制文件通常比 Go 大，但 Rust 没有 GC 暂停，适合对延迟敏感的场景。
