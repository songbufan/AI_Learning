# 项目概述

## 项目简介

我们将构建一个命令行任务管理工具 `todo-cli`，这是一个经典的 Rust 入门项目。

## 功能需求

- 添加任务
- 列出所有任务
- 标记任务完成
- 删除任务
- 数据持久化到 JSON 文件

## 项目结构

```
todo-cli/
├── Cargo.toml
├── src/
│   ├── main.rs       # 入口和 CLI 解析
│   ├── models.rs     # Task 结构体、Priority 枚举
│   ├── storage.rs    # JSON 读写
│   └── commands.rs   # 增删改查逻辑
└── tests/
    └── integration_test.rs
```

## 依赖选择

```toml
[dependencies]
serde = { version = "1", features = ["derive"] }
serde_json = "1"
clap = { version = "4", features = ["derive"] }
```

- `serde`：序列化/反序列化框架
- `clap`：命令行参数解析

## CLI 设计

```
todo-cli add "学习 Rust" --priority high
todo-cli list
todo-cli complete 1
todo-cli delete 2
```

## 练习任务

1. 用 `cargo new todo-cli` 创建项目
2. 在 Cargo.toml 中添加依赖
3. 设计 Task 结构体和 Priority 枚举

## 知识点总结

- 模块系统：`mod` 声明模块
- `pub` 控制可见性
- `Cargo.toml` 管理依赖
- Derive 宏自动实现 trait

> 💡 提示：先设计数据结构，再实现功能。良好的类型设计让后续开发事半功倍。
