# 第一个 Rust 程序

## Hello World

Rust 的程序入口是 `main` 函数。新建项目后，`src/main.rs` 中会有默认代码：

```rust
fn main() {
    println!("Hello, Rust!");
}
```

## 代码解析

| 元素 | 说明 |
|------|------|
| `fn main()` | 程序入口函数 |
| `{}` | 函数体花括号 |
| `println!` | 打印宏（注意感叹号） |
| `"Hello, Rust!"` | 字符串字面量 |
| `;` | 语句结束符 |

## 宏 vs 函数

`println!` 后面的感叹号表示它是一个**宏**（macro），不是普通函数。宏在编译期展开，可以接受不定参数。

```rust
// 宏 — 编译期处理
println!("Hello, {}!", name);

// 函数 — 运行时调用
print("Hello, World!");
```

## 运行程序

```bash
cargo run
```

`cargo run` 会自动先编译再运行。如果只编译不运行，使用 `cargo build`。

## 练习任务

1. 修改 `main.rs`，打印自己的名字
2. 尝试在一行打印多行内容（使用 `\n`）
3. 使用 `cargo build` 查看编译产物位置

## 知识点总结

- `fn main()` 是程序入口
- `println!` 是宏，不是函数
- `cargo run` = 编译 + 运行
- Rust 语句以分号 `;` 结束

> 💡 提示：Rust 文件扩展名是 `.rs`。编译器严格检查代码规范，缩进用 4 个空格。
