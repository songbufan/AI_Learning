# 所有权

## 什么是所有权？

所有权（Ownership）是 Rust 最独特的特性，是 Rust 实现内存安全的核心机制，**不需要垃圾回收**。

## 三条所有权规则

1. **每个值都有一个所有者**（owner）
2. **同一时间只能有一个所有者**
3. **当所有者离开作用域，值会被丢弃**（drop）

## 作用域

Rust 中的作用域类似其他语言：

```rust
{                       // s 在这里无效，尚未声明
    let s = "hello";    // 从此处起 s 有效

    // 使用 s
    println!("{}", s);
}                       // 作用域结束，s 不再有效
```

## 移动语义（Move）

将值赋给另一个变量时，所有权会**转移**：

```rust
let s1 = String::from("hello");
let s2 = s1;           // s1 的所有权移动到 s2

// println!("{}", s1);  // 编译错误！s1 已失效
println!("{}", s2);     // OK
```

这与 Python 的引用计数不同。Rust 在编译期确定所有权，**没有运行时开销**。

## 克隆（Clone）

如果需要深度复制，使用 `clone()`：

```rust
let s1 = String::from("hello");
let s2 = s1.clone();   // 深拷贝，s1 仍有效

println!("{} {}", s1, s2);
```

## 栈上数据

栈上的数据（如整数、布尔值）可以直接复制：

```rust
let x = 5;
let y = x;        // 复制，x 仍有效

println!("x = {}, y = {}", x, y);
```

## 练习任务

1. 声明 `String`，赋值给另一个变量，观察原变量失效
2. 使用 `clone()` 复制 `String`
3. 声明整数，验证栈上数据的 Copy 行为
4. 理解为什么 `String` 需要移动而 `i32` 不需要

## 知识点总结

- 所有权在编译期确定，无 GC
- 赋值 = 移动（堆数据）
- `clone()` 显式深拷贝
- `Copy` trait：栈上数据自动复制

> 💡 提示：所有权的设计初衷是让编译器在编译期完成内存管理，零运行时开销。这是 Rust " fearless " 的基石。
