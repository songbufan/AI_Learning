# 基本数据类型

## 标量类型

Rust 有四种基本标量类型：整数、浮点数、布尔值和字符。

## 整数类型

| 长度 | 有符号 | 无符号 |
|------|--------|--------|
| 8 位 | `i8` | `u8` |
| 16 位 | `i16` | `u16` |
| 32 位 | `i32` | `u32` |
| 64 位 | `i64` | `u64` |
| 128 位 | `i128` | `u128` |
| 架构 | `isize` | `usize` |

- 有符号：`i32`（默认），范围 `-2^(n-1)` 到 `2^(n-1)-1`
- 无符号：`u32`，范围 `0` 到 `2^n - 1`

## 浮点数类型

- `f32`：32 位浮点数（单精度）
- `f64`（默认）：64 位浮点数（双精度）

## 布尔类型

```rust
let t = true;
let f: bool = false;
```

## 字符类型

```rust
let c = '字';
let heart = '❤';
```

`char` 是 Unicode 标量值，占用 4 字节。

## 数字运算

```rust
let sum = 5 + 10;
let diff = 95.5 - 4.3;
let product = 4 * 30;
let quotient = 56.7 / 32.2;
let remainder = 43 % 5;
```

## 练习任务

1. 声明 `i8` 和 `u8` 变量，打印它们的值
2. 尝试 `u8` 赋负值，观察编译错误
3. 声明 `f64` 变量，进行加减乘除运算
4. 使用 `char` 类型存储一个 emoji 表情

## 知识点总结

- 整数：`i32` 默认，`u8`、`i64` 等按需选择
- 浮点：`f64` 默认
- 布尔：`bool`，仅 `true`/`false`
- 字符：`char`，Unicode 标量，4 字节

> 💡 提示：Rust 不支持隐式类型转换。使用 `as` 关键字显式转换：`let f: f64 = x as f64`。
