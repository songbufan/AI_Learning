# 集合类型

## Vector

`Vec<T>` 是动态数组，最常用的集合类型：

```rust
let mut v: Vec<i32> = Vec::new();
v.push(1);
v.push(2);
v.push(3);
```

### 创建 Vector

```rust
// 空向量
let v: Vec<i32> = Vec::new();

// 带初始值
let v = vec![1, 2, 3];

// 重复值
let v = vec![0; 5];  // [0, 0, 0, 0, 0]
```

### 访问元素

```rust
let v = vec![1, 2, 3];

println!("{}", v[0]);          // 索引访问（可能 panic）
println!("{}", v.get(0).unwrap());  // 安全访问
```

### 遍历

```rust
for i in &v {
    println!("{}", i);
}

// 可变遍历
for i in &mut v {
    *i += 10;
}
```

## HashMap

键值对映射，键必须实现 `Eq + Hash`：

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();

scores.insert(String::from("小明"), 90);
scores.insert(String::from("小红"), 95);
```

### 访问

```rust
let name = String::from("小明");
let score = scores.get(&name);  // Option<&i32>
```

### entry API

```rust
scores.entry(String::from("小明")).or_insert(70);
```

## 练习任务

1. 创建 Vec 并 push 5 个整数
2. 遍历 Vec 计算总和和平均值
3. 创建 HashMap 存储学生成绩
4. 使用 `entry().or_insert()` 安全插入

## 知识点总结

- `Vec<T>`：动态数组，推荐优先使用
- `HashMap<K,V>`：键值映射，键需实现 Hash
- 索引访问可能 panic，`get()` 返回 Option 更安全
- `entry().or_insert()` 处理已存在的键

> 💡 提示：Rust 标准库集合丰富。遇到哈希冲突时，HashMap 使用随机种子防止 DoS 攻击。
