# 循环

## Rust 的三种循环

Rust 提供三种循环方式：`loop`、`while` 和 `for`。

## loop — 无限循环

`loop` 创建一个无限循环，用 `break` 退出：

```rust
let mut counter = 0;

loop {
    counter += 1;
    if counter == 10 {
        break;
    }
}
```

`loop` 可以作为表达式，`break` 可以返回值：

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2;
    }
};
// result = 20
```

## while 循环

```rust
let mut number = 3;

while number != 0 {
    println!("{}!", number);
    number -= 1;
}
```

## for 循环（推荐）

Rust 中**最常用的循环**，遍历迭代器：

```rust
let arr = [10, 20, 30, 40, 50];

for element in arr {
    println!("值: {}", element);
}
```

### range 循环

```rust
// 1 到 4（不包含 4）
for i in 1..4 {
    println!("{}", i);  // 1, 2, 3
}

// 包含 4
for i in 1..=4 {
    println!("{}", i);  // 1, 2, 3, 4
}

// 递减
for i in (1..4).rev() {
    println!("{}", i);  // 3, 2, 1
}
```

## 循环控制

- `break`：退出循环
- `continue`：跳过当前迭代

## 练习任务

1. 使用 `loop` + `break` 计算 1 到 100 的和
2. 使用 `while` 实现倒计时
3. 使用 `for` 遍历数组并找出最大值
4. 使用 `for` + `rev()` 倒序打印数字

## 知识点总结

- `loop`：无限循环，可返回值
- `while`：条件循环
- `for`：迭代器循环（推荐）
- `1..4` 不包含 4，`1..=4` 包含 4

> 💡 提示：Rust 中 `for` 循环远多于 `while`。`for` 更安全（不会无限循环），更 Pythonic。
