# 枚举与模式匹配

## 枚举（enum）

枚举可以定义一组可能的取值，比 C/Java 的 enum 更强大：

```rust
enum Direction {
    Up,
    Down,
    Left,
    Right,
}

let dir = Direction::Up;
```

## 枚举携带数据

Rust 的枚举可以携带不同类型的数据：

```rust
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(i32, i32, i32),
}
```

## Option<T> — 安全空值

Rust 没有 `null`，用 `Option<T>` 替代：

```rust
enum Option<T> {
    Some(T),
    None,
}

let some_number = Some(5);
let absent_number: Option<i32> = None;
```

使用 `Option` 时必须显式处理 `None` 情况，编译器强制检查。

## match 处理 Option

```rust
let x: Option<i32> = Some(5);

match x {
    Some(i) => println!("值: {}", i),
    None => println!("空值"),
}
```

## if let 简化

```rust
let x = Some(5);

if let Some(i) = x {
    println!("值: {}", i);
}
```

## 知识点总结

- `enum` 可以携带不同类型的数据
- `Option<T>` 替代 null，强制处理空值
- `match` 穷尽性检查所有枚举变体
- Rust 枚举是代数数据类型（ADT）

> 💡 提示：`Option<T>` 是 Rust 消除空指针异常的核心机制。编译器确保你不会忘记处理 None。
