# 字符串处理

## Rust 的两种字符串

Rust 有两种主要的字符串类型：

| 类型 | 描述 | 位置 | 可变性 |
|------|------|------|--------|
| `String` | 堆分配，可变 UTF-8 | 堆 | 可变 |
| `&str` | 字符串切片 | 任意 | 不可变 |

## 创建字符串

```rust
// 从字面量创建
let s = "hello";           // &str

// 转换为 String
let s = s.to_string();     // "hello"
let s = String::from("hello");

// 追加
let mut s = String::from("hello");
s.push_str(" world");
s.push('!');
// s = "hello world!"
```

## 字符串操作

```rust
let s = String::from("hello world");

// 拼接
let s2 = s + " rust";      // "hello world rust"

// format! 宏（推荐）
let s3 = format!("{} loves {}", "Rust", "You");

// 长度
println!("{}", s.len());   // 11

// 判断是否为空
println!("{}", s.is_empty());
```

## 索引与切片

Rust 的字符串是 UTF-8 编码，**不能直接用索引访问**：

```rust
// 编译错误！
// let h = s[0];

// 正确方式
let hello = &s[0..5];      // "hello"
```

## 遍历字符

```rust
for c in "你好".chars() {
    println!("{}", c);     // 你，好
}
```

## 练习任务

1. 用 `+` 拼接两个字符串
2. 用 `format!` 拼接多个字符串
3. 使用 `push_str` 和 `push` 修改字符串
4. 遍历字符串的每个字符

## 知识点总结

- `String`：堆上可变 UTF-8
- `&str`：字符串切片（不可变引用）
- 字符串是 UTF-8，不能用 `s[0]` 索引
- `format!` 是最灵活的拼接方式

> 💡 提示：Rust 选择 UTF-8 是因为它是互联网的通用编码，`String` 的 `.len()` 返回字节数而非字符数。
