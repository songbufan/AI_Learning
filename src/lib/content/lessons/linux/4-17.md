# 环境变量与 Shell 配置

## 环境变量

环境变量是 Shell 中存储配置信息的变量，影响程序的行为。

### 常用环境变量

```bash
$HOME       # 用户主目录路径（如 /home/alice）
$PATH       # 可执行文件搜索路径
$USER       # 当前用户名
$SHELL      # 默认 Shell 路径
$LANG       # 系统语言/区域设置
$PS1        # 终端提示符样式
$PWD        # 当前工作目录
$OLDPWD     # 上一次的工作目录
```

### 查看和设置环境变量

```bash
# 查看环境变量
echo $HOME
env                          # 查看所有环境变量
printenv HOME                # 同 echo，跨平台兼容

# 设置临时环境变量（当前 Shell 会话有效）
export MY_VAR="hello"

# 设置永久环境变量
echo 'export MY_VAR="hello"' >> ~/.bashrc
source ~/.bashrc             # 重新加载配置
```

## PATH 管理

`PATH` 是 Shell 查找命令的目录列表，用冒号 `:` 分隔。

```bash
# 查看 PATH
echo $PATH
# 输出：/usr/local/bin:/usr/bin:/bin:/usr/local/sbin

# 添加路径（临时）
export PATH=$PATH:/new/path

# 添加路径（永久）
echo 'export PATH=$PATH:/new/path' >> ~/.bashrc
source ~/.bashrc

# 查看某个命令的位置
which python3
type -a python3
```

## Shell 配置文件

### Bash 配置文件加载顺序

| Shell 类型 | 加载顺序 |
|-----------|----------|
| 登录 Shell | `/etc/profile` → `~/.bash_profile` → `~/.bash_login` → `~/.profile` |
| 交互式非登录 | `~/.bashrc` |
| 非交互式 | `$BASH_ENV` |

### 常用配置文件

```bash
~/.bashrc       # 交互式 Shell 配置（别名、函数、提示符）
~/.profile      # 登录 Shell 配置（环境变量、PATH）
~/.bash_profile # 登录 Shell 配置（可替代 ~/.profile）
```

### 实用配置示例

```bash
# ~/.bashrc 中添加：

# 自定义提示符
export PS1='\u@\h:\w\$ '

# 常用别名
alias ll='ls -la'
alias la='ls -A'
alias l='ls -CF'
alias rm='rm -i'
alias cp='cp -i'
alias mv='mv -i'

# 添加 PATH
export PATH=$PATH:$HOME/.local/bin

# 设置编辑器
export EDITOR=vim
```

## 变量类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 局部变量 | 只在当前 Shell 有效 | `name="Alice"` |
| 环境变量 | 对当前 Shell 及子进程有效 | `export name="Alice"` |
| Shell 变量 | Bash 内部使用 | `$BASH_VERSION` |

## 练习任务

1. 查看当前 PATH：`echo $PATH | tr ':' '\n'`
2. 临时添加目录到 PATH：`export PATH=$PATH:/tmp/test`
3. 查看所有环境变量：`env | head -20`
4. 在 `~/.bashrc` 中添加一个别名：`alias ll='ls -la'`
5. 重新加载配置：`source ~/.bashrc`
6. 测试别名：输入 `ll` 查看效果

## 知识点总结

- 环境变量使用 `export` 设置，对当前 Shell 及子进程有效
- `PATH` 控制命令查找路径，用冒号分隔
- `~/.bashrc` 在每次打开终端时加载
- `~/.profile` 在登录时加载一次
- 别名（alias）可以简化常用命令

> 💡 提示：`~/.bashrc` 是交互式 Shell 的配置文件，每次打开终端都会加载。`.profile` 在登录时加载一次。修改配置后使用 `source ~/.bashrc` 立即生效。
