# Linux 简介

## 什么是 Linux

Linux 是一套开源免费的操作系统内核，由芬兰程序员 **Linus Torvalds** 于 1991 年首次发布。它是当今世界上使用最广泛的操作系统内核，驱动着从超级计算机、服务器到嵌入式设备和智能手机的一切。

## Linux 的历史

| 时间 | 事件 |
|------|------|
| 1969 | Unix 诞生于贝尔实验室 |
| 1983 | Richard Stallman 发起 GNU 计划 |
| 1991 | Linus Torvalds 发布 Linux 0.01 |
| 1992 | Linux 采用 GPL 开源协议 |
| 现在 | Linux 统治服务器、云计算、移动端 |

## Linux 核心特点

1. **开源免费** — 源代码公开，可自由修改和分发
2. **多用户多任务** — 支持数百人同时使用一台服务器
3. **稳定性高** — 企业服务器可连续运行数年不重启
4. **安全性强** — 完善的权限管理和安全机制
5. **高度可定制** — 从内核到桌面环境完全可控

## Linux 的应用领域

- **服务器领域**：全球 90% 以上的服务器运行 Linux
- **云计算**：AWS、Azure、阿里云等云平台基于 Linux
- **嵌入式设备**：路由器、智能电视、车载系统
- **移动端**：Android 系统基于 Linux 内核
- **科学计算**：TOP500 超级计算机全部运行 Linux

## 为什么学习 Linux

作为开发者，掌握 Linux 是必备技能：

- 绝大多数服务器部署在 Linux 上
- 开发和部署环境通常基于 Linux
- DevOps、云计算、容器技术均以 Linux 为基础
- 开源社区活跃，学习资源丰富

```bash
# 验证系统信息
uname -a           # 查看内核版本
cat /etc/os-release # 查看发行版信息
whoami             # 查看当前用户
```

## 练习任务

1. 在你的终端中运行 `uname -a` 查看系统内核版本
2. 运行 `cat /etc/os-release` 查看你使用的 Linux 发行版
3. 用 `whoami` 查看当前登录的用户名
4. 思考：为什么 Linux 在服务器领域如此受欢迎？

## 知识点总结

- Linux 是开源操作系统内核，基于 Unix 设计哲学
- 全球绝大多数服务器运行 Linux
- Linux 在云计算、嵌入式、移动端都有广泛应用
- 开发者必须掌握 Linux 命令行基础

> 💡 提示：可以先在虚拟机或 WSL（Windows Subsystem for Linux）中体验 Linux。
