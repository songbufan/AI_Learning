# Linux 发行版与桌面环境

## 什么是 Linux 发行版

Linux 内核本身只是操作系统的核心。一个完整的操作系统还需要系统工具、软件包管理器、桌面环境等。将这些组件打包在一起的完整系统称为 **Linux 发行版**（Distribution）。

## 主流 Linux 发行版

| 发行版 | 基于 | 包管理器 | 适用场景 | 特点 |
|--------|------|----------|----------|------|
| **Ubuntu** | Debian | apt/dpkg | 桌面/服务器/新手 | 社区活跃，文档丰富 |
| **Debian** | — | apt/dpkg | 稳定服务器 | 极致稳定，软件包测试严格 |
| **CentOS/Rocky** | RHEL | dnf/rpm | 企业服务器 | 企业级稳定支持 |
| **Fedora** | RHEL | dnf/rpm | 开发者/桌面 | 软件新，滚动更新 |
| **Arch Linux** | 独立 | pacman | 高级用户 | 滚动更新，高度可定制 |
| **openSUSE** | — | zypper/rpm | 桌面/服务器 | YaST 配置工具强大 |

## Debian vs RPM 系

```
Debian 系（apt）         RPM 系（yum/dnf）
  Ubuntu                   Fedora
  Debian                   CentOS/Rocky
  Linux Mint               openSUSE
  Kali Linux               RHEL
```

## 桌面环境

Linux 提供了多种桌面环境，可以根据硬件配置和个人偏好选择：

| 桌面环境 | 资源占用 | 特点 |
|----------|----------|------|
| GNOME | 中等 | 现代化设计，默认于 Ubuntu/Fedora |
| KDE Plasma | 较高 | 高度可定制，视觉效果华丽 |
| XFCE | 低 | 轻量快速，适合老旧硬件 |
| LXDE/LXQt | 极低 | 超轻量，资源占用极小 |
| i3wm | 极低 | 平铺式窗口管理器，键盘驱动 |

## 如何选择发行版

- **新手入门**：Ubuntu、Linux Mint（界面友好，社区支持好）
- **服务器部署**：Ubuntu Server、Rocky Linux、Debian
- **开发工作**：Fedora（软件最新）、Arch Linux（滚动更新）
- **旧硬件**： Lubuntu、Xubuntu（轻量版）

## 包管理系统

```bash
# Debian/Ubuntu (apt)
sudo apt update              # 更新软件源
sudo apt upgrade             # 升级所有软件包
sudo apt install package     # 安装软件包
sudo apt remove package      # 卸载软件包

# RedHat/CentOS/Fedora (dnf/yum)
sudo dnf install package     # 安装软件包
sudo dnf update              # 更新所有软件包
sudo dnf remove package      # 卸载软件包
```

## 练习任务

1. 运行 `cat /etc/os-release` 确认你当前使用的 Linux 发行版
2. 了解你的发行版使用的包管理器是什么
3. 在维基百科上查找你感兴趣的 Linux 发行版的历史
4. 如果使用桌面版，查看你的桌面环境是什么（`echo $XDG_CURRENT_DESKTOP`）

## 知识点总结

- Linux 发行版 = Linux 内核 + 系统工具 + 软件包 + 桌面环境
- Debian 系使用 apt，RPM 系使用 dnf/yum
- 选择发行版应根据使用场景：桌面/服务器/开发/老旧硬件
- 桌面环境影响系统的外观和资源占用

> 💡 提示：对于初学者，推荐从 Ubuntu 或 Linux Mint 开始，社区支持完善，遇到问题容易找到解决方案。
