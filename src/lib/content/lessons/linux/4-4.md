# Linux 文件系统结构

## FHS 标准

Linux 遵循 **Filesystem Hierarchy Standard（文件系统层次标准）**，规定了目录和文件的组织方式。理解这一结构是使用 Linux 的基础。

## 根目录结构

```
/                    ← 根目录，所有目录的起点
├── bin/             ← 用户命令二进制文件（ls, cp, mv 等）
├── sbin/            ← 系统管理命令（fdisk, ifconfig 等）
├── etc/             ← 系统配置文件目录
├── home/            ← 普通用户的主目录
├── root/            ← root 用户的主目录
├── tmp/             ← 临时文件（重启后清空）
├── var/             ← 可变文件（日志、缓存、数据库）
├── usr/             ← 系统程序和数据（第二层次）
├── lib/             ← 共享库文件
├── dev/             ← 设备文件（硬盘、终端等）
├── proc/            ← 进程信息虚拟文件系统
├── sys/             ← 系统信息虚拟文件系统
├── boot/            ← 启动文件（内核、引导加载器）
├── mnt/             ← 临时挂载点
├── media/           ← 可移动媒体挂载点（U盘、光盘）
└── opt/             ← 第三方软件安装目录
```

## 重要目录详解

### `/home/`
每个普通用户都有一个独立的目录，路径为 `/home/用户名`。这是用户存放个人文件的地方。

```bash
# 查看你的主目录
echo $HOME
# 示例输出：/home/alice
```

### `/etc/`
系统的"配置中心"，几乎所有系统配置文件都在这里：

```
/etc/
├── passwd      ← 用户账户信息
├── shadow      ← 用户密码加密存储
├── group       ← 用户组信息
├── hostname    ← 主机名
├── resolv.conf ← DNS 配置
├── fstab       ← 文件系统挂载表
└── ssh/        ← SSH 配置目录
```

### `/var/`
存放经常变化的文件：

```
/var/
├── log/        ← 系统日志（/var/log/syslog, /var/log/auth.log）
├── cache/      ← 缓存文件
├── lib/        ← 可变状态文件
├── spool/      ← 任务队列（邮件、打印）
└── tmp/        ← 临时文件（重启后保留）
```

### `/usr/`
存放系统程序和只读数据，是根目录下最大的目录之一：

```
/usr/
├── bin/        ← 非必需的系统命令
├── lib/        ← 库文件
├── share/      ← 共享数据（文档、图标等）
├── src/        ← 源代码
└── local/      ← 本地安装的软件
```

## 重要概念

### 一切皆文件

Linux 的一个核心理念：**一切皆文件**。不仅普通数据是文件，目录、设备、管道、套接字都是文件。

```bash
# 查看不同类型"文件"
ls -l /dev     # 设备文件
ls -l /proc    # 虚拟文件系统
ls -l /proc/1  # 进程 1 的信息（也是文件）
```

### 挂载点

Linux 的所有分区都必须挂载到某个目录下才能访问。`/` 是根挂载点，其他分区挂载到子目录。

## 练习任务

1. 在终端中执行 `ls /` 查看根目录结构
2. 进入 `/etc/` 目录，列出其中的文件和目录
3. 查看 `/etc/passwd` 文件的内容（使用 `cat /etc/passwd`）
4. 查看你的主目录路径（`echo $HOME`）
5. 用 `ls -l /dev` 查看设备文件

## 知识点总结

- Linux 遵循 FHS 标准组织目录结构
- `/` 是所有目录的根，所有路径以 `/` 开头
- `/etc/` 存放配置文件，`/home/` 存放用户文件
- `/var/log/` 存放系统日志，是排查问题的关键目录
- 一切皆文件是 Linux 的核心设计哲学

> 💡 提示：记住几个关键目录的作用，其他目录可以通过 `man hier` 或 `ls /` 逐步了解。
