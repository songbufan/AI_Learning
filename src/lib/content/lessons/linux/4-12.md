# Systemd 与服务管理

## Systemd 概述

**Systemd** 是当前主流 Linux 发行版（Ubuntu 16.04+、CentOS 7+、Fedora）的初始化系统和服务管理器。

```bash
# Systemd 的职责
systemd-udevd      # 设备管理
systemd-journald   # 日志管理
systemd-logind     # 用户登录管理
systemd-resolved   # DNS 解析
systemd-networkd   # 网络管理
```

## systemctl 常用命令

| 命令 | 功能 |
|------|------|
| `systemctl start name` | 启动服务 |
| `systemctl stop name` | 停止服务 |
| `systemctl restart name` | 重启服务 |
| `systemctl reload name` | 重新加载配置（不中断服务） |
| `systemctl status name` | 查看服务状态 |
| `systemctl enable name` | 设置开机自启 |
| `systemctl disable name` | 取消开机自启 |
| `systemctl is-active name` | 检查服务是否运行 |
| `systemctl is-enabled name` | 检查是否设置了开机自启 |
| `systemctl list-units` | 列出所有运行中的服务 |

## 服务状态

```bash
# 查看服务状态
sudo systemctl status nginx

# 输出含义：
# ● nginx.service - A high performance web server
#      Loaded: loaded (/lib/systemd/system/nginx.service; enabled)
#      Active: active (running) since Mon 2024-01-01 00:00:00 UTC
#    Main PID: 1234 (nginx)
#       Tasks: 5
#      Memory: 10.5M
```

## 服务 Unit 文件

Systemd 使用 Unit 文件定义服务：

```ini
# /etc/systemd/system/app.service
[Unit]
Description=My Application
After=network.target

[Service]
Type=simple
User=deploy
WorkingDirectory=/var/www/app
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```

## 日志管理

```bash
# 查看特定服务的日志
sudo journalctl -u nginx

# 实时跟踪日志
sudo journalctl -u nginx -f

# 查看今天的日志
sudo journalctl --since today

# 查看最近 1 小时的日志
sudo journalctl --since "1 hour ago"

# 按优先级过滤
sudo journalctl -u nginx -p err  # 只显示错误及以上
```

## 练习任务

1. 查看当前运行的服务：`systemctl list-units --type=service --state=running`
2. 查看 Nginx 服务状态：`sudo systemctl status nginx`
3. 查看系统日志：`sudo journalctl --since today | head -20`
4. 查看开机启动项：`systemctl list-unit-files --type=service --state=enabled`
5. 尝试重启一个服务：`sudo systemctl restart ssh`

## 知识点总结

- Systemd 是现代 Linux 的服务管理系统
- `systemctl` 是管理服务的核心命令
- Unit 文件定义服务的配置和行为
- `journalctl` 查看系统和服务日志
- `Restart=always` 确保服务崩溃后自动重启

> 💡 提示：服务配置文件的优先级：`/etc/systemd/system/` > `/lib/systemd/system/`。修改配置后需要 `sudo systemctl daemon-reload` 重新加载。
