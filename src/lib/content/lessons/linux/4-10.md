# 用户与组管理

## 用户管理命令

Linux 是一个多用户操作系统，用户和组管理是系统管理的核心。

```bash
useradd alice              # 创建新用户
useradd -m -s /bin/bash alice  # 创建用户并设置默认 Shell
passwd alice               # 修改用户密码
usermod -aG sudo alice     # 将用户加入 sudo 组
userdel -r alice           # 删除用户及其主目录
id alice                   # 查看用户 UID/GID/所属组
whoami                     # 查看当前登录用户
```

## 组管理命令

```bash
groupadd devs              # 创建新组
groupdel devs              # 删除组
gpasswd -a alice devs      # 将用户加入组
gpasswd -d alice devs      # 将用户从组中移除
groups alice               # 查看用户所属所有组
```

## 重要系统文件

```
/etc/passwd    ← 用户账户信息（用户名、UID、GID、主目录、Shell）
/etc/shadow    ← 用户密码加密存储（仅 root 可读）
/etc/group     ← 组信息
/etc/gshadow   ← 组密码加密存储
```

### /etc/passwd 格式

```
alice:x:1000:1000:Alice:/home/alice:/bin/bash
│   │   │    │      │           │           │
│   │   │    │      │           │           └─ 登录 Shell
│   │   │    │      │           └─ 主目录
│   │   │    │      └─ 备注（GECOS）
│   │   │    └─ GID（主组 ID）
│   │   └─ UID（用户 ID）
│   └─ 密码占位符（x 表示密码在 /etc/shadow）
└─ 用户名
```

## 用户类型

| 类型 | UID 范围 | 说明 |
|------|----------|------|
| root | 0 | 超级用户，拥有所有权限 |
| 系统用户 | 1-999 | 运行系统服务 |
| 普通用户 | 1000+ | 普通登录用户 |

## 切换用户

```bash
su - alice       # 切换到 alice 用户（加载环境变量）
su               # 切换到 root（需 root 密码）
sudo command     # 以 root 权限执行单条命令
sudo -i          # 切换到 root 交互式 Shell
```

## 练习任务

1. 查看当前用户信息：`id` 和 `whoami`
2. 查看你的用户组：`groups`
3. 查看 /etc/passwd 文件的前 5 行：`head -5 /etc/passwd`
4. 查看 /etc/group 文件
5. 创建一个测试组：`sudo groupadd testgroup`
6. 将当前用户加入该组：`sudo usermod -aG testgroup $USER`

## 知识点总结

- Linux 用户分为 root、系统用户、普通用户三类
- `/etc/passwd` 存储用户信息，`/etc/shadow` 存储加密密码
- `useradd` 创建用户，`groupadd` 创建组
- `su` 切换用户，`sudo` 以管理员权限执行命令
- 组用于批量管理用户权限

> 💡 提示：UID 0 是 root，UID 1-999 是系统用户，UID 1000+ 是普通用户。不要轻易修改系统用户的 UID。
