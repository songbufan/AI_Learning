# 网络配置与诊断

## 网络接口信息

### ip 命令（推荐）

`ip` 是新一代网络配置工具，已替代 `ifconfig`：

```bash
ip addr                    # 查看所有网络接口和 IP 地址
ip addr show eth0          # 查看特定接口
ip route                   # 查看路由表
ip link                    # 查看网络接口状态
ip link set eth0 up        # 启用网卡
ip link set eth0 down      # 禁用网卡
```

## 网络诊断命令

### ping — 测试连通性

```bash
ping google.com            # 持续 ping
ping -c 4 google.com       # ping 4 次后停止
ping -i 0.5 host           # 每 0.5 秒 ping 一次
```

### curl — 传输数据

```bash
curl https://example.com   # 获取网页内容
curl -I https://example.com # 只获取 HTTP 响应头
curl -o file.zip URL        # 下载文件
curl -L URL                 # 跟随重定向
```

### DNS 查询

```bash
host google.com            # DNS 查询
dig google.com             # 详细 DNS 信息
dig +short google.com      # 只显示 IP 地址
nslookup google.com        # DNS 查询（兼容性好）
cat /etc/resolv.conf       # 查看 DNS 服务器配置
```

### 端口监听

```bash
# ss 命令（替代 netstat）
ss -tulpn                  # 显示所有 TCP/UDP 监听端口
ss -t state established    # 显示已建立的 TCP 连接
ss -s                      # 显示统计摘要
```

## 网络配置

```bash
# 查看网络配置
ip addr                    # IP 地址
ip route                   # 路由表
cat /etc/resolv.conf       # DNS 配置

# 测试连通性
ping 8.8.8.8               # 测试外网连通
curl -I https://baidu.com  # 测试 HTTP 访问
```

## 练习任务

1. 使用 `ip addr` 查看本机 IP 地址
2. 使用 `ip route` 查看默认网关
3. 使用 `ping -c 4 google.com` 测试外网连通性
4. 使用 `curl -I https://www.baidu.com` 查看 HTTP 响应头
5. 使用 `ss -tulpn` 查看哪些端口在监听
6. 使用 `cat /etc/resolv.conf` 查看 DNS 配置

## 知识点总结

- `ip addr` 替代了 `ifconfig`，是现代 Linux 的标准工具
- `ss` 替代了 `netstat`，查看端口和连接
- `curl` 是测试 HTTP 服务最常用的工具
- `ping` 测试网络连通性
- 记住常用端口号是 Linux 运维的基本功

> 💡 提示：在排查网络问题时，按照 "本机 IP → 网关 → DNS → 目标服务" 的顺序逐段排查，可以快速定位问题。
