# 终端与 Shell 基础

## 什么是终端

**终端（Terminal）** 是 Linux 中与系统交互的主要方式。通过终端，你可以输入命令来控制计算机。现代终端通常是"终端模拟器"，提供了图形化窗口来运行 Shell。

## 什么是 Shell

**Shell** 是命令解释器，它读取你在终端中输入的命令，然后执行它们。常见的 Shell 类型：

| Shell | 路径 | 特点 |
|-------|------|------|
| Bash | `/bin/bash` | 最流行，兼容性好，默认于多数发行版 |
| Zsh | `/bin/zsh` | 功能强大，支持插件和主题（Oh My Zsh） |
| Fish | `/usr/bin/fish` | 用户友好，自动补全优秀 |
| Sh | `/bin/sh` | POSIX 标准 Shell，最基础 |

## Bash 基础

Bash（Bourne Again Shell）是 Linux 最常用的 Shell。让我们从基础开始：

```bash
# 基本命令
echo "Hello, Linux!"     # 输出文本
date                    # 显示当前日期时间
whoami                  # 显示当前用户名
pwd                     # 显示当前所在目录
hostname                # 显示主机名
cal                     # 显示日历
```

## 终端快捷键

熟练掌握快捷键能大幅提升效率：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + C` | 取消当前命令 |
| `Ctrl + L` | 清屏（同 `clear` 命令） |
| `Ctrl + R` | 搜索历史命令 |
| `Tab` | 自动补全路径/命令 |
| `Ctrl + D` | 退出终端（同 `exit`） |
| `Ctrl + A` | 光标移到行首 |
| `Ctrl + E` | 光标移到行尾 |
| `Ctrl + U` | 删除光标前所有内容 |
| `Ctrl + W` | 删除光标前一个单词 |

## 命令帮助

遇到不熟悉的命令，可以查阅帮助：

```bash
# 三种获取帮助的方式
command --help          # 查看命令基本选项
man command             # 查看完整手册页
tldr command            # 查看简化的常用示例（需安装 tldr）
```

## 命令历史

```bash
history                 # 查看命令历史
history | grep ssh      # 搜索包含 ssh 的历史命令
!123                    # 执行历史中第 123 条命令
!!                      # 重复上一条命令
!$                      # 使用上一条命令的最后一个参数
```

## Tab 自动补全

Tab 是 Linux 终端最强大的功能之一：

- 输入命令的一部分后按 `Tab` 自动补全
- 输入路径时按 `Tab` 自动补全文件名
- 按两次 `Tab` 显示所有可能的补全选项

```bash
# 示例
cd /u<Tab>              # 自动补全为 cd /usr/
ls /etc/<Tab>           # 显示 /etc/ 下的文件和目录
git ch<Tab><Tab>         # 显示所有 git checkout 相关命令
```

## 练习任务

1. 打开终端，输入 `echo "Hello, Linux!"` 并执行
2. 使用 `date` 查看当前日期时间
3. 使用 `whoami` 查看当前用户名
4. 练习使用 `Tab` 键自动补全路径
5. 尝试使用 `history` 查看你的命令历史
6. 按 `Ctrl + R`，然后输入 "ls" 搜索历史中的 ls 命令

## 知识点总结

- 终端是 Linux 的主要交互方式，Shell 是命令解释器
- Bash 是最流行的 Shell，Zsh 和 Fish 提供了更多功能
- Tab 自动补全是提高效率的关键
- `man` 命令可以查阅任何命令的完整手册

> 💡 提示：初学者可以安装 `tldr`（`sudo apt install tldr`）来获取简化版的命令帮助，比 `man` 更易读。
