# 文件操作命令

## touch — 创建空文件

`touch` 命令用于创建空文件或更新文件的时间戳。

```bash
touch newfile.txt              # 创建空文件
touch file1 file2 file3        # 一次创建多个文件
touch -t 202501011200 file     # 设置文件时间戳
touch existing_file            # 更新已有文件的时间戳
```

## cp — 复制文件

`cp`（copy）用于复制文件或目录。

```bash
cp file1.txt file2.txt         # 复制文件
cp file1.txt dir/              # 复制文件到目录
cp -r dir1/ dir2/              # 递归复制目录（-r = recursive）
cp -i file1.txt file2.txt      # 覆盖前提示（interactive）
cp -v source dest              # 显示复制过程（verbose）
```

### cp 注意事项

```bash
# 目标不存在 → 复制后重命名
cp file.txt newfile.txt    # 创建 newfile.txt

# 目标存在 → 覆盖
cp file.txt existing.txt   # 覆盖 existing.txt

# 目标为目录 → 复制进去
cp file.txt /home/alice/   # 放到目录内
```

## mv — 移动/重命名

`mv`（move）用于移动或重命名文件和目录。

```bash
mv old.txt new.txt            # 重命名文件
mv file.txt /path/to/dir/     # 移动到目录
mv dir1/ dir2/                # 重命名目录
mv -i file1 file2             # 覆盖前提示
```

### mv 与 cp 的区别

- `mv` 只是移动指针，不复制数据 → 速度快
- 跨文件系统移动时会先复制再删除

## rm — 删除文件

`rm`（remove）删除文件或目录。⚠️ **删除后无法恢复！**

```bash
rm file.txt                   # 删除文件（无提示！）
rm -i file.txt                # 删除前确认（推荐）
rm -f file.txt                # 强制删除，不提示
rm *.log                      # 使用通配符删除
rm -r directory/              # 递归删除目录
rm -rf directory/             # 强制递归删除（极其危险！⚠️）
```

### 危险命令警示

```bash
# ⚠️ 极度危险！不要在 sudo 下使用通配符删除
sudo rm -rf /       # 会删除整个系统！
sudo rm -rf /*      # 同上
```

## 文件通配符

| 通配符 | 含义 | 示例 |
|--------|------|------|
| `*` | 匹配任意字符（含空） | `*.txt` 匹配所有 .txt 文件 |
| `?` | 匹配单个字符 | `file?.txt` 匹配 file1.txt, fileA.txt |
| `[abc]` | 匹配括号内任意字符 | `file[123].txt` |
| `[a-z]` | 匹配范围内任意字符 | `file[1-5].txt` |

```bash
ls *.py                     # 列出所有 Python 文件
rm file?.txt                # 删除 file1.txt, fileA.txt 等
cp file[1-5].txt backup/    # 复制 file1.txt ~ file5.txt
```

## 练习任务

1. 创建一个空文件 `practice.txt`
2. 复制 `practice.txt` 为 `practice_backup.txt`
3. 将 `practice.txt` 重命名为 `practice_renamed.txt`
4. 在 `/tmp` 下创建目录结构：`mkdir -p test/a/b/c`
5. 将 `practice_renamed.txt` 移动到 `test/a/b/c/`
6. 用 `ls -R test` 查看完整的目录结构
7. ⚠️ 安全删除：`rm -i test/a/b/c/practice_renamed.txt`

## 知识点总结

- `touch` 创建空文件或更新时间戳
- `cp -r` 递归复制目录，`mv` 移动/重命名
- `rm` 删除后不可恢复，推荐用 `rm -i` 添加确认
- `rm -rf` 极其危险，使用时务必小心
- 通配符 `*`、`?`、`[ ]` 可以批量匹配文件

> 💡 提示：养成使用 `rm -i` 的习惯，或者设置别名 `alias rm='rm -i'` 防止误删。
