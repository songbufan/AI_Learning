# 文本处理三剑客

Linux 提供了三个强大的文本处理工具：**grep**、**sed**、**awk**。掌握它们是成为 Linux 高手的必经之路。

## grep — 文本搜索

`grep`（Global Regular Expression Print）在文件中搜索匹配模式的行。

```bash
grep "pattern" file.txt              # 搜索包含 pattern 的行
grep -i "pattern" file.txt           # 忽略大小写
grep -n "pattern" file.txt           # 显示匹配行的行号
grep -c "pattern" file.txt           # 统计匹配行数
grep -v "pattern" file.txt           # 反向搜索（排除匹配行）
grep -r "pattern" /path/to/dir/      # 递归搜索目录
```

### 正则表达式

```bash
grep "^hello" file.txt     # 以 hello 开头的行（^ 行首）
grep "end$" file.txt       # 以 end 结尾的行（$ 行尾）
grep "^$" file.txt         # 匹配空行
grep "[0-9]" file.txt      # 包含数字的行
grep -E "[0-9]{3}" file   # 3 个连续数字（-E 扩展正则）
```

## sed — 流编辑器

`sed`（stream editor）用于对文本进行替换、删除、插入等操作。

```bash
# 替换
sed 's/old/new/g' file.txt           # 全局替换
sed 's/old/new/2' file.txt           # 只替换第 2 个
sed 's/old/new/gi' file.txt          # 全局 + 忽略大小写

# 删除
sed '5d' file.txt                    # 删除第 5 行
sed '1,5d' file.txt                  # 删除第 1-5 行
sed '/pattern/d' file.txt            # 删除包含 pattern 的行

# 打印
sed -n '5p' file.txt                 # 只打印第 5 行
sed -n '1,5p' file.txt               # 打印第 1-5 行
```

### 直接修改文件

```bash
sed -i 's/old/new/g' file.txt        # 直接修改文件
sed -i.bak 's/old/new/g' file.txt    # 修改前先备份
```

## awk — 文本分析

`awk` 是一种处理文本的编程语言，特别适合处理按列分隔的表格数据。

```bash
# 打印指定列
awk '{print $1}' file.txt            # 打印第一列
awk '{print $1, $3}' file.txt        # 打印第1列和第3列
awk '{print $NF}' file.txt           # 打印最后一列

# 指定分隔符
awk -F: '{print $1}' /etc/passwd    # 用冒号分隔

# 条件筛选
awk '$3 > 100 {print $1, $3}' file  # 第3列大于100

# 内置变量
awk '{print NR": "$0}' file.txt     # NR = 行号
```

## 综合示例

```bash
# 统计
wc -l file.txt             # 行数
wc -w file.txt             # 单词数

# 排序
sort file.txt              # 按字母排序
sort -n file.txt           # 按数字排序
sort -r file.txt           # 倒序排列

# 去重
uniq file.txt              # 去除相邻重复行
sort file.txt | uniq -c    # 统计每行出现次数

# 对比
diff file1 file2           # 逐行对比
diff -u file1 file2        # 统一格式（用于 patch）
```

## 练习任务

1. 创建一个包含多行文本的文件
2. 用 `grep` 搜索包含特定关键词的行
3. 用 `sed` 替换文件中的某个词
4. 用 `awk` 提取 CSV 文件的某一列
5. 用 `sort | uniq -c` 统计每行出现的次数
6. 用 `wc -l` 统计文件行数

## 知识点总结

- `grep`：搜索文件中的文本（行级）
- `sed`：流编辑器，用于替换、删除、插入文本
- `awk`：按列处理文本，适合表格数据
- `wc`：统计行数/单词数/字节数
- `sort`/`uniq`/`diff`：排序、去重、对比

> 💡 提示：三者组合使用非常强大。例如：`grep "error" log.txt | awk '{print $1}' | sort | uniq -c` 可以统计每个小时出现的错误次数。
