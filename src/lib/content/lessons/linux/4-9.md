# 文件权限管理

## 权限模型

Linux 采用 **9 位权限位**来控制文件和目录的访问，分为三组：

```
rwxrwxrwx
│││││││││
│││││││└── 其他用户 (others)
││││││└── 组用户 (group)
││││└── 所有者 (owner)
```

- **r (read)** = 4：可读取
- **w (write)** = 2：可修改
- **x (execute)** = 1：可执行

### 权限数字计算

| 权限 | 数字 |
|------|------|
| rwx | 7 (4+2+1) |
| rw- | 6 (4+2+0) |
| r-x | 5 (4+0+1) |
| r-- | 4 (4+0+0) |
| --- | 0 |

## 查看文件权限

```bash
ls -l file.txt

# 输出示例：
# -rw-r--r-- 1 alice users 1234 Jul 25 10:30 file.txt
# │││││││││
# │││└─── 所有者：读+写（6）
# ││└──── 组：只读（4）
# │└───── 其他：只读（4）
# └────── 文件类型（-=文件, d=目录）
```

## 修改权限：chmod

`chmod`（change mode）修改文件权限，有两种方式：

### 数字方式

```bash
chmod 755 file.txt         # rwxr-xr-x（所有者全权限，其他人读+执行）
chmod 644 file.txt         # rw-r--r--（所有者读写，其他人只读）
chmod 700 file.txt         # rwx------（只有所有者可访问）
chmod 777 file.txt         # rwxrwxrwx（所有人完全权限，⚠️ 不安全）
```

### 符号方式

```bash
chmod u+x script.sh        # 所有者添加执行权限
chmod g+w file.txt         # 组添加写权限
chmod o-r file.txt         # 其他人移除读权限
chmod a+rx file.txt        # 所有人添加读和执行权限
```

**符号说明：**
- `u` = user（所有者）
- `g` = group（组）
- `o` = others（其他人）
- `a` = all（所有人）

## 修改所有者：chown

`chown`（change owner）修改文件的所有者和所属组。

```bash
chown alice file.txt                       # 修改所有者
chown alice:developers file.txt            # 修改所有者和组
chown -R alice:developers /project/        # 递归修改目录及子内容
```

> 注意：`chown` 通常需要 `sudo` 权限

## 特殊权限

| 权限 | 作用 |
|------|------|
| Setuid (s) | 执行时以文件所有者身份运行 |
| Setgid (s) | 目录新建文件自动继承目录的组 |
| Sticky Bit (t) | 目录中只有文件所有者能删除文件（如 /tmp） |

## 目录权限

| 权限 | 对目录的含义 |
|------|-------------|
| r | 可以列出目录内容（ls） |
| w | 可以在目录中创建/删除文件 |
| x | 可以进入目录（cd）和访问其中文件 |

> ⚠️ 注意：删除文件需要有**目录的写权限**，而非文件本身的写权限！

## umask

`umask` 设置新创建文件的默认权限掩码：

```bash
umask                    # 查看当前 umask（通常是 0022 或 0002）
umask 002                # 设置 umask（组用户有写权限）

# umask 0022 的含义：
# 文件默认权限：666 - 022 = 644（rw-r--r--）
# 目录默认权限：777 - 022 = 755（rwxr-xr-x）
```

## 练习任务

1. 创建一个文件 `test.txt`，查看其权限 `ls -l test.txt`
2. 使用 `chmod 644 test.txt` 设置权限
3. 使用符号方式 `chmod u+x test.txt` 添加执行权限
4. 创建一个目录 `shared_dir`，设置 `chmod 777 shared_dir`
5. 在目录中创建文件，观察目录权限如何影响操作
6. 查看当前 umask 值：`umask -S`

## 知识点总结

- Linux 权限分为所有者、组、其他人三组，每组 rwx
- `chmod` 修改权限（数字方式或符号方式）
- `chown` 修改所有者（需 sudo）
- 删除文件需要目录的写权限
- `umask` 控制新文件的默认权限

> 💡 提示：不要对 Web 目录使用 777 权限，这会带来严重的安全风险。推荐使用 755（目录）和 644（文件）。
