# Shell 脚本基础

## 脚本文件结构

一个基本的 Shell 脚本：

```bash
#!/bin/bash
# 这是一个注释

# 变量定义
name="Alice"
age=25

# 输出
echo "Hello, $name!"
```

### 执行脚本

```bash
chmod +x script.sh    # 添加执行权限
./script.sh           # 执行脚本
bash script.sh        # 用 bash 执行（不需要 chmod）
source script.sh      # 在当前 Shell 中执行（影响环境变量）
```

## 变量

```bash
# 变量定义（等号两侧不能有空格）
name="Alice"
age=25
pi=3.14

# 使用变量（需要 $ 前缀）
echo $name
echo ${age}

# 只读变量
readonly pi=3.14

# 环境变量
export PATH=$PATH:/new/path
```

## 条件判断

```bash
# if-elif-else
if [ $age -ge 18 ]; then
    echo "成年人"
elif [ $age -ge 13 ]; then
    echo "青少年"
else
    echo "儿童"
fi

# case 语句
case $fruit in
    "apple") echo "苹果" ;;
    "banana") echo "香蕉" ;;
    *) echo "其他水果" ;;
esac
```

### 条件测试操作符

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `-eq` | 等于 | `[ $a -eq 5 ]` |
| `-ne` | 不等于 | `[ $a -ne 5 ]` |
| `-gt` | 大于 | `[ $a -gt 5 ]` |
| `-lt` | 小于 | `[ $a -lt 5 ]` |
| `-ge` | 大于等于 | `[ $a -ge 5 ]` |
| `-le` | 小于等于 | `[ $a -le 5 ]` |

## 循环

```bash
# for 循环
for i in {1..5}; do
    echo "数字: $i"
done

# while 循环
count=1
while [ $count -le 5 ]; do
    echo "计数: $count"
    count=$((count + 1))
done

# 遍历文件
for file in *.txt; do
    echo "处理: $file"
done
```

## 函数

```bash
# 定义函数
greet() {
    local name=$1  # 参数 $1, $2, ...
    echo "Hello, $name!"
}

# 调用函数
greet "Alice"
greet "Bob"
```

## 命令行参数

```bash
# $0 = 脚本名称
# $1, $2, ... = 参数
# $# = 参数个数
# $@ = 所有参数
# $? = 上一条命令的退出状态

echo "脚本名: $0"
echo "参数1: $1"
echo "参数个数: $#"
echo "所有参数: $@"
```

2. 添加变量：让脚本接收一个名字参数并输出问候
3. 添加条件判断：根据参数个数输出不同消息
4. 添加循环：用 for 循环输出 1 到 10
5. 添加函数：创建一个计算平方的函数

## 知识点总结

- Shell 脚本以 `#!/bin/bash` 开头
- 变量用 `name=value` 定义，使用时要加 `$`
- `[ ]` 条件判断两侧要有空格
- `$1, $2...` 获取命令行参数，`$#` 获取参数个数
- 函数用 `name() { ... }` 定义

> 💡 提示：Shell 脚本调试技巧：在脚本开头添加 `set -x` 可以看到每条命令的执行过程。用 `shellcheck` 工具可以检查脚本错误。
